Users interact with ClickHouse using SQL statements. ClickHouse supports common SQL statements like [SELECT](/reference/statements/select) and [CREATE](/reference/statements/create), but it also provides specialized statements like [KILL](/reference/statements/kill) and [OPTIMIZE](/reference/statements/optimize).
