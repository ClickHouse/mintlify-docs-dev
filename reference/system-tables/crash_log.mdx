## Description {#description}

Contains information about stack traces for fatal errors. The table does not exist in the database by default, it is created only when fatal errors occur.

## Columns {#columns}

{/*AUTOGENERATED_START*/}
- `hostname` ([LowCardinality(String)](/reference/data-types/string)) — Hostname of the server executing the query.
- `event_date` ([DateTime](/reference/data-types/datetime)) — Date of the event.
- `event_time` ([DateTime](/reference/data-types/datetime)) — Time of the event.
- `timestamp_ns` ([UInt64](/reference/data-types/int-uint)) — Timestamp of the event with nanoseconds.
- `signal` ([Int32](/reference/data-types/int-uint)) — Signal number.
- `thread_id` ([UInt64](/reference/data-types/int-uint)) — Thread ID.
- `query_id` ([String](/reference/data-types/string)) — Query ID.
- `trace` ([Array](/reference/data-types/array)([UInt64](/reference/data-types/int-uint))) — Stack trace at the moment of crash. Each element is a virtual memory address inside ClickHouse server process.
- `trace_full` ([Array](/reference/data-types/array)([String](/reference/data-types/string))) — Stack trace at the moment of crash. Each element contains a called method inside ClickHouse server process.
- `version` ([String](/reference/data-types/string)) — ClickHouse server version.
- `revision` ([UInt32](/reference/data-types/int-uint)) — ClickHouse server revision.
- `build_id` ([String](/reference/data-types/string)) — BuildID that is generated by compiler.
{/*AUTOGENERATED_END*/}

SELECT * FROM system.crash_log ORDER BY event_time DESC LIMIT 1;
