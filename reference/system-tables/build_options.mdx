## Description <a id="description"></a>

Contains information about the ClickHouse server's build options.

## Columns <a id="columns"></a>

{/*AUTOGENERATED_START*/}
- `name` ([String](/reference/data-types/index)) — Name of the build option.
- `value` ([String](/reference/data-types/index)) — Value of the build option.
{/*AUTOGENERATED_END*/}

## Example <a id="example"></a>

```sql
SELECT * FROM system.build_options LIMIT 5
```

```text
┌─name─────────────┬─value─┐
│ USE_BROTLI       │ 1     │
│ USE_BZIP2        │ 1     │
│ USE_CAPNP        │ 1     │
│ USE_CASSANDRA    │ 1     │
│ USE_DATASKETCHES │ 1     │
└──────────────────┴───────┘
```
