<div id="migration">
  # Migration
</div>

Outils ponctuels et données utilisés pour migrer la documentation ClickHouse de Docusaurus
vers Mintlify. **L’intégralité de ce dossier peut être supprimée une fois la migration
terminée** — rien sur le site en production n’en dépend pendant l’exécution.

<div id="contents">
  ## Contenu
</div>

* `slug-map.csv` — correspondance de chaque slug Docusaurus → fichier/URL Mintlify, avec
  les hash source/migrés pour le suivi de l’obsolescence.
* `slug-aliases.csv` — alias revus manuellement pour les slugs qui n’ont pas pu être
  résolus automatiquement.
* `migrate.py` — script principal de migration. Lit `slug-map.csv`, applique
  les transformations nécessaires à Mintlify, puis écrit le résultat.
* `generate-slug-map.py` — régénère `slug-map.csv` à partir du Docusaurus upstream
  * de la structure actuelle de ce dépôt.
* `apply-slug-aliases.py` — réécrit les marqueurs `<!-- MIGRATE: unknown slug -->`
  à l’aide de `slug-aliases.csv`.
* `suggest-slug-aliases.py` — propose des alias pour les slugs non résolus.
* `match_slugless.py` — trouve les pages Mintlify sans correspondance avec un slug upstream.
* `verify_mapping.py` — vérifie la cohérence de la table de correspondance des slugs pour détecter les doublons/dérives.
* `find_dup_imports.py` — détecte les conflits d’imports MDX causés par la
  remontée des imports de snippets dans le bundle parent par Mintlify.

Voir `.claude/skills/migrate-docusaurus-to-mintlify/SKILL.md` pour le
workflow de migration.
