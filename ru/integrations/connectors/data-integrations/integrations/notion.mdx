[Notion](https://www.notion.com/) — это единое рабочее пространство для заметок, документов, проектов и Custom Agents на базе ИИ.

Вы можете подключить ClickHouse Cloud к [Custom Agent](https://www.notion.com/help/mcp-connections-for-custom-agents) в Notion как пользовательский MCP-сервер. После подключения агент сможет просматривать ваши данные, выполнять аналитические запросы в режиме только для чтения и получать информацию о сервисе и расходах в ClickHouse Cloud, не покидая Notion.

<div id="prerequisites">
  ## Предварительные требования
</div>

* Запущенный [сервис ClickHouse Cloud](/ru/get-started/setup/cloud) с [включенным удалённым MCP-сервером](/ru/products/cloud/features/ai-ml/mcp/remote-mcp#enable-remote-mcp-server)
* Рабочее пространство Notion на тарифе **Business** или **Enterprise**
* Администратор рабочего пространства включил **Custom MCP servers** в разделе **Settings** &gt; **Notion AI** &gt; **AI connectors**

<div id="connect-clickhouse-to-notion">
  ## Подключите ClickHouse к Custom Agent в Notion
</div>

1. В Notion откройте Custom Agent, который хотите расширить, и нажмите **Настройки**.
2. В разделе **Инструменты и доступ** нажмите **Добавить подключение** и выберите **Custom MCP server**.

{/* TODO(screenshot): меню «Add connection» в разделе Tools & Access агента, где показана опция «Custom MCP server» */}

3. Введите URL-адрес удалённого MCP-сервера ClickHouse Cloud и задайте для подключения отображаемое имя, например `ClickHouse`:

   ```text
   https://mcp.clickhouse.cloud/mcp
   ```

{/* TODO(screenshot): диалоговое окно Custom MCP server с заполненными URL-адресом сервера и отображаемым именем */}

4. Нажмите **Save**, затем завершите процесс OAuth, чтобы выполнить аутентификацию с помощью учетных данных ClickHouse Cloud. Доступ будет ограничен организациями и сервисами, к которым у вашей учетной записи уже есть доступ.

{/* TODO(screenshot): экран согласия OAuth / состояние с подтверждением "Подключено" */}

5. Разверните новое соединение, чтобы просмотреть [доступные инструменты ClickHouse](/ru/products/cloud/features/ai-ml/remote-mcp#available-tools), и включите те, которые должен использовать этот агент. Все инструменты ClickHouse Remote MCP работают в режиме только для чтения.

{/* TODO(screenshot): развернутое подключение ClickHouse со списком переключателей инструментов */}

<Note>
  Для каждого Custom Agent требуется отдельное подключение к ClickHouse, и только пользователь, который его авторизовал, может изменять настройки его инструментов. Подробнее см. в [рекомендациях Notion по безопасности для подключений Agent](https://www.notion.com/help/security-best-practices-for-agent-connections).
</Note>

<div id="example-prompts">
  ## Примеры промптов
</div>

После подключения вы можете задавать Custom Agent вопросы на естественном языке. Вот несколько примеров:

| Промпт                                                                       | Вызываемый инструмент   |
| ---------------------------------------------------------------------------- | ----------------------- |
| &quot;Какие базы данных доступны в моем сервисе ClickHouse?&quot;            | `list_databases`        |
| &quot;Покажи 10 первых строк из таблицы `hits`&quot;                         | `run_select_query`      |
| &quot;Сколько стоил ClickHouse для моей организации на прошлой неделе?&quot; | `get_organization_cost` |
| &quot;Покажи недавние резервные копии для этого сервиса&quot;                | `list_service_backups`  |

Полный набор шаблонов на естественном языке и инструментов см. в разделе [Пример использования Remote MCP](/ru/products/cloud/features/ai-ml/mcp/remote-mcp#example-usage).
