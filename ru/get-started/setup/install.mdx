Выберите вариант развертывания или способ установки.

<Visibility for="agents">
  Если вы ИИ-агент и устанавливаете ClickHouse, проще всего
  воспользоваться ClickHouse CLI. Выполните следующую
  однострочную команду — она автоматически определит вашу ОС и
  архитектуру и сохранит бинарный файл `clickhouse` в текущем каталоге:

  ```bash
  curl https://clickhouse.com/ | sh
  ```

  После этого вы можете запустить сервер командой `./clickhouse server` или выполнять
  разовые запросы с помощью `./clickhouse local`. Не нужны ни менеджер пакетов, ни Docker, ни права root.
</Visibility>

<Card title="ClickHouse Cloud (рекомендуется)" icon="cloud" href="/ru/get-started/setup/cloud">
  Начните работу сразу, без необходимости подбирать размер кластера и заниматься его масштабированием. ClickHouse Cloud берет на себя подбор ресурсов, масштабирование, безопасность, надежность и обновления.
</Card>

Если вы предпочитаете самостоятельное управление, выберите один из вариантов ClickHouse с открытым исходным кодом ниже. Для локальной установки используйте скрипт быстрой установки или CLI `clickhousectl`, либо установите ClickHouse Server из пакетов или бинарных файлов для развертывания в продакшн.
