<div id="description">
  ## Описание
</div>

Эта таблица содержит информацию о столбцах в частях проекций таблиц семейства MergeTree.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `partition` ([String](/ru/reference/data-types)) — имя партиции.
* `name` ([String](/ru/reference/data-types)) — Имя части данных.
* `part_type` ([String](/ru/reference/data-types)) — Формат хранения части данных.
* `parent_name` ([String](/ru/reference/data-types)) — Имя исходной (родительской) части данных.
* `parent_uuid` ([UUID](/ru/reference/data-types)) — UUID исходной (родительской) части данных.
* `parent_part_type` ([String](/ru/reference/data-types)) — Формат хранения исходной (родительской) части данных.
* `active` ([UInt8](/ru/reference/data-types)) — Флаг, показывающий, активна ли часть данных
* `marks` ([UInt64](/ru/reference/data-types)) — Количество меток.
* `rows` ([UInt64](/ru/reference/data-types)) — количество строк.
* `bytes_on_disk` ([UInt64](/ru/reference/data-types)) — Суммарный размер всех файлов частей данных в байтах.
* `data_compressed_bytes` ([UInt64](/ru/reference/data-types)) — Общий размер сжатых данных в части данных. Все вспомогательные файлы (например, файлы с mark) не включаются.
* `data_uncompressed_bytes` ([UInt64](/ru/reference/data-types)) — Общий размер несжатых данных в части данных. Все вспомогательные файлы (например, файлы меток) не учитываются.
* `marks_bytes` ([UInt64](/ru/reference/data-types)) — Размер файла меток.
* `parent_marks` ([UInt64](/ru/reference/data-types)) — Количество marks в исходной (родительской) части.
* `parent_rows` ([UInt64](/ru/reference/data-types)) — Количество строк в исходной (родительской) части.
* `parent_bytes_on_disk` ([UInt64](/ru/reference/data-types)) — Общий размер в байтах всех файлов исходной (родительской) части данных.
* `parent_data_compressed_bytes` ([UInt64](/ru/reference/data-types)) — Общий размер сжатых данных в исходной (родительской) части данных.
* `parent_data_uncompressed_bytes` ([UInt64](/ru/reference/data-types)) — Суммарный размер несжатых данных в исходной (родительской) части данных.
* `parent_marks_bytes` ([UInt64](/ru/reference/data-types)) — Размер файла с метками в исходной (родительской) части данных.
* `modification_time` ([DateTime](/ru/reference/data-types)) — Время изменения каталога с частью данных. Обычно оно соответствует времени создания части данных.
* `remove_time` ([DateTime](/ru/reference/data-types)) — Время, когда часть данных стала неактивной.
* `refcount` ([UInt32](/ru/reference/data-types)) — Число мест, в которых используется часть данных. Значение больше 2 указывает на то, что часть данных используется в запросах или при слиянии.
* `min_date` ([Date](/ru/reference/data-types)) — минимальное значение для столбца Date, если он включён в ключ партиционирования.
* `max_date` ([Date](/ru/reference/data-types)) — Максимальное значение столбца Date, если он входит в ключ партиционирования.
* `min_time` ([DateTime](/ru/reference/data-types)) — минимальное значение для столбца типа DateTime, если он входит в ключ партиционирования.
* `max_time` ([DateTime](/ru/reference/data-types)) — максимальное значение для столбца DateTime, если он входит в ключ партиционирования.
* `partition_id` ([String](/ru/reference/data-types)) — идентификатор партиции.
* `min_block_number` ([Int64](/ru/reference/data-types)) — Минимальное количество частей данных, из которых после слияния состоит текущая часть.
* `max_block_number` ([Int64](/ru/reference/data-types)) — Максимальное число частей данных, образующих текущую часть после слияния.
* `level` ([UInt32](/ru/reference/data-types)) — Глубина дерева слияния. Ноль означает, что текущая часть была создана в результате вставки, а не при слиянии других частей.
* `data_version` ([UInt64](/ru/reference/data-types)) — число, используемое для определения того, какие мутации должны быть применены к части данных (мутации с версией выше, чем у data&#95;version).
* `primary_key_bytes_in_memory` ([UInt64](/ru/reference/data-types)) — Объём памяти (в байтах), используемый для значений первичного ключа.
* `primary_key_bytes_in_memory_allocated` ([UInt64](/ru/reference/data-types)) — Объём памяти (в байтах), зарезервированный для значений первичного ключа.
* `database` ([String](/ru/reference/data-types)) — Название базы данных.
* `table` ([String](/ru/reference/data-types)) — Название таблицы.
* `engine` ([String](/ru/reference/data-types)) — Название движка таблицы без параметров.
* `disk_name` ([String](/ru/reference/data-types)) — Имя диска, на котором хранится часть данных.
* `path` ([String](/ru/reference/data-types)) — Абсолютный путь к папке с файлами части данных.
* `column` ([String](/ru/reference/data-types)) — Имя столбца.
* `type` ([String](/ru/reference/data-types)) — тип столбца.
* `column_position` ([UInt64](/ru/reference/data-types)) — Порядковый номер столбца в таблице, начиная с 1.
* `default_kind` ([String](/ru/reference/data-types)) — тип выражения (DEFAULT, MATERIALIZED, ALIAS) для значения по умолчанию либо пустая строка, если оно не определено.
* `default_expression` ([String](/ru/reference/data-types)) — Выражение для значения по умолчанию или пустая строка, если оно не задано.
* `column_bytes_on_disk` ([UInt64](/ru/reference/data-types)) — Общий размер столбца в байтах.
* `column_data_compressed_bytes` ([UInt64](/ru/reference/data-types)) — Общий размер сжатых данных в столбце в байтах.
* `column_data_uncompressed_bytes` ([UInt64](/ru/reference/data-types)) — Общий размер несжатых данных в столбце в байтах.
* `column_marks_bytes` ([UInt64](/ru/reference/data-types)) — Размер столбца с засечками, в байтах.
* `column_modification_time` ([Nullable(DateTime)](/ru/reference/data-types)) — Время последнего изменения столбца.
