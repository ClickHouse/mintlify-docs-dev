<div id="description">
  ## Описание
</div>

Содержит информацию о доступных сертификатах и источниках их получения.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `version` ([Int32](/ru/reference/data-types)) — Версия сертификата. Значения: 0 для v1, 1 для v2, 2 для v3.
* `serial_number` ([Nullable(String)](/ru/reference/data-types)) — Серийный номер сертификата, присвоенный издателем.
* `signature_algo` ([Nullable(String)](/ru/reference/data-types)) — Алгоритм подписи — алгоритм, который издатель использовал для подписи этого сертификата.
* `issuer` ([Nullable(String)](/ru/reference/data-types)) — Издатель — уникальный идентификатор центра сертификации, выдавшего этот сертификат.
* `not_before` ([Nullable(String)](/ru/reference/data-types)) — Начало временного интервала, в течение которого этот сертификат действителен.
* `not_after` ([Nullable(String)](/ru/reference/data-types)) — Конец временного интервала, в течение которого этот сертификат действителен.
* `subject` ([Nullable(String)](/ru/reference/data-types)) — Субъект — идентифицирует владельца открытого ключа.
* `pkey_algo` ([Nullable(String)](/ru/reference/data-types)) — Алгоритм открытого ключа определяет алгоритм, с которым можно использовать открытый ключ.
* `path` ([String](/ru/reference/data-types)) — Путь к файлу или каталогу, содержащему этот сертификат.
* `default` ([UInt8](/ru/reference/data-types)) — Сертификат находится в стандартном расположении сертификатов.
* `protocol` ([String](/ru/reference/data-types)) — Имя протокола, если сертификат получен из TLS-конфигурации для конкретного протокола, иначе пусто.

{/*AUTOGENERATED_END*/}
