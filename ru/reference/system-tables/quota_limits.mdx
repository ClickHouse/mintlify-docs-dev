<div id="description">
  ## Описание
</div>

Содержит информацию о максимальных значениях для всех интервалов всех квот. Одной квоте может соответствовать любое число строк или ни одной.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `quota_name` ([String](/ru/reference/data-types)) — Имя квоты.
* `duration` ([UInt32](/ru/reference/data-types)) — Длительность временного интервала для расчета потребления ресурсов, в секундах.
* `is_randomized_interval` ([UInt8](/ru/reference/data-types)) — Логическое значение. Показывает, является ли интервал случайным. Если интервал не является случайным, он всегда начинается в одно и то же время. Например, интервал в 1 минуту всегда начинается с целой минуты (то есть может начаться в 11:20:00, но никогда не начинается в 11:20:01), а интервал в один день всегда начинается в полночь по UTC. Если интервал случайный, самый первый интервал начинается в случайный момент времени, а последующие интервалы идут один за другим. Значения: 0 — интервал не является случайным, 1 — интервал является случайным.
* `max_queries` ([Nullable(UInt64)](/ru/reference/data-types)) — Максимально допустимое количество запросов всех типов, разрешенных к выполнению.
* `max_query_selects` ([Nullable(UInt64)](/ru/reference/data-types)) — Максимально допустимое количество запросов SELECT, разрешенных к выполнению.
* `max_query_inserts` ([Nullable(UInt64)](/ru/reference/data-types)) — Максимально допустимое количество запросов INSERT, разрешенных к выполнению.
* `max_errors` ([Nullable(UInt64)](/ru/reference/data-types)) — Максимальное количество запросов, завершившихся ошибкой, допустимое в течение указанного периода времени.
* `max_result_rows` ([Nullable(UInt64)](/ru/reference/data-types)) — Максимальное общее количество строк в результирующем наборе всех запросов, допустимое в течение указанного периода времени.
* `max_result_bytes` ([Nullable(UInt64)](/ru/reference/data-types)) — Максимальное общее количество байтов в результирующем наборе всех запросов, допустимое в течение указанного периода времени.
* `max_read_rows` ([Nullable(UInt64)](/ru/reference/data-types)) — Максимальное количество строк, которое можно прочитать при выполнении всех запросов в течение указанного периода времени.
* `max_read_bytes` ([Nullable(UInt64)](/ru/reference/data-types)) — Максимальное количество байтов, которое можно прочитать при выполнении всех запросов в течение указанного периода времени.
* `max_execution_time` ([Nullable(Float64)](/ru/reference/data-types)) — Максимально допустимое суммарное время выполнения всех запросов в течение указанного периода времени (в наносекундах)
* `max_written_bytes` ([Nullable(UInt64)](/ru/reference/data-types)) — Максимальное количество байтов, которое можно записать при выполнении всех запросов в течение указанного периода времени.
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/ru/reference/data-types)) — Максимальное количество последовательных неудачных попыток аутентификации, допустимое в течение указанного периода времени.
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/ru/reference/data-types)) — Максимальное количество выполнений одного и того же нормализованного запроса, допустимое в течение указанного периода времени.
