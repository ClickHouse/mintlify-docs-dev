<div id="description">
  ## Описание
</div>

Содержит список всех доступных комбинаторов агрегатных функций, которые можно применять к агрегатным функциям, чтобы изменять их поведение.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ru/reference/data-types)) — Название комбинатора.
* `is_internal` ([UInt8](/ru/reference/data-types)) — Указывает, предназначен ли этот комбинатор только для внутреннего использования.

{/*AUTOGENERATED_END*/}
