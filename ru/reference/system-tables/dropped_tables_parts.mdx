<div id="description">
  ## Описание
</div>

Содержит сведения о частях удалённых таблиц [MergeTree](/ru/reference/engines/table-engines/mergetree-family/mergetree) из [system.dropped&#95;tables](/ru/reference/system-tables/dropped_tables)

Схема этой таблицы совпадает со схемой [system.parts](/ru/reference/system-tables/parts)

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `partition` ([String](/ru/reference/data-types)) — Идентификатор партиции (строковое представление, производное от выражения ключа партиционирования таблицы).
* `name` ([String](/ru/reference/data-types)) —
  Имя части данных. По структуре имени части можно определить многие характеристики данных, а также шаблоны приёма и слияния. Формат имени части следующий:

```text
<partition_id>_<minimum_block_number>_<maximum_block_number>_<level>_<data_version>
```

* Определения:
  * `partition_id` - идентифицирует ключ партиционирования
  * `minimum_block_number` - идентифицирует минимальный номер блока в части. ClickHouse всегда объединяет только непрерывные блоки
  * `maximum_block_number` - идентифицирует максимальный номер блока в части
  * `level` - увеличивается на единицу с каждым дополнительным слиянием части. Уровень 0 означает, что это новая часть, которая ещё не подвергалась слиянию. Важно помнить, что все части в ClickHouse всегда неизменяемы
  * `data_version` - необязательное значение, увеличивается при мутации части (опять же, изменённые данные всегда записываются только в новую часть, поскольку части неизменяемы)

* `uuid` ([UUID](/ru/reference/data-types)) — UUID части данных.

* `part_type` ([String](/ru/reference/data-types)) — Формат хранения части данных. Возможные значения: `Wide` — каждый столбец хранится в отдельном файле, `Compact` — все столбцы хранятся в одном файле. Формат хранения данных определяется настройками `min_bytes_for_wide_part` и `min_rows_for_wide_part` таблицы MergeTree.

* `active` ([UInt8](/ru/reference/data-types)) — флаг, указывающий, активна ли часть данных. Если часть данных активна, она используется в таблице. В противном случае она вскоре будет удалена. Неактивные части данных появляются после операций слияния и мутации.

* `marks` ([UInt64](/ru/reference/data-types)) — Количество меток. Чтобы получить примерное число строк в части данных, умножьте marks на гранулярность индекса (обычно 8192) (эта оценка не работает при адаптивной гранулярности).

* `rows` ([UInt64](/ru/reference/data-types)) — количество строк.

* `files` ([UInt64](/ru/reference/data-types)) — Число файлов в части данных.

* `bytes_on_disk` ([UInt64](/ru/reference/data-types)) — Суммарный размер в байтах всех файлов частей данных.

* `data_compressed_bytes` ([UInt64](/ru/reference/data-types)) — Общий размер сжатых данных в части данных. Все вспомогательные файлы (например, файлы с marks) не учитываются.

* `data_uncompressed_bytes` ([UInt64](/ru/reference/data-types)) — Общий размер несжатых данных в части данных. Все вспомогательные файлы (например, файлы с отметками) не включаются.

* `primary_key_size` ([UInt64](/ru/reference/data-types)) — Объём памяти (в байтах), занимаемый значениями первичного ключа в файле primary.idx/cidx на диске.

* `marks_bytes` ([UInt64](/ru/reference/data-types)) — Размер файла с метками.

* `secondary_indices_compressed_bytes` ([UInt64](/ru/reference/data-types)) — Общий размер сжатых данных вторичных индексов в части данных. Все вспомогательные файлы (например, файлы marks) не учитываются.

* `secondary_indices_uncompressed_bytes` ([UInt64](/ru/reference/data-types)) — Общий размер несжатых данных для вторичных индексов в части данных. Все вспомогательные файлы (например, файлы с метками) не учитываются.

* `secondary_indices_marks_bytes` ([UInt64](/ru/reference/data-types)) — Размер файла меток для вторичных индексов.

* `modification_time` ([DateTime](/ru/reference/data-types)) — Время изменения каталога с частью данных. Обычно соответствует времени создания части данных.

* `remove_time` ([DateTime](/ru/reference/data-types)) — Время, когда часть данных перестала быть активной.

* `refcount` ([UInt32](/ru/reference/data-types)) — Количество мест, в которых используется часть данных. Значение больше 2 означает, что часть данных используется в запросах или при слиянии.

* `min_date` ([Date](/ru/reference/data-types)) — Минимальное значение ключа даты в этой части данных.

* `max_date` ([Date](/ru/reference/data-types)) — максимальное значение ключа даты в части данных.

* `min_time` ([DateTime](/ru/reference/data-types)) — Минимальное значение ключа даты и времени в части данных.

* `max_time` ([DateTime](/ru/reference/data-types)) — Максимальное значение ключа даты и времени в части данных.

* `partition_id` ([String](/ru/reference/data-types)) — идентификатор партиции.

* `min_block_number` ([Int64](/ru/reference/data-types)) — Минимальное количество частей данных, из которых состоит текущая часть после слияния.

* `max_block_number` ([Int64](/ru/reference/data-types)) — Максимальное количество частей данных, из которых состоит текущая часть после слияния.

* `level` ([UInt32](/ru/reference/data-types)) — Глубина дерева слияний. Ноль означает, что текущая часть была создана в результате вставки, а не слияния других частей.

* `data_version` ([UInt64](/ru/reference/data-types)) — число, используемое для определения того, какие мутации должны быть применены к части данных (мутации с версией выше, чем у data&#95;version).

* `primary_key_bytes_in_memory` ([UInt64](/ru/reference/data-types)) — Объем памяти (в байтах), используемой для значений первичного ключа. Будет равен 0, если `primary_key_lazy_load` включен и ключ не загружен. Если значение не равно нулю, эти байты находятся в самой part и учитываются в `jemalloc.mergetree_arena.active_bytes`. Они НИКОГДА не учитываются в `PrimaryIndexCacheBytes` — для каждой part это взаимоисключающие варианты: индекс находится либо в part (эта метрика), либо в общем `PrimaryIndexCache` (другая), в зависимости от `primary_key_lazy_load` и `use_primary_key_cache`.

* `primary_key_bytes_in_memory_allocated` ([UInt64](/ru/reference/data-types)) — Объём памяти (в байтах), зарезервированной для значений первичного ключа. Равно 0, если `primary_key_lazy_load` включён и ключ не загружен. Если значение не равно нулю, входит в `jemalloc.mergetree_arena.active_bytes`. О связи с `PrimaryIndexCacheBytes` см. примечание к `primary_key_bytes_in_memory`.

* `index_granularity_bytes_in_memory` ([UInt64](/ru/reference/data-types)) — Объём памяти (в байтах), используемой для значений гранулярности индекса (будет равен 0, если primary&#95;key&#95;lazy&#95;load=1 и use&#95;primary&#95;key&#95;cache=1). Если значение не равно нулю, эти байты частично принадлежат этому объекту и учитываются в `jemalloc.mergetree_arena.active_bytes`.

* `index_granularity_bytes_in_memory_allocated` ([UInt64](/ru/reference/data-types)) — Объём памяти (в байтах), зарезервированной для значений гранулярности индекса (будет равен 0 при `primary&#95;key&#95;lazy&#95;load=1` и `use&#95;primary&#95;key&#95;cache=1`). Если значение ненулевое, оно входит в `jemalloc.mergetree_arena.active_bytes`.

* `is_frozen` ([UInt8](/ru/reference/data-types)) — Флаг, показывающий, что для данных партиции существует резервная копия. 1 — резервная копия существует. 0 — резервная копия отсутствует. Подробнее см. в разделе FREEZE PARTITION.

* `database` ([String](/ru/reference/data-types)) — Название базы данных.

* `table` ([String](/ru/reference/data-types)) — Название таблицы.

* `engine` ([String](/ru/reference/data-types)) — название движка таблицы без параметров.

* `disk_name` ([String](/ru/reference/data-types)) — Имя диска, на котором хранится часть данных.

* `path` ([String](/ru/reference/data-types)) — Абсолютный путь к папке, содержащей файлы части данных.

* `hash_of_all_files` ([String](/ru/reference/data-types)) — хеш sipHash128 сжатых файлов.

* `hash_of_uncompressed_files` ([String](/ru/reference/data-types)) — sipHash128 от несжатых файлов (файлов с marks, файла индекса и т. д.).

* `uncompressed_hash_of_compressed_files` ([String](/ru/reference/data-types)) — sipHash128 данных в сжатых файлах, вычисленный так, как если бы эти файлы были несжатыми.

* `delete_ttl_info_min` ([DateTime](/ru/reference/data-types)) — минимальное значение ключа даты и времени в правиле TTL DELETE.

* `delete_ttl_info_max` ([DateTime](/ru/reference/data-types)) — Максимальное значение ключа даты и времени в правиле TTL DELETE.

* `move_ttl_info.expression` ([Array(String)](/ru/reference/data-types)) — Массив выражений. Каждое выражение задаёт правило TTL MOVE.

* `move_ttl_info.min` ([Array(DateTime)](/ru/reference/data-types)) — Массив значений даты и времени. Каждый элемент задаёт минимальное значение ключа для правила TTL MOVE.

* `move_ttl_info.max` ([Array(DateTime)](/ru/reference/data-types)) — Массив значений даты и времени. Каждый элемент описывает максимальное значение ключа для правила TTL MOVE.

* `default_compression_codec` ([String](/ru/reference/data-types)) — Имя кодека, используемого для сжатия этой части данных (если для столбцов не задан явный кодек).

* `recompression_ttl_info.expression` ([Array(String)](/ru/reference/data-types)) — TTL-выражение.

* `recompression_ttl_info.min` ([Array(DateTime)](/ru/reference/data-types)) — Минимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы понять, есть ли хотя бы одна строка с истёкшим TTL.

* `recompression_ttl_info.max` ([Array(DateTime)](/ru/reference/data-types)) — Максимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы понять, содержатся ли в ней все строки с истёкшим TTL.

* `group_by_ttl_info.expression` ([Array(String)](/ru/reference/data-types)) — TTL-выражение.

* `group_by_ttl_info.min` ([Array(DateTime)](/ru/reference/data-types)) — Минимальное значение вычисленного выражения TTL в этой части данных. Используется, чтобы понять, есть ли хотя бы одна строка с истёкшим TTL.

* `group_by_ttl_info.max` ([Array(DateTime)](/ru/reference/data-types)) — Максимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы понять, все ли строки с истёкшим TTL присутствуют.

* `rows_where_ttl_info.expression` ([Array(String)](/ru/reference/data-types)) — выражение TTL.

* `rows_where_ttl_info.min` ([Array(DateTime)](/ru/reference/data-types)) — Минимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы определить, есть ли в ней хотя бы одна строка с истёкшим TTL.

* `rows_where_ttl_info.max` ([Array(DateTime)](/ru/reference/data-types)) — Максимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы понять, все ли строки с истекшим TTL присутствуют.

* `projections` ([Array(String)](/ru/reference/data-types)) — Список имён проекций, вычисленных для данной части.

* `visible` ([UInt8](/ru/reference/data-types)) — флаг, указывающий, видна ли эта часть для запросов SELECT.

* `creation_tid` ([Tuple(UInt64, UInt64, UUID)](/ru/reference/data-types)) — идентификатор транзакции, которая создала или пытается создать этот объект.

* `removal_tid_lock` ([UInt64](/ru/reference/data-types)) — Хэш removal&#95;tid, используется для блокировки объекта перед удалением.

* `removal_tid` ([Tuple(UInt64, UInt64, UUID)](/ru/reference/data-types)) — идентификатор транзакции, которая удалила или пытается удалить этот объект

* `creation_csn` ([UInt64](/ru/reference/data-types)) — CSN транзакции, которая создала этот объект

* `removal_csn` ([UInt64](/ru/reference/data-types)) — CSN транзакции, в результате которой был удалён этот объект

* `has_lightweight_delete` ([UInt8](/ru/reference/data-types)) — Флаг, указывающий, есть ли у части маска легковесного удаления.

* `last_removal_attempt_time` ([DateTime](/ru/reference/data-types)) — Время последней попытки сервера удалить эту часть.

* `removal_state` ([String](/ru/reference/data-types)) — Текущее состояние процесса удаления части.
