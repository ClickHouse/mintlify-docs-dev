<div id="description">
  ## Описание
</div>

Содержит информацию о выполняющихся в данный момент слияниях и мутациях частей в таблицах семейства MergeTree.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ru/reference/data-types)) — Имя базы данных, в которой находится таблица.
* `table` ([String](/ru/reference/data-types)) — Имя таблицы.
* `elapsed` ([Float64](/ru/reference/data-types)) — Время (в секундах), прошедшее с начала слияния.
* `progress` ([Float64](/ru/reference/data-types)) — Доля выполненной работы в диапазоне от 0 до 1.
* `num_parts` ([UInt64](/ru/reference/data-types)) — Количество частей, подлежащих слиянию.
* `source_part_names` ([Array(String)](/ru/reference/data-types)) — Список имён исходных частей.
* `result_part_name` ([String](/ru/reference/data-types)) — Имя части, которая будет сформирована в результате слияния.
* `source_part_paths` ([Array(String)](/ru/reference/data-types)) — Список путей для каждой исходной части.
* `result_part_path` ([String](/ru/reference/data-types)) — Путь к части, которая будет сформирована в результате слияния.
* `partition_id` ([String](/ru/reference/data-types)) — Идентификатор партиции, в которой выполняется слияние.
* `partition` ([String](/ru/reference/data-types)) — Имя партиции
* `is_mutation` ([UInt8](/ru/reference/data-types)) — 1, если этот процесс является мутацией части.
* `total_size_bytes_compressed` ([UInt64](/ru/reference/data-types)) — Общий размер сжатых данных в слитых фрагментах.
* `total_size_bytes_uncompressed` ([UInt64](/ru/reference/data-types)) — Общий размер несжатых данных в слитых фрагментах.
* `total_size_marks` ([UInt64](/ru/reference/data-types)) — Общее количество отметок в слитых частях.
* `bytes_read_uncompressed` ([UInt64](/ru/reference/data-types)) — Количество прочитанных байтов в несжатом виде.
* `rows_read` ([UInt64](/ru/reference/data-types)) — Количество прочитанных строк.
* `bytes_written_uncompressed` ([UInt64](/ru/reference/data-types)) — Количество записанных байтов в несжатом виде.
* `rows_written` ([UInt64](/ru/reference/data-types)) — Количество записанных строк.
* `columns_written` ([UInt64](/ru/reference/data-types)) — Количество записанных столбцов (при Вертикальном слиянии).
* `memory_usage` ([UInt64](/ru/reference/data-types)) — Объём памяти, используемой процессом слияния.
* `thread_id` ([UInt64](/ru/reference/data-types)) — Идентификатор потока процесса слияния.
* `merge_type` ([String](/ru/reference/data-types)) — Тип текущего слияния. Пусто, если это мутация.
* `merge_algorithm` ([String](/ru/reference/data-types)) — Алгоритм, используемый в текущем слиянии. Пусто, если это мутация.
