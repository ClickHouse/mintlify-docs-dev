<div id="description">
  ## Описание
</div>

Эта таблица содержит информацию о частях проекций таблиц семейства MergeTree.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `partition` ([String](/ru/reference/data-types)) — имя партиции.
* `name` ([String](/ru/reference/data-types)) — Имя части данных.
* `part_type` ([String](/ru/reference/data-types)) — Формат хранения части данных. Возможные значения: Wide (отдельный файл для каждого столбца) и Compact (один файл для всех столбцов).
* `parent_name` ([String](/ru/reference/data-types)) — Имя исходной (родительской) части данных.
* `parent_uuid` ([UUID](/ru/reference/data-types)) — UUID исходной (родительской) части данных.
* `parent_part_type` ([String](/ru/reference/data-types)) — Формат хранения родительской (исходной) части данных.
* `active` ([UInt8](/ru/reference/data-types)) — Флаг, указывающий, активна ли часть данных. Если часть данных активна, она используется в таблице. В противном случае она скоро будет удалена. Неактивные части данных появляются после операций слияния и мутации.
* `marks` ([UInt64](/ru/reference/data-types)) — Количество marks. Чтобы получить приблизительное число строк в data part, умножьте количество marks на гранулярность индекса (обычно 8192) (эта оценка не работает для адаптивной гранулярности).
* `rows` ([UInt64](/ru/reference/data-types)) — количество строк.
* `bytes_on_disk` ([UInt64](/ru/reference/data-types)) — Суммарный размер в байтах всех файлов частей данных.
* `data_compressed_bytes` ([UInt64](/ru/reference/data-types)) — Общий размер сжатых данных в части данных. Вспомогательные файлы (например, файлы marks) не учитываются.
* `data_uncompressed_bytes` ([UInt64](/ru/reference/data-types)) — Общий размер несжатых данных в части данных. Все вспомогательные файлы (например, файлы с метками) не учитываются.
* `marks_bytes` ([UInt64](/ru/reference/data-types)) — Размер файла с marks.
* `parent_marks` ([UInt64](/ru/reference/data-types)) — Количество меток в исходной (родительской) части.
* `parent_rows` ([UInt64](/ru/reference/data-types)) — Число строк в исходной (родительской) части.
* `parent_bytes_on_disk` ([UInt64](/ru/reference/data-types)) — Общий размер в байтах всех файлов исходных (родительских) частей данных.
* `parent_data_compressed_bytes` ([UInt64](/ru/reference/data-types)) — Общий размер сжатых данных в исходной (родительской) части данных.
* `parent_data_uncompressed_bytes` ([UInt64](/ru/reference/data-types)) — Общий размер несжатых данных в исходной (родительской) части данных.
* `parent_marks_bytes` ([UInt64](/ru/reference/data-types)) — Размер файла меток в исходной (родительской) части данных.
* `modification_time` ([DateTime](/ru/reference/data-types)) — Время изменения каталога, содержащего часть данных. Обычно соответствует времени создания части данных.
* `remove_time` ([DateTime](/ru/reference/data-types)) — Время, когда часть данных стала неактивной.
* `refcount` ([UInt32](/ru/reference/data-types)) — Количество мест, в которых используется часть данных. Значение больше 2 указывает на то, что часть данных используется в запросах или при слиянии.
* `min_date` ([Date](/ru/reference/data-types)) — Минимальное значение ключа даты в части данных.
* `max_date` ([Date](/ru/reference/data-types)) — Максимальное значение ключа даты в части данных.
* `min_time` ([DateTime](/ru/reference/data-types)) — минимальное значение ключа даты и времени в части данных.
* `max_time` ([DateTime](/ru/reference/data-types)) — максимальное значение ключа даты и времени в части данных.
* `partition_id` ([String](/ru/reference/data-types)) — идентификатор партиции.
* `min_block_number` ([Int64](/ru/reference/data-types)) — Минимальное количество частей данных, из которых состоит текущая часть после слияния.
* `max_block_number` ([Int64](/ru/reference/data-types)) — Максимальное количество частей данных, образующих текущую часть после слияния.
* `level` ([UInt32](/ru/reference/data-types)) — Глубина дерева слияния. Ноль означает, что текущая часть была создана в результате вставки, а не слияния других частей.
* `data_version` ([UInt64](/ru/reference/data-types)) — Число, используемое для определения того, какие мутации должны быть применены к части данных (мутации с версией выше, чем у data&#95;version).
* `primary_key_bytes_in_memory` ([UInt64](/ru/reference/data-types)) — Объем памяти (в байтах), используемый для хранения значений первичного ключа.
* `primary_key_bytes_in_memory_allocated` ([UInt64](/ru/reference/data-types)) — Объём памяти (в байтах), зарезервированный для значений первичного ключа.
* `is_frozen` ([UInt8](/ru/reference/data-types)) — Флаг, показывающий наличие резервной копии данных партиции. 1 — резервная копия существует. 0 — резервной копии нет.
* `database` ([String](/ru/reference/data-types)) — Название базы данных.
* `table` ([String](/ru/reference/data-types)) — Название таблицы.
* `engine` ([String](/ru/reference/data-types)) — Название движка таблицы без параметров.
* `disk_name` ([String](/ru/reference/data-types)) — Имя диска, на котором хранится часть данных.
* `path` ([String](/ru/reference/data-types)) — Абсолютный путь к каталогу с файлами data part.
* `hash_of_all_files` ([String](/ru/reference/data-types)) — хеш sipHash128 сжатых файлов.
* `hash_of_uncompressed_files` ([String](/ru/reference/data-types)) — sipHash128 несжатых файлов (файлов с marks, индексного файла и т. д.).
* `uncompressed_hash_of_compressed_files` ([String](/ru/reference/data-types)) — sipHash128 данных в сжатых файлах, как если бы они были в несжатом виде.
* `delete_ttl_info_min` ([DateTime](/ru/reference/data-types)) — Минимальное значение ключа даты и времени для правила DELETE в TTL.
* `delete_ttl_info_max` ([DateTime](/ru/reference/data-types)) — Максимальное значение ключа даты и времени в правиле TTL DELETE.
* `move_ttl_info.expression` ([Array(String)](/ru/reference/data-types)) — Массив выражений. Каждое выражение задаёт правило TTL MOVE.
* `move_ttl_info.min` ([Array(DateTime)](/ru/reference/data-types)) — Массив значений даты и времени. Каждый элемент задаёт минимальное значение ключа для правила TTL MOVE.
* `move_ttl_info.max` ([Array(DateTime)](/ru/reference/data-types)) — Массив значений даты и времени. Каждый элемент описывает максимальное значение ключа для правила TTL MOVE.
* `default_compression_codec` ([String](/ru/reference/data-types)) — имя кодека, используемого для сжатия этой части данных (если для столбцов не задан явный кодек).
* `recompression_ttl_info.expression` ([Array(String)](/ru/reference/data-types)) — выражение TTL.
* `recompression_ttl_info.min` ([Array(DateTime)](/ru/reference/data-types)) — Минимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы определить, есть ли хотя бы одна строка с истёкшим TTL.
* `recompression_ttl_info.max` ([Array(DateTime)](/ru/reference/data-types)) — Максимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы понять, все ли строки с истекшим TTL присутствуют в этой части.
* `group_by_ttl_info.expression` ([Array(String)](/ru/reference/data-types)) — TTL-выражение.
* `group_by_ttl_info.min` ([Array(DateTime)](/ru/reference/data-types)) — Минимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы определить, есть ли в ней хотя бы одна строка с истекшим TTL.
* `group_by_ttl_info.max` ([Array(DateTime)](/ru/reference/data-types)) — Максимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы понять, включает ли она все строки с истёкшим TTL.
* `rows_where_ttl_info.expression` ([Array(String)](/ru/reference/data-types)) — TTL-выражение.
* `rows_where_ttl_info.min` ([Array(DateTime)](/ru/reference/data-types)) — Минимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы определить, есть ли здесь хотя бы одна строка с истёкшим TTL.
* `rows_where_ttl_info.max` ([Array(DateTime)](/ru/reference/data-types)) — Максимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы понять, все ли строки с истёкшим TTL у нас есть.
* `is_broken` ([UInt8](/ru/reference/data-types)) — Повреждена ли часть проекции
* `exception_code` ([Int32](/ru/reference/data-types)) — Сообщение об ошибке, объясняющее некорректное состояние части проекции
* `exception` ([String](/ru/reference/data-types)) — Код исключения, объясняющий повреждённое состояние части проекции
