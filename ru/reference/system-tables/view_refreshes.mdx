<div id="description">
  ## Описание
</div>

Информация о [Refreshable Materialized View](/ru/reference/statements/create/view#refreshable-materialized-view). Содержит все refreshable materialized view, независимо от того, выполняется ли сейчас обновление или нет.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ru/reference/data-types)) — Имя базы данных, в которой находится таблица.
* `view` ([String](/ru/reference/data-types)) — Имя таблицы.
* `uuid` ([UUID](/ru/reference/data-types)) — UUID таблицы (база данных Atomic).
* `status` ([String](/ru/reference/data-types)) — Текущее состояние обновления.
* `last_success_time` ([Nullable(DateTime)](/ru/reference/data-types)) — Время, когда началось последнее успешное обновление. NULL, если с момента запуска сервера или создания таблицы успешных обновлений не было.
* `last_success_duration_ms` ([Nullable(UInt64)](/ru/reference/data-types)) — Сколько длилось последнее обновление.
* `last_refresh_time` ([Nullable(DateTime)](/ru/reference/data-types)) — Время, когда последняя попытка обновления завершилась (если известно) или началась (если неизвестно или всё ещё выполняется). NULL, если с момента запуска сервера или создания таблицы попыток обновления не было.
* `last_refresh_replica` ([String](/ru/reference/data-types)) — Если координация включена, имя реплики, выполнившей текущую (если она выполняется) или предыдущую (если не выполняется) попытку обновления.
* `next_refresh_time` ([Nullable(DateTime)](/ru/reference/data-types)) — Время, на которое запланирован запуск следующего обновления, если status = Scheduled.
* `exception` ([String](/ru/reference/data-types)) — Сообщение об ошибке из предыдущей попытки, если она завершилась неудачей.
* `retry` ([UInt64](/ru/reference/data-types)) — Сколько неудачных попыток уже было для текущего обновления. Недоступно, если status равен `RunningOnAnotherReplica`.
* `progress` ([Nullable(Float64)](/ru/reference/data-types)) — Прогресс текущего выполняющегося или последнего завершённого обновления на данной реплике, от 0 до 1. NULL, если status равен `RunningOnAnotherReplica` или обновление не выполняется.
* `read_rows` ([Nullable(UInt64)](/ru/reference/data-types)) — Количество строк, прочитанных текущим выполняющимся или последним завершённым обновлением на данной реплике. NULL, если status равен `RunningOnAnotherReplica`.
* `read_bytes` ([Nullable(UInt64)](/ru/reference/data-types)) — Количество байтов, прочитанных текущим выполняющимся или последним завершённым обновлением на данной реплике. NULL, если status равен `RunningOnAnotherReplica`
* `total_rows` ([Nullable(UInt64)](/ru/reference/data-types)) — Оценочное общее количество строк, которые должны быть прочитаны текущим выполняющимся или последним завершённым обновлением на данной реплике. NULL, если status равен `RunningOnAnotherReplica`
* `written_rows` ([Nullable(UInt64)](/ru/reference/data-types)) — Количество строк, записанных текущим выполняющимся или последним завершённым обновлением на данной реплике. NULL, если status равен `RunningOnAnotherReplica`
* `written_bytes` ([Nullable(UInt64)](/ru/reference/data-types)) — Количество байтов, записанных текущим выполняющимся или последним завершённым обновлением на данной реплике. NULL, если status равен `RunningOnAnotherReplica`

{/*AUTOGENERATED_END*/}

  ## Пример
</div>

```sql
SELECT
    database,
    view,
    status,
    last_refresh_result,
    last_refresh_time,
    next_refresh_time
FROM system.view_refreshes

┌─database─┬─view───────────────────────┬─status────┬─last_refresh_result─┬───last_refresh_time─┬───next_refresh_time─┐
│ default  │ hello_documentation_reader │ Scheduled │ Finished            │ 2023-12-01 01:24:00 │ 2023-12-01 01:25:00 │
└──────────┴────────────────────────────┴───────────┴─────────────────────┴─────────────────────┴─────────────────────┘
```
