Позволяет выполнять запросы к данным, предоставляемым сервером [Apache Arrow Flight](/ru/concepts/features/interfaces/arrowflight).

**Синтаксис**

```sql
arrowFlight('host:port', 'dataset_name' [, 'username', 'password'])
```

**Аргументы**

* `host:port` — Адрес сервера Arrow Flight. [String](/ru/reference/data-types/string).
* `dataset_name` — Имя набора данных или дескриптора, доступного на сервере Arrow Flight. [String](/ru/reference/data-types/string).
* `username` - Имя пользователя для HTTP-аутентификации basic.
* `password` - Пароль для HTTP-аутентификации basic.
  Если `username` и `password` не указаны, это означает, что аутентификация не используется
  (это будет работать, только если сервер Arrow Flight это допускает).

**Возвращаемое значение**

* Объект таблицы, представляющий удалённый набор данных. Схема определяется по ответу Arrow Flight.

**Пример**

```sql title="Query"
SELECT * FROM arrowFlight('127.0.0.1:9005', 'sample_dataset') ORDER BY id;
```

```text title="Response"
┌─id─┬─name────┬─value─┐
│  1 │ foo     │ 42.1  │
│  2 │ bar     │ 13.3  │
│  3 │ baz     │ 77.0  │
└────┴─────────┴───────┘
```
