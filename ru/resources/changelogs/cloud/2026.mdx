<div id="clickstack-cloud">
  ### ClickStack Cloud: закрытая предварительная версия
</div>

ClickStack Cloud — это полностью управляемая бессерверная платформа обсервабилити, созданная на базе ClickHouse Cloud. Команды могут отправлять данные OpenTelemetry в управляемую конечную точку и сразу изучать журналы, метрики и трейсы без развертывания и эксплуатации инфраструктуры обсервабилити. Сейчас сервис доступен в закрытой предварительной версии в AWS us-east-1. Подробнее читайте в [посте блога](https://clickhouse.com/blog/clickstack-cloud-private-preview) и записывайтесь в [список ожидания](https://clickhouse.com/cloud/clickstack-cloud-waitlist), чтобы получить доступ.

<div id="ai-notebooks-clickstack">
  ### ИИ-блокноты для Управляемого ClickStack (бета)
</div>

ИИ-блокноты теперь доступны в бета-версии для Управляемого ClickStack и предоставляют SRE-специалистам и инженерным командам сохраняемые, прозрачные рабочие пространства для расследования инцидентов с помощью ИИ. Блокноты поддерживают структурированные последовательности промптов, запросов, графиков, этапов рассуждения и выводов, а также ветвящиеся рабочие процессы для проверки нескольких гипотез. Подробнее см. в [документации](/ru/clickstack/notebooks).

<div id="clickstack-mcp-server">
  ### ClickStack MCP Server
</div>

Новый ClickStack MCP Server с открытым исходным кодом предоставляет внешним ИИ-агентам структурированные инструменты для расследований в области обсервабилити на базе ClickStack и ClickHouse. Он предоставляет семантические примитивы расследования для журналов, метрик и трейсов, а также двунаправленные примитивы оркестрации для создания панелей мониторинга, сохранения поисковых запросов и настройки оповещений. Подробнее см. в [документации](/ru/clickstack/mcp) и [публикации в блоге](https://clickhouse.com/blog/observability-mcp-server-ai-notebooks#clickstack-mcp-server).

<div id="executable-udfs">
  ### Исполняемые UDF (публичная бета)
</div>

Исполняемые UDF теперь доступны в ClickHouse Cloud в рамках публичной беты. Вы можете написать функцию на Python, загрузить ее в свой кластер и вызывать из SQL как любую встроенную функцию. ClickHouse запускает пул долгоживущих изолированных процессов в песочнице и пропускает через них строки со скоростью выполнения запросов, поэтому вы можете использовать свою функцию везде, где работает SQL, — в ad-hoc-запросах, JOIN и даже в materialized view, которые срабатывают при каждой вставке. Подробнее см. в [блоге с анонсом](https://clickhouse.com/blog/executable-udfs-clickhouse-cloud-beta).

<div id="clickpipes-gcp-native">
  ### ClickPipes работает нативно в GCP
</div>

Инфраструктура ClickPipes теперь работает нативно в GCP для всех новых сервисов ClickHouse Cloud, размещённых в GCP (созданных после 26 мая), включая поддержку Private Service Connect (PSC). Это исключает расходы на межоблачный исходящий трафик, позволяет использовать нативные механизмы приватного сетевого взаимодействия GCP, снижает задержки и обеспечивает гарантии локальности данных. См. [список поддерживаемых регионов GCP](/ru/integrations/clickpipes#list-of-static-ips).

<div id="clickpipes-pubsub">
  ### ClickPipes для GCP Pub/Sub (закрытая предварительная версия)
</div>

ClickPipes теперь поддерживает стриминг данных из топиков GCP Pub/Sub напрямую в ClickHouse Cloud. Функция доступна в рамках закрытой предварительной версии — [зарегистрируйтесь](https://clickhouse.com/cloud/clickpipes#pubsub-private-preview), чтобы получить доступ. Подробнее см. в [документации](/ru/integrations/clickpipes/pubsub).

<div id="clickhouse-agents">
  ### ClickHouse Agents — агентная аналитика (публичная бета)
</div>

ClickHouse Agents теперь доступен в публичной бете — это собственное решение ClickHouse для агентной аналитики на базе Claude, которое позволяет пользователям создавать, запускать и оркестрировать агентов для работы с данными в ClickHouse. Среди возможностей — диалоговый анализ с учетом схемы данных, AgentBuilder с поддержкой MCP, топологии субагентов и генерация кода. Доступно на [ai.clickhouse.cloud](https://ai.clickhouse.cloud).

<div id="clickhouse-postgres">
  ### ClickHouse Postgres (публичная бета)
</div>

Полностью управляемый Postgres на локальном NVMe-хранилище теперь доступен в публичной бете и обеспечивает более чем в 5 раз больше TPS, чем AWS RDS. Нативный конвейер CDC передает данные напрямую в ClickHouse без промежуточной инфраструктуры. Расширение с открытым исходным кодом `pg_clickhouse` позволяет разработчикам отправлять запросы к таблицам ClickHouse из стандартных сеансов Postgres. Подробнее читайте в [статье в блоге](https://clickhouse.com/blog/postgres-managed-by-clickhouse-beta).

  ### Горизонтальное автомасштабирование (закрытая предварительная версия)

<div id="postgres-query-insights">
  ### Postgres Query Insights (закрытая предварительная версия)
</div>

Новая вкладка **Query Insights** теперь доступна в [ClickHouse Cloud Managed Postgres](/ru/products/managed-postgres/overview) (закрытая предварительная версия). Она ранжирует каждый шаблон запроса по степени влияния и показывает, почему каждый из них выполняется медленно, в трёх представлениях:

* **Обзор** — общее состояние базы данных на одном экране
* **Шаблоны** — таблица, которую можно сортировать по времени выполнения, CPU, ошибкам и P95
* **Выдвижная панель шаблона** — перцентили задержки, CPU в сравнении с I/O, кэш в сравнении с диском, сбросы временных данных на диск, нехватка параллельных воркеров и объём WAL

Работает на базе [pg&#95;stat&#95;ch](https://github.com/ClickHouse/pg_stat_ch), Postgres-расширения с открытым исходным кодом.

<div id="centralized-marketplace-billing">
  ### Централизованная оплата через маркетплейс
</div>

Теперь клиенты могут консолидировать биллинг между организациями через одну подписку через облачный маркетплейс (AWS, Azure и GCP). Основные изменения:

* **Общий доступ к подписке через маркетплейс:** Переведите организацию с оплаты кредитной картой на существующую подписку через маркетплейс другой организации, чтобы не оформлять дополнительную подписку через маркетплейс. Консолидируется только использование по модели PAYG (предоплаченные кредиты не включаются).
* **Обновление подписок через маркетплейс:** Переключите организацию на подписку через маркетплейс, используемую другой организацией.
* **Резервный способ оплаты:** Организации, использующие оплату через маркетплейс, теперь могут добавить кредитную карту в качестве резервного способа оплаты, если основная подписка через маркетплейс отменена или истекла.

Подробнее см. в [документации по биллингу](/ru/products/cloud/reference/billing/managing-payment-methods).

<div id="april-3-2026">
  ## 3 апреля 2026 г.
</div>

* **Более интеллектуальное автомасштабирование с двухоконным рекомендателем:** ClickHouse Cloud теперь использует для вертикального автомасштабирования подход с двумя окнами анализа прошлой нагрузки: вместо прежнего единственного 30-часового окна применяются 3-часовое «малое окно» и 30-часовое «большое окно». Это сокращает задержку scale-down с 30 часов до всего 3 часов, снижая затраты на инфраструктуру для переменных рабочих нагрузок без ущерба для скорости scale-up. Подробнее читайте в [публикации блога](https://clickhouse.com/blog/smarter-auto-scaling).
* **Monitoring в консоли Cloud:** Новые обзорные и инфраструктурные панели дают лучшее представление о поведении серверов ClickHouse. Пользователи с ролью Admin теперь получают уведомления по электронной почте о распространенных проблемах при использовании ClickHouse Cloud. Подробнее читайте в [публикации блога](https://clickhouse.com/blog/clickhouse-cloud-new-monitoring-capabilities).
* **Compute-compute separation (хранилища):** Поддержка auto-idling для основных сервисов (также называемых родительскими сервисами) постепенно становится доступной в рамках публичного предварительного просмотра. Если эта возможность еще не включена для вашей организации, [обратитесь в службу поддержки](https://clickhouse.com/support/program), чтобы получить доступ. После выхода этой возможности в общую доступность поведение по умолчанию будет таким: для существующих основных сервисов можно будет включить auto-idling, а для новых основных сервисов он будет включен по умолчанию.
* **Интеграция с каталогом данных:** ClickHouse Cloud теперь поддерживает Iceberg REST Catalog и Microsoft OneLake как интеграции с каталогами озер данных в интерфейсе источников данных. После подключения каталог отображается как база данных, что позволяет читать таблицы Iceberg напрямую, без дублирования данных.
* **Собственное облако (BYOC) на GCP теперь общедоступно:** ClickHouse BYOC теперь общедоступен в Google Cloud, что позволяет развертывать сервисы ClickHouse в вашем собственном проекте GCP и соблюдать строгие требования к резидентности данных. Подробнее читайте в [документации](/ru/products/cloud/guides/infrastructure/deployment-options/byoc/overview) и [публикации блога](https://clickhouse.com/blog/byoc-gcp-ga). Вы можете [связаться с нами](https://clickhouse.com/cloud/bring-your-own-cloud), чтобы запросить доступ.
* **Уведомления о биллинге для предоплаченных кредитов и изменениях способа оплаты:** ClickHouse Cloud теперь отправляет уведомления, когда в вашу организацию добавляются предоплаченные кредиты в рамках контракта с обязательствами или когда обновляется способ оплаты (кредитная карта или подписка через маркетплейс). По умолчанию уведомления включены в интерфейсе и по электронной почте, а при необходимости их также можно настроить для отправки в Slack.
