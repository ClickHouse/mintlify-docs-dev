<div id="migration">
  # Миграция
</div>

Одноразовые инструменты и данные, использованные для переноса документации ClickHouse из Docusaurus
в Mintlify. **Всю эту папку можно удалить после завершения миграции** —
на рабочем сайте от неё ничего не зависит.

<div id="contents">
  ## Содержимое
</div>

* `slug-map.csv` — соответствие каждого Docusaurus slug → файлу/URL в Mintlify, с
  исходными/перенесёнными хешами для отслеживания устаревания.
* `slug-aliases.csv` — проверенные вручную псевдонимы для slug, которые не удалось
  сопоставить автоматически.
* `migrate.py` — основной скрипт миграции. Читает `slug-map.csv`, применяет
  необходимые для Mintlify преобразования, записывает результат.
* `generate-slug-map.py` — заново генерирует `slug-map.csv` из исходного Docusaurus
  * текущей структуры этого репозитория.
* `apply-slug-aliases.py` — переписывает маркеры `<!-- MIGRATE: unknown slug -->`
  с использованием `slug-aliases.csv`.
* `suggest-slug-aliases.py` — предлагает кандидаты в псевдонимы для неразрешённых slug.
* `match_slugless.py` — находит страницы Mintlify без соответствующего slug в исходном Docusaurus.
* `verify_mapping.py` — проверяет карту соответствий slug на предмет дубликатов/расхождений.
* `find_dup_imports.py` — обнаруживает конфликты импортов в MDX, вызванные тем, что Mintlify
  поднимает импорт сниппетов в родительский bundle.

См. `.claude/skills/migrate-docusaurus-to-mintlify/SKILL.md` для
описания рабочего процесса миграции.
