Common pandas patterns and their DataStore equivalents. Most code works unchanged!

## Data Loading <a id="loading"></a>

### Read CSV <a id="read-csv"></a>

```python
# Pandas
import pandas as pd
df = pd.read_csv("data.csv")

# DataStore - same!
from chdb import datastore as pd
df = pd.read_csv("data.csv")
```

### Read Multiple Files <a id="read-multiple-files"></a>

```python
# Pandas
import glob
dfs = [pd.read_csv(f) for f in glob.glob("data/*.csv")]
df = pd.concat(dfs)

# DataStore - more efficient with glob pattern
df = pd.read_csv("data/*.csv")
```

## Filtering <a id="filtering"></a>

### Single Condition <a id="single-condition"></a>

```python
# Pandas and DataStore - identical
df[df['age'] > 25]
df[df['city'] == 'NYC']
df[df['name'].str.contains('John')]
```

### Multiple Conditions <a id="multiple-conditions"></a>

```python
# AND
df[(df['age'] > 25) & (df['city'] == 'NYC')]

# OR
df[(df['age'] < 18) | (df['age'] > 65)]

# NOT
df[~(df['status'] == 'inactive')]
```

### Using query() <a id="using-query"></a>

```python
# Pandas and DataStore - identical
df.query('age > 25 and city == "NYC"')
df.query('salary > 50000')
```

### isin() <a id="isin"></a>

```python
# Pandas and DataStore - identical
df[df['city'].isin(['NYC', 'LA', 'SF'])]
```

### between() <a id="between"></a>

```python
# Pandas and DataStore - identical
df[df['age'].between(18, 65)]
```

## GroupBy and Aggregation <a id="groupby"></a>

### Simple GroupBy <a id="simple-groupby"></a>

```python
# Pandas and DataStore - identical
df.groupby('city')['salary'].mean()
df.groupby('city')['salary'].sum()
df.groupby('city').size()  # count
```

### Multiple Aggregations <a id="multiple-aggregations"></a>

```python
# Pandas and DataStore - identical
df.groupby('city')['salary'].agg(['sum', 'mean', 'count'])

df.groupby('city').agg({
    'salary': ['sum', 'mean'],
    'age': ['min', 'max']
})
```

### Named Aggregations <a id="named-aggregations"></a>

```python
# Pandas and DataStore - identical
df.groupby('city').agg(
    total_salary=('salary', 'sum'),
    avg_salary=('salary', 'mean'),
    employee_count=('id', 'count')
)
```

### Multiple GroupBy Keys <a id="multiple-groupby-keys"></a>

```python
# Pandas and DataStore - identical
df.groupby(['city', 'department'])['salary'].mean()
```

## Joining Data <a id="joining"></a>

### Inner Join <a id="inner-join"></a>

```python
# Pandas
pd.merge(df1, df2, on='id')

# DataStore - same API
pd.merge(df1, df2, on='id')

# DataStore also supports
df1.join(df2, on='id')
```

### Left Join <a id="left-join"></a>

```python
# Pandas and DataStore - identical
pd.merge(df1, df2, on='id', how='left')
```

### Join on Different Columns <a id="join-on-different-columns"></a>

```python
# Pandas and DataStore - identical
pd.merge(df1, df2, left_on='emp_id', right_on='id')
```

### Concat <a id="concat"></a>

```python
# Pandas and DataStore - identical
pd.concat([df1, df2, df3])
pd.concat([df1, df2], axis=1)
```

## Creating New Columns <a id="new-columns"></a>

### Simple Assignment <a id="simple-assignment"></a>

```python
# Pandas and DataStore - identical
df['total'] = df['price'] * df['quantity']
df['age_group'] = df['age'] // 10 * 10
```

### Using assign() <a id="using-assign"></a>

```python
# Pandas and DataStore - identical
df = df.assign(
    total=df['price'] * df['quantity'],
    is_adult=df['age'] >= 18
)
```

### Conditional (where/mask) <a id="conditional-where-mask"></a>

```python
# Pandas and DataStore - identical
df['status'] = df['age'].where(df['age'] >= 18, 'minor')
```

### apply() for Custom Logic <a id="apply-for-custom-logic"></a>

```python
# Works, but triggers pandas execution
df['category'] = df['amount'].apply(lambda x: 'high' if x > 1000 else 'low')

# DataStore alternative (stays lazy)
df['category'] = (
    df.when(df['amount'] > 1000, 'high')
      .otherwise('low')
)
```

## Window Functions <a id="window"></a>

### Rolling <a id="rolling"></a>

```python
# Pandas and DataStore - identical

```

### Expanding <a id="expanding"></a>

```python
# Pandas and DataStore - identical
df['cumsum'] = df['amount'].expanding().sum()
df['cummax'] = df['amount'].expanding().max()
```

### Shift <a id="shift"></a>

```python
# Pandas and DataStore - identical
df['prev_value'] = df['value'].shift(1)   # Lag
df['next_value'] = df['value'].shift(-1)  # Lead
```

### Diff <a id="diff"></a>

```python
# Pandas and DataStore - identical
```
