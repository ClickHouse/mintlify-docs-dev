The ClickHouse MCP server is the **open-standard access layer** of the stack — it exposes ClickHouse to the chat front-end over the Model Context Protocol so the agent can explore your data and run read-only queries against it.

In the bundled stack, the open-source server exposes three tools to the agent:

- **List databases** — enumerate the databases in the connected ClickHouse instance.
- **List tables** — inspect the tables and their schemas within a database.
- **Run SELECT queries** — execute read-only queries and return the results.

This page explains the role the bundled MCP server plays in the stack. It does not re-document the server itself:

- Full MCP integration catalog (clients + agent-library guides): [MCP guides](/core/guides/use-cases/ai-ml/MCP)
- Source and configuration: [github.com/ClickHouse/mcp-clickhouse](https://github.com/ClickHouse/mcp-clickhouse)

<Info>
**Prefer a managed MCP server?** ClickHouse Cloud offers a fully managed [Remote MCP server](/cloud/features/ai-ml/remote-mcp) — zero install, OAuth authentication, and a richer tool set that adds management operations (services, billing, ClickPipes, backups) on top of the read-only tools above. See its [comparison with the open-source server](/cloud/features/ai-ml/remote-mcp#remote-vs-oss).
</Info>
