LibreChat is the **chat and agent front-end** of the stack — the interface where users talk to their data. This page covers LibreChat's role within the bundle and points to the integrated [Docker setup](/products/agentic-data-stack/docker-setup).

For the standalone "LibreChat + ClickHouse MCP" integration guide (outside the bundle), see the canonical guide: [Using ClickHouse MCP server with LibreChat](/core/guides/use-cases/ai-ml/MCP/librechat). For LibreChat's own feature documentation (agents, code interpreter, model selection, and more), see [librechat.ai](https://www.librechat.ai/docs).

<Info>
**Prefer a managed experience?** ClickHouse Cloud offers [ClickHouse Agents](/cloud/features/ai-ml/agents) (Beta) — a hosted, no-setup agent experience built on the same foundation, with the agent-building features available through the Cloud console.
</Info>
