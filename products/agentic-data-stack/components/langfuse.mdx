Langfuse is the **observability and tracing layer** of the stack — it captures agent workflows, tool calls, latency, and cost so you can see what the agent did and why.

This page covers Langfuse's role within the bundle and links to the canonical docs rather than duplicating them:

- Langfuse on ClickHouse overview: [Langfuse](/cloud/features/ai-ml/langfuse)
- Langfuse companion guide: [langfuse.com/integrations/agentic-data-stack](https://langfuse.com/integrations/agentic-data-stack)

<Info>
**Prefer a managed experience?** [Langfuse Cloud](https://cloud.langfuse.com) is a fully managed deployment powered by a managed ClickHouse cluster — no infrastructure to run.
</Info>
