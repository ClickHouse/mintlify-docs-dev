<Info>
  **Windows 사용자**

  ClickHouse는 Linux와 macOS에서 네이티브로 실행됩니다. Windows에서는
  [Windows Subsystem for Linux (WSL)](https://learn.microsoft.com/en-us/windows/wsl/about) 환경에서 다음 단계를 실행하십시오.
</Info>

ClickHouse CLI(`clickhousectl`)를 사용하면 로컬 ClickHouse 버전을 설치하고 관리하고,
서버를 실행하며 쿼리를 수행할 수 있습니다.

<Steps>
  <Step>
    ## ClickHouse CLI 설치

    ```bash
    curl https://clickhouse.com/cli | sh
    ```

    편의를 위해 `chctl` 별칭도 자동으로 생성됩니다.
  </Step>

  <Step>
    ## ClickHouse 설치

    ClickHouse의 최신 안정 버전을 설치합니다:

    ```bash
    clickhousectl local install stable
    ```

    특정 버전을 설치할 수도 있습니다:

    ```bash
    clickhousectl local install lts             # 최신 LTS 릴리스
    clickhousectl local install 25.6            # 최신 25.6.x.x
    clickhousectl local install 25.6.1.1        # 정확한 버전
    ```
  </Step>

  <Step>
    ## clickhouse-server 시작

    ```bash
    clickhousectl local server start
    ```

    서버는 백그라운드에서 실행됩니다. 실행 중인지 확인하려면 다음 명령을 사용하십시오:

    ```bash
    clickhousectl local server list
    ```
  </Step>

  <Step>
    ## clickhouse-client 시작

    ```bash
    clickhousectl local client
    ```

    다음과 비슷한 내용이 표시됩니다:

    ```response
    ClickHouse client version 24.5.1.117 (official build).
    Connecting to localhost:9000 as user default.
    Connected to ClickHouse server version 24.5.1.

    local-host :)
    ```

    이제 ClickHouse에 SQL 명령을 보낼 준비가 되었습니다!

    <Tip>
      [Quick Start](/ko/get-started/setup/install)에서는 테이블을 생성하고 데이터를 삽입하는 단계를 안내합니다.
    </Tip>
  </Step>
</Steps>
