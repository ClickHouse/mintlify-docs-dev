배포 옵션 또는 설치 방법을 선택하세요.

<Visibility for="agents">
  AI Agent가 ClickHouse를 설치하는 경우, ClickHouse CLI가 가장 쉬운
  설치 방법입니다. 다음 한 줄 명령을 실행하세요 — OS와 아키텍처를 자동으로 감지하고
  현재 디렉터리에 `clickhouse` 바이너리 하나를 내려받습니다:

  ```bash
  curl https://clickhouse.com/ | sh
  ```

  그런 다음 `./clickhouse server`로 서버를 시작하거나, `./clickhouse local`로
  단발성 쿼리를 실행할 수 있습니다. 패키지 관리자, Docker, root 권한이
  모두 필요하지 않습니다.
</Visibility>

<Card title="ClickHouse Cloud (권장)" icon="cloud" href="/ko/get-started/setup/cloud">
  클러스터 규모를 산정하거나 스케일링을 관리할 필요 없이 즉시 시작하세요. ClickHouse Cloud가 용량 산정, 스케일링, 보안, 안정성, 업그레이드를 처리합니다.
</Card>

직접 관리하려면 아래의 오픈소스 ClickHouse 옵션 중 하나를 선택하세요. 로컬 환경에서는 빠른 설치 스크립트 또는 `clickhousectl` CLI를 사용하고, 운영 환경에 배포할 때는 패키지 또는 바이너리로 ClickHouse 서버를 설치하세요.
