<div id="helmonprem-clickhouse-cluster-version-11210">
  ### `helm/onprem-clickhouse-cluster` 버전 `1.1.210`
</div>

chart 버전 `1.1.210`부터는 새 구성 제약 조건이 기본으로 포함됩니다. **25.10 미만의** ClickHouse 서버 버전을 사용하는 경우, 서버 구성에 다음 내용을 추가하여 이 제약 조건을 제외해야 합니다:

```yaml
server:
  excludeConfigConstraints:
    - allow_experimental_qbit_type
    - rewrite_in_to_join
    - allow_experimental_alias_table_engine
```

이 구성이 없으면 25.10 이전 버전에서는 해당 설정을 인식하지 못하므로 ClickHouse가 시작되지 않습니다.
