<div id="clickstack-cloud">
  ### ClickStack Cloud 비공개 프리뷰
</div>

ClickStack Cloud는 ClickHouse Cloud를 기반으로 구축된 완전관리형 서버리스 관측성 플랫폼입니다. 팀은 관리형 엔드포인트로 OpenTelemetry 데이터를 전송하고, 관측성 인프라를 직접 운영하지 않아도 로그, 메트릭, 트레이스를 즉시 살펴볼 수 있습니다. 현재 AWS us-east-1에서 비공개 프리뷰로 제공됩니다. 자세한 내용은 [블로그 게시물](https://clickhouse.com/blog/clickstack-cloud-private-preview)을 확인하시고, 이용하려면 [대기자 명단](https://clickhouse.com/cloud/clickstack-cloud-waitlist)에 등록하십시오.

<div id="ai-notebooks-clickstack">
  ### Managed ClickStack용 AI Notebooks (베타)
</div>

이제 Managed ClickStack에서 AI Notebooks를 베타로 사용할 수 있습니다. 이를 통해 SRE와 엔지니어링 팀은 AI 지원 인시던트 조사를 위한 지속적이고 투명한 워크스페이스를 활용할 수 있습니다. 노트북은 여러 가설을 탐색할 수 있도록 분기형 워크플로와 함께 프롬프트, 쿼리, 차트, 추론 단계, 조사 결과를 구조화된 순서로 지원합니다. 자세한 내용은 [문서](/ko/clickstack/notebooks)를 참조하십시오.

<div id="clickstack-mcp-server">
  ### ClickStack MCP Server
</div>

새로운 오픈소스 ClickStack MCP Server는 ClickStack과 ClickHouse를 기반으로 하는 구조화된 관측성 조사 도구를 외부 AI 에이전트에 제공합니다. 이 서버는 로그, 메트릭, 트레이스를 위한 의미론적 조사 프리미티브는 물론, 대시보드 생성, 검색 저장, 알림을 위한 양방향 오케스트레이션 프리미티브도 제공합니다. 자세한 내용은 [documentation](/ko/clickstack/mcp) 및 [blog post](https://clickhouse.com/blog/observability-mcp-server-ai-notebooks#clickstack-mcp-server)를 참조하십시오.

<div id="executable-udfs">
  ### Executable UDFs (공개 베타)
</div>

Executable UDFs는 이제 ClickHouse Cloud에서 공개 베타로 제공됩니다. Python으로 함수를 작성해 클러스터에 업로드한 뒤, 다른 기본 제공 함수처럼 SQL에서 호출할 수 있습니다. ClickHouse는 장시간 유지되는 샌드박스 프로세스 풀을 실행하고, 쿼리 속도로 행을 이 프로세스들에 전달하므로 SQL을 사용할 수 있는 곳이라면 어디서나 이 함수를 사용할 수 있습니다. 즉, ad-hoc 쿼리, 조인, 심지어 삽입이 발생할 때마다 실행되는 materialized view에서도 사용할 수 있습니다. 자세한 내용은 [발표 블로그](https://clickhouse.com/blog/executable-udfs-clickhouse-cloud-beta)를 참조하십시오.

<div id="clickpipes-gcp-native">
  ### ClickPipes는 GCP에서 네이티브로 실행됩니다
</div>

이제 ClickPipes 인프라는 GCP에서 호스팅되는 모든 신규 ClickHouse Cloud 서비스(5월 26일 이후 생성)에 대해 GCP에서 네이티브로 실행되며, Private Service Connect(PSC)도 지원합니다. 이를 통해 클라우드 간 egress 비용이 없어지고, GCP 네이티브 프라이빗 네트워킹을 사용할 수 있으며, 지연 시간이 줄어들고, 데이터 지역성이 보장됩니다. [지원되는 GCP 리전 목록](/ko/integrations/clickpipes#list-of-static-ips)을 참조하십시오.

<div id="clickpipes-pubsub">
  ### GCP Pub/Sub용 ClickPipes (비공개 프리뷰)
</div>

이제 ClickPipes는 GCP Pub/Sub 토픽의 데이터를 ClickHouse Cloud로 직접 스트리밍 수집할 수 있도록 지원합니다. 현재 비공개 프리뷰로 제공되며, 이용하려면 [신청](https://clickhouse.com/cloud/clickpipes#pubsub-private-preview)하십시오. 자세한 내용은 [문서](/ko/integrations/clickpipes/pubsub)를 참조하십시오.

<div id="clickhouse-agents">
  ### ClickHouse Agents — 에이전트 기반 분석 (공개 베타)
</div>

ClickHouse Agents가 이제 공개 베타로 제공됩니다. Claude로 구동되는 ClickHouse의 에이전트 기반 분석 인터페이스로, ClickHouse 데이터에 대해 에이전트를 구축하고 실행하며 오케스트레이션할 수 있습니다. 주요 기능으로는 스키마 인식 대화형 분석, MCP를 지원하는 AgentBuilder, 서브에이전트 토폴로지, 코드 생성이 있습니다. [ai.clickhouse.cloud](https://ai.clickhouse.cloud)에서 사용할 수 있습니다.

<div id="clickhouse-postgres">
  ### ClickHouse Postgres (공개 베타)
</div>

로컬 NVMe 스토리지를 사용하는 완전 관리형 Postgres가 이제 공개 베타로 제공되며, AWS RDS보다 TPS를 5배 이상 더 높게 제공합니다. 네이티브 CDC 파이프라인은 중간 인프라 없이 데이터를 ClickHouse로 직접 스트리밍합니다. 오픈소스 `pg_clickhouse` 확장 기능을 사용하면 개발자가 표준 Postgres 세션에서 ClickHouse 테이블을 쿼리할 수 있습니다. 자세한 내용은 [블로그 게시물](https://clickhouse.com/blog/postgres-managed-by-clickhouse-beta)을 참조하십시오.

<div id="postgres-query-insights">
  ### Postgres 쿼리 인사이트(비공개 프리뷰)
</div>

이제 [ClickHouse Cloud Managed Postgres](/ko/products/managed-postgres/overview)에서 새로운 **쿼리 인사이트** 탭을 사용할 수 있습니다(비공개 프리뷰). 이 탭은 모든 쿼리 패턴을 영향도순으로 정렬하고, 다음 3가지 화면에서 각 패턴이 느린 이유를 보여줍니다:

* **Overview** — 한 화면에서 보는 데이터베이스 상태
* **Patterns** — 런타임, CPU, 오류, P95를 기준으로 정렬할 수 있는 테이블
* **패턴별 flyout** — 지연 시간 백분위수, CPU 대비 I/O, 캐시 대비 디스크, 임시 spill, 병렬 워커 부족, WAL 볼륨

오픈 소스 Postgres 확장 기능인 [pg&#95;stat&#95;ch](https://github.com/ClickHouse/pg_stat_ch)로 구동됩니다.

<div id="centralized-marketplace-billing">
  ### 통합 마켓플레이스 청구
</div>

이제 고객은 단일 cloud marketplace subscription(AWS, Azure, GCP)을 통해 여러 조직의 청구를 통합할 수 있습니다. 주요 업데이트는 다음과 같습니다.

* **마켓플레이스 subscription 공유:** 조직의 청구 방식을 신용카드 청구에서 다른 조직의 기존 marketplace subscription으로 전환할 수 있으므로, 추가 marketplace subscription을 설정할 필요가 없습니다. PAYG 사용량만 통합되며 선불 크레딧은 포함되지 않습니다.
* **마켓플레이스 subscription 업데이트:** 조직의 marketplace subscription을 다른 조직에서 사용 중인 subscription으로 변경할 수 있습니다.
* **백업 결제 수단:** marketplace 청구를 사용하는 조직은 프라이머리 marketplace subscription이 취소되거나 만료될 경우를 대비한 폴백으로 이제 신용카드를 추가할 수 있습니다.

자세한 내용은 [청구 문서](/ko/products/cloud/reference/billing/managing-payment-methods)를 참조하십시오.

* **두 개의 윈도우를 사용하는 더 스마트한 자동 스케일링 추천기:** ClickHouse Cloud는 이제 수직 자동 스케일링에 이중 조회 기간 방식을 사용합니다. 기존의 단일 30시간 윈도우를 3시간 &quot;소형 윈도우&quot;와 30시간 &quot;대형 윈도우&quot;를 결합한 방식으로 대체했습니다. 이를 통해 축소 지연 시간을 최대 30시간에서 최소 3시간까지 줄여, 스케일 업 응답성은 유지하면서도 변동성이 큰 워크로드의 인프라 비용을 낮출 수 있습니다. 자세한 내용은 [블로그 게시물](https://clickhouse.com/blog/smarter-auto-scaling)을 참조하십시오.
* **Cloud Console의 모니터링:** 새로운 개요 및 인프라 대시보드를 통해 ClickHouse 서버의 동작을 더 잘 파악할 수 있습니다. 이제 관리자 사용자는 ClickHouse Cloud 사용 중 자주 발생하는 문제에 대한 이메일 알림을 받습니다. 자세한 내용은 [블로그 게시물](https://clickhouse.com/blog/clickhouse-cloud-new-monitoring-capabilities)을 참조하십시오.
* **컴퓨트-컴퓨트 분리 (warehouses):** 기본 서비스(부모 서비스라고도 함)의 자동 유휴 상태 전환 지원이 이제 공개 프리뷰로 순차적으로 제공되고 있습니다. 이 기능이 아직 조직에 활성화되지 않았다면 액세스 권한을 위해 [support에 문의하십시오](https://clickhouse.com/support/program). 이 기능이 일반 제공으로 전환되면, 기존 기본 서비스는 자동 유휴 상태 전환을 켤 수 있는 옵션이 제공되고 새 기본 서비스에는 기본적으로 이 기능이 활성화됩니다.
* **Data Catalog 통합:** ClickHouse Cloud는 이제 데이터 소스 UI에서 Iceberg REST 카탈로그와 Microsoft OneLake를 데이터 레이크 카탈로그 통합으로 지원합니다. 연결이 완료되면 카탈로그가 데이터베이스로 표시되므로 데이터를 복제하지 않고도 Iceberg 테이블을 직접 읽을 수 있습니다.
* **GCP의 Bring Your Own Cloud (BYOC)가 이제 일반 제공됩니다:** ClickHouse BYOC는 이제 Google Cloud에서 일반 제공되며, 이를 통해 자체 GCP 프로젝트에 ClickHouse 서비스를 배포하고 엄격한 데이터 상주 요구 사항을 준수할 수 있습니다. 자세한 내용은 [문서](/ko/products/cloud/guides/infrastructure/deployment-options/byoc/overview)와 [블로그 게시물](https://clickhouse.com/blog/byoc-gcp-ga)을 참조하십시오. 액세스를 요청하려면 [문의해 주십시오](https://clickhouse.com/cloud/bring-your-own-cloud).
* **선불 크레딧 추가 및 결제 수단 변경에 대한 청구 알림:** ClickHouse Cloud는 이제 약정 계약에 따라 조직에 선불 크레딧이 추가되거나 결제 수단(신용카드 또는 marketplace subscription)이 업데이트될 때 알림을 전송합니다. 알림은 기본적으로 UI와 이메일로 활성화되어 있으며, Slack으로도 전송되도록 구성할 수 있습니다.
