<div id="description">
  ## 설명
</div>

서버가 인식하고 있는 각 테이블의 메타데이터를 포함합니다.

[분리된](/ko/reference/statements/detach) 테이블은 `system.tables`에 표시되지 않습니다.

[임시 테이블](/ko/reference/statements/create/table#temporary-tables)은 생성된 세션에서만 `system.tables`에 표시됩니다. 이러한 테이블은 `database` 필드가 비어 있고 `is_temporary` 플래그가 켜진 상태로 표시됩니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ko/reference/data-types)) — 테이블이 속해 있는 데이터베이스의 이름입니다.
* `name` ([String](/ko/reference/data-types)) — 테이블 이름.
* `uuid` ([UUID](/ko/reference/data-types)) — 테이블 uuid (Atomic 데이터베이스).
* `engine` ([String](/ko/reference/data-types)) — 테이블 엔진 이름(매개변수 없음).
* `is_temporary` ([UInt8](/ko/reference/data-types)) — 테이블이 임시인지 나타내는 플래그입니다.
* `data_paths` ([Array(String)](/ko/reference/data-types)) — 파일 시스템에 있는 테이블 데이터의 경로입니다.
* `metadata_path` ([String](/ko/reference/data-types)) — 파일 시스템에 있는 테이블 메타데이터 경로입니다.
* `metadata_modification_time` ([DateTime](/ko/reference/data-types)) — 테이블 메타데이터의 최근 수정 시간입니다.
* `metadata_version` ([Int32](/ko/reference/data-types)) — ReplicatedMergeTree 테이블의 메타데이터 버전입니다. ReplicatedMergeTree 테이블이 아니면 0입니다.
* `dependencies_database` ([배열(String)](/ko/reference/data-types)) — 데이터베이스 종속성.
* `dependencies_table` ([Array(String)](/ko/reference/data-types)) — 테이블 종속성(현재 테이블의 materialized view 목록).
* `create_table_query` ([String](/ko/reference/data-types)) — 테이블을 생성할 때 사용된 쿼리입니다.
* `engine_full` ([String](/ko/reference/data-types)) — 테이블 엔진 매개변수입니다.
* `as_select` ([String](/ko/reference/data-types)) — 뷰용 SELECT 쿼리입니다.
* `parameterized_view_parameters` ([Array(Tuple(name String, type String))](/ko/reference/data-types)) — 매개변수화된 뷰의 매개변수입니다.
* `partition_key` ([String](/ko/reference/data-types)) — 테이블에 지정된 파티션 키 표현식입니다.
* `sorting_key` ([String](/ko/reference/data-types)) — 테이블에 지정된 정렬 키 표현식입니다.
* `primary_key` ([String](/ko/reference/data-types)) — 테이블에 지정된 기본 키 표현식입니다.
* `sampling_key` ([String](/ko/reference/data-types)) — 테이블에 지정된 샘플링 키 표현식입니다.
* `unique_key` ([String](/ko/reference/data-types)) — 테이블의 UNIQUE KEY 절에 지정된 고유 키 표현식입니다.
* `storage_policy` ([String](/ko/reference/data-types)) — 스토리지 정책입니다. MergeTree 및 분산 엔진을 사용하는 테이블에 적용됩니다.
* `total_rows` ([Nullable(UInt64)](/ko/reference/data-types)) — 총 행 수입니다. 테이블의 정확한 행 수를 빠르게 확인할 수 있으면 해당 값을 제공하고, 그렇지 않으면 NULL입니다(Buffer 테이블의 기반 테이블 포함).
* `total_bytes` ([Nullable(UInt64)](/ko/reference/data-types)) — 스토리지에서 테이블의 정확한 바이트 수를 빠르게 파악할 수 있으면 총 바이트 수를 반환하고, 그렇지 않으면 NULL을 반환합니다(하위 스토리지는 포함하지 않음). 테이블이 데이터를 디스크에 저장하는 경우 사용 중인 디스크 공간(즉, 압축된 크기)을 반환합니다. 테이블이 데이터를 메모리에 저장하는 경우 메모리에서 사용 중인 바이트 수의 근삿값을 반환합니다.
* `total_bytes_uncompressed` ([Nullable(UInt64)](/ko/reference/data-types)) — 스토리지의 테이블에 대한 part checksums에서 정확한 바이트 수를 빠르게 확인할 수 있는 경우 압축되지 않은 총 바이트 수이고, 그렇지 않으면 NULL입니다(기저 스토리지(있는 경우)는 고려하지 않음).
* `parts` ([Nullable(UInt64)](/ko/reference/data-types)) — 이 테이블에 있는 전체 파트 수입니다.
* `active_parts` ([Nullable(UInt64)](/ko/reference/data-types)) — 이 테이블의 활성 파트 수입니다.
* `total_marks` ([Nullable(UInt64)](/ko/reference/data-types)) — 이 테이블의 모든 파트에 있는 마크의 총개수입니다.
* `active_on_fly_data_mutations` ([UInt64](/ko/reference/data-types)) — 즉시 적용할 수 있는 활성 데이터 뮤테이션(UPDATE 및 DELETE)의 총개수입니다.
* `active_on_fly_alter_mutations` ([UInt64](/ko/reference/data-types)) — 즉시 적용 가능한 활성 ALTER 뮤테이션(MODIFY COLUMN)의 총 개수입니다.
* `active_on_fly_metadata_mutations` ([UInt64](/ko/reference/data-types)) — 즉시 적용 가능한 활성 메타데이터 뮤테이션(RENAME)의 총 개수입니다.
* `columns_descriptions_cache_size` ([UInt64](/ko/reference/data-types)) — *MergeTree 테이블의 컬럼 설명 캐시 크기
* `lifetime_rows` ([Nullable(UInt64)](/ko/reference/data-types)) — 서버 시작 이후 삽입된 총 행 수(Buffer 테이블에만 해당).
* `lifetime_bytes` ([Nullable(UInt64)](/ko/reference/data-types)) — 서버 시작 이후 삽입된 총 바이트 수(Buffer 테이블에만 해당).
* `comment` ([String](/ko/reference/data-types)) — 테이블에 대한 주석입니다.
* `has_own_data` ([UInt8](/ko/reference/data-types)) — 테이블 자체가 디스크에 일부 데이터를 저장하는지, 아니면 다른 데이터 원본만 참조하는지를 나타내는 플래그입니다.
* `loading_dependencies_database` ([Array(String)](/ko/reference/data-types)) — 데이터베이스 로드 종속성(현재 객체보다 먼저 로드되어야 하는 객체 목록).
* `loading_dependencies_table` ([Array(String)](/ko/reference/data-types)) — 테이블 로딩 종속성(현재 객체에 앞서 로드되어야 하는 객체 목록).
* `loading_dependent_database` ([Array(String)](/ko/reference/data-types)) — 종속 데이터베이스 로딩.
* `loading_dependent_table` ([Array(String)](/ko/reference/data-types)) — 종속 로딩 테이블.
* `definer` ([String](/ko/reference/data-types)) — 테이블에 사용되는 SQL security definer의 이름입니다.

{/*AUTOGENERATED_END*/}
