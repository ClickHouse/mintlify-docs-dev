<div id="migration">
  # 마이그레이션
</div>

Docusaurus에서 Mintlify로 ClickHouse 문서를 마이그레이션할 때 사용한 일회성 도구와 데이터입니다.
**마이그레이션이 완료되면 이 폴더 전체를 제거해도 됩니다** — 현재 운영 중인 사이트는 런타임에 이 폴더의 어떤 항목에도 의존하지 않습니다.

<div id="contents">
  ## 목차
</div>

* `slug-map.csv` — 모든 Docusaurus slug와 Mintlify 파일/URL의 대응표이며,
  staleness 추적을 위한 source/migrated 해시를 포함합니다.
* `slug-aliases.csv` — 자동으로 확인되지 않은 slug에 대해 수동 검토한
  별칭입니다.
* `migrate.py` — 기본 마이그레이션 스크립트입니다. `slug-map.csv`를 읽고,
  Mintlify에 필요한 변환을 적용한 뒤 결과를 출력합니다.
* `generate-slug-map.py` — upstream Docusaurus
  * 이 저장소의 현재 레이아웃을 기준으로 `slug-map.csv`를 다시 생성합니다.
* `apply-slug-aliases.py` — `<!-- MIGRATE: unknown slug -->` 표시를
  `slug-aliases.csv`를 사용해 재작성합니다.
* `suggest-slug-aliases.py` — 확인되지 않은 slug에 대한 별칭 후보를 제안합니다.
* `match_slugless.py` — upstream slug와 일치하는 항목이 없는 Mintlify 페이지를 찾습니다.
* `verify_mapping.py` — slug 맵의 중복/드리프트를 기본 점검합니다.
* `find_dup_imports.py` — Mintlify가 snippet import를 상위 bundle로
  끌어올리면서 발생하는 MDX import conflicts를 감지합니다.

마이그레이션 워크플로는 `.claude/skills/migrate-docusaurus-to-mintlify/SKILL.md`를
참조하십시오.
