[Notion](https://www.notion.com/)은 메모, 문서, 프로젝트, AI 기반 사용자 지정 에이전트를 위한 통합 워크스페이스입니다.

ClickHouse Cloud를 사용자 지정 MCP 서버로 Notion [사용자 지정 에이전트](https://www.notion.com/help/mcp-connections-for-custom-agents)에 연결할 수 있습니다. 연결되면 에이전트는 Notion 내에서 데이터를 탐색하고, 읽기 전용 분석 쿼리를 실행하며, ClickHouse Cloud의 서비스 및 비용 정보를 확인할 수 있습니다.

<div id="prerequisites">
  ## 필수 조건
</div>

* [원격 MCP 서버가 활성화된](/ko/products/cloud/features/ai-ml/mcp/remote-mcp#enable-remote-mcp-server) 상태로 실행 중인 [ClickHouse Cloud 서비스](/ko/get-started/setup/cloud)
* **Business** 또는 **Enterprise** 요금제의 Notion 워크스페이스
* 워크스페이스 관리자가 **설정** &gt; **Notion AI** &gt; **AI 커넥터**에서 **사용자 지정 MCP 서버**를 활성화해 두어야 합니다

<div id="connect-clickhouse-to-notion">
  ## ClickHouse를 Notion 사용자 지정 에이전트에 연결
</div>

1. Notion에서 확장할 사용자 지정 에이전트를 열고 **설정**을 클릭합니다.
2. **도구 &amp; 액세스** 아래에서 **연결 추가**를 클릭한 다음 **사용자 지정 MCP 서버**를 선택합니다.

{/* TODO(스크린샷): 에이전트의 Tools & Access 안에 있는 "Add connection" 메뉴에서 "Custom MCP server" 옵션이 표시된 상태 */}

3. ClickHouse Cloud 원격 MCP 서버 URL을 입력하고 연결 표시 이름을 `ClickHouse`와 같이 지정하세요:

   ```text
   https://mcp.clickhouse.cloud/mcp
   ```

{/* TODO(스크린샷): 서버 URL과 표시 이름이 입력되어 있는 Custom MCP server 모달 */}

4. **Save**를 클릭한 다음 OAuth 인증 절차를 완료하여 ClickHouse Cloud 자격 증명으로 인증하세요. 액세스 범위는 계정에서 이미 접근할 수 있는 조직과 서비스로 한정됩니다.

{/* TODO(screenshot): OAuth 동의 및 "연결됨" 확인 화면 */}

5. 새 연결 항목을 펼쳐 [사용 가능한 ClickHouse 도구](/ko/products/cloud/features/ai-ml/remote-mcp#available-tools)를 확인하고, 이 에이전트에서 사용할 도구를 사용 설정하십시오. 모든 ClickHouse Remote MCP 도구는 읽기 전용입니다.

{/* TODO(screenshot): 도구 토글 목록이 표시된 확장된 ClickHouse 연결 */}

<Note>
  각 사용자 지정 에이전트에는 전용 ClickHouse 연결이 필요하며, 연결 인증을 완료한 사용자만 해당 도구 설정을 변경할 수 있습니다. 자세한 내용은 Notion의 [에이전트 연결을 위한 보안 모범 사례](https://www.notion.com/help/security-best-practices-for-agent-connections)를 참조하십시오.
</Note>

<div id="example-prompts">
  ## 프롬프트 예시
</div>

연결한 후에는 사용자 지정 에이전트에 자연어로 질문할 수 있습니다. 몇 가지 예시는 다음과 같습니다.

| 프롬프트                                                   | 호출되는 도구                 |
| ------------------------------------------------------ | ----------------------- |
| &quot;내 ClickHouse 서비스에서 사용할 수 있는 데이터베이스는 무엇인가요?&quot; | `list_databases`        |
| &quot;`hits` 테이블의 상위 10개 행을 보여주세요&quot;                | `run_select_query`      |
| &quot;지난주 우리 조직의 ClickHouse 비용은 얼마였나요?&quot;           | `get_organization_cost` |
| &quot;이 서비스의 최근 백업을 나열해 주세요&quot;                      | `list_service_backups`  |

자연어 패턴과 도구의 전체 목록은 [Remote MCP example usage](/ko/products/cloud/features/ai-ml/mcp/remote-mcp#example-usage) 섹션을 참조하십시오.
