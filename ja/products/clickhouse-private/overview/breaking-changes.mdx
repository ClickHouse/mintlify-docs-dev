<div id="helmonprem-clickhouse-cluster-version-11210">
  ### `helm/onprem-clickhouse-cluster` version `1.1.210`
</div>

チャートバージョン `1.1.210` 以降では、新しい設定用の制約がデフォルトで含まれます。ClickHouse server のバージョンが **25.10 未満** の場合は、サーバー設定に以下を追加して、これらの制約を除外する必要があります。

```yaml
server:
  excludeConfigConstraints:
    - allow_experimental_qbit_type
    - rewrite_in_to_join
    - allow_experimental_alias_table_engine
```

この構成がないと、25.10 より前のバージョンではこれらの設定が認識されないため、ClickHouse は起動に失敗します。
