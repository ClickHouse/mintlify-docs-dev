[Notion](https://www.notion.com/) は、メモ、ドキュメント、プロジェクト、AI を活用したカスタムエージェントを一元的に扱えるワークスペースです。

ClickHouse Cloud をカスタムMCPサーバーとして Notion の [カスタムエージェント](https://www.notion.com/help/mcp-connections-for-custom-agents) に接続できます。接続すると、そのエージェントは Notion を離れることなく、データを探索し、読み取り専用の分析クエリを実行し、ClickHouse Cloud のサービス情報やコスト情報を表示できます。

<div id="prerequisites">
  ## 前提条件
</div>

* 稼働中の[ClickHouse Cloud サービス](/ja/get-started/setup/cloud)で、[Remote MCPサーバーが有効になっている](/ja/products/cloud/features/ai-ml/mcp/remote-mcp#enable-remote-mcp-server)
* **Business** または **Enterprise** プランの Notion ワークスペース
* ワークスペースの管理者が **設定** &gt; **Notion AI** &gt; **AI connectors** で **Custom MCP servers** を有効にしている

<div id="connect-clickhouse-to-notion">
  ## ClickHouseをNotionのカスタムエージェントに接続する
</div>

1. Notionで、拡張したいカスタムエージェントを開き、**設定**をクリックします。
2. **Tools &amp; Access**で、**接続を追加**をクリックし、**カスタムMCPサーバー**を選択します。

{/* TODO(screenshot): エージェントの [Tools & Access] 内の「接続を追加」メニューに「カスタムMCPサーバー」オプションが表示されている状態 */}

3. ClickHouse Cloud Remote MCPサーバーのURLを入力し、接続に `ClickHouse` などの表示名を付けます。

   ```text
   https://mcp.clickhouse.cloud/mcp
   ```

{/* TODO(screenshot): サーバーURLと表示名を入力したカスタムMCPサーバーのモーダル */}

4. Click **Save** をクリックし、OAuth フローを完了して ClickHouse Cloud の認証情報で認証します。アクセスできる範囲は、アカウントがすでにアクセス可能な organizations と service に限定されます。

{/* TODO(screenshot): OAuth の同意画面 / 「Connected」確認状態 */}

5. 新しい接続を展開し、[利用可能な ClickHouse ツール](/ja/products/cloud/features/ai-ml/remote-mcp#available-tools)を確認して、このエージェントで使用したいものを有効にします。ClickHouse Remote MCP ツールはすべて読み取り専用です。

{/* TODO(screenshot): ツールのトグル一覧が表示された、展開済みの ClickHouse 接続 */}

<Note>
  各カスタムエージェントにはそれぞれ専用の ClickHouse 接続が必要です。また、接続を認証した本人のみが、そのツール設定を変更できます。詳細については、Notion の[Agent 接続のセキュリティのベストプラクティス](https://www.notion.com/help/security-best-practices-for-agent-connections)を参照してください。
</Note>

<div id="example-prompts">
  ## プロンプトの例
</div>

接続が完了したら、カスタムエージェントに自然言語で質問できます。以下に例を示します。

| プロンプト                                                 | 呼び出されるツール               |
| ----------------------------------------------------- | ----------------------- |
| &quot;自分の ClickHouse service で利用できるデータベースは何ですか？&quot; | `list_databases`        |
| &quot;`hits` テーブルの先頭 10 行を表示してください&quot;              | `run_select_query`      |
| &quot;先週の組織の ClickHouse コストはいくらでしたか？&quot;            | `get_organization_cost` |
| &quot;この service の最近のバックアップを一覧表示してください&quot;          | `list_service_backups`  |

自然言語パターンとツールの完全な一覧については、[Remote MCP の使用例](/ja/products/cloud/features/ai-ml/mcp/remote-mcp#example-usage) を参照してください。
