デプロイ方法またはインストール方法を選択してください。

<Visibility for="agents">
  AI Agent として ClickHouse をインストールする場合は、ClickHouse CLI を使うのが最も簡単です。次のワンライナーを実行してください。OS とアーキテクチャを自動検出し、単一の `clickhouse` バイナリを現在のディレクトリに配置します。

  ```bash
  curl https://clickhouse.com/ | sh
  ```

  その後、`./clickhouse server` でサーバーを起動することも、`./clickhouse local` で単発のクエリを実行することもできます。パッケージマネージャー、Docker、root 権限は不要です。
</Visibility>

<Card title="ClickHouse Cloud（推奨）" icon="cloud" href="/ja/get-started/setup/cloud">
  クラスターのサイジングやスケーリングを気にすることなく、すぐに構築を始められます。ClickHouse Cloud が、サイジング、スケーリング、セキュリティ、信頼性、アップグレードを担います。
</Card>

自分で管理したい場合は、以下のオープンソースの ClickHouse オプションから選択してください。ローカル環境のセットアップにはクイックインストールスクリプトまたは `clickhousectl` CLI を使用し、本番環境へのデプロイにはパッケージまたはバイナリから ClickHouse Server をインストールしてください。
