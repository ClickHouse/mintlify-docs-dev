<div id="description">
  ## 説明
</div>

このテーブルには、即時に計算でき、Prometheus フォーマットでエクスポート可能なヒストグラムメトリクスが含まれています。内容は常に最新です。非推奨の `system.latency_log` を置き換えるものです。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `metric` ([String](/ja/reference/data-types)) — メトリック名。
* `value` ([Float64](/ja/reference/data-types)) — メトリック値。
* `description` ([String](/ja/reference/data-types)) — メトリックの説明。
* `labels` ([Map(String, String)](/ja/reference/data-types)) — メトリックのラベル。

{/*AUTOGENERATED_END*/}

<div id="example">
  ## 例
</div>

次のようなクエリを使用すると、すべてのヒストグラムメトリクスをPrometheusフォーマットでエクスポートできます。

```sql
SELECT
  metric AS name,
  toFloat64(value) AS value,
  description AS help,
  labels,
  'histogram' AS type
FROM system.histogram_metrics
FORMAT Prometheus
```
