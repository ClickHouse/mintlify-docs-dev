<div id="description">
  ## 説明
</div>

このシステムテーブルは、`SHOW PROCESSLIST` クエリの実装に使用されます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `is_initial_query` ([UInt8](/ja/reference/data-types)) — このクエリがユーザーから直接送信されたものか、または分散クエリ実行の過程で ClickHouse server によって発行されたものかを示します。
* `user` ([String](/ja/reference/data-types)) — クエリを実行したユーザーです。分散処理では、クエリはデフォルトユーザーとしてリモートサーバーに送信される点に注意してください。このフィールドには、特定のクエリのユーザー名が格納されます。そのクエリによって開始された別のクエリのユーザー名ではありません。
* `query_id` ([String](/ja/reference/data-types)) — 定義されている場合のクエリID。
* `address` ([IPv6](/ja/reference/data-types)) — クエリの送信元 IP アドレスです。分散処理でも同様です。分散クエリの元の送信元を追跡するには、クエリ要求元サーバー上の system.processes を参照してください。
* `port` ([UInt16](/ja/reference/data-types)) — クエリの送信元のクライアントポート。
* `initial_user` ([String](/ja/reference/data-types)) — 最初のクエリ (分散クエリ実行時) を実行したユーザー名。
* `initial_query_id` ([String](/ja/reference/data-types)) — 元のクエリの ID (分散クエリ実行時) 。
* `initial_address` ([IPv6](/ja/reference/data-types)) — 親クエリの送信元 IP アドレス。
* `initial_port` ([UInt16](/ja/reference/data-types)) — 親クエリの送信に使用されたクライアントポート。
* `interface` ([UInt8](/ja/reference/data-types)) — クエリの送信に使用されたインターフェイス。TCP = 1、HTTP = 2、GRPC = 3、MYSQL = 4、POSTGRESQL = 5、LOCAL = 6、TCP&#95;INTERSERVER = 7。
* `os_user` ([String](/ja/reference/data-types)) — `clickhouse-client` を実行するオペレーティングシステムのユーザー名
* `client_hostname` ([String](/ja/reference/data-types)) — `clickhouse-client` または別の TCP クライアントが実行されているクライアントマシンのホスト名。
* `client_name` ([String](/ja/reference/data-types)) — clickhouse-client またはその他の TCP クライアントの名前。
* `client_revision` ([UInt64](/ja/reference/data-types)) — clickhouse-client またはその他の TCP クライアントのリビジョン。
* `client_version_major` ([UInt64](/ja/reference/data-types)) — clickhouse-client または他の TCP クライアントのメジャーバージョン。
* `client_version_minor` ([UInt64](/ja/reference/data-types)) — clickhouse-client またはその他の TCP クライアントのマイナーバージョン。
* `client_version_patch` ([UInt64](/ja/reference/data-types)) — clickhouse-client または他の TCP クライアントのバージョンのパッチ部分。
* `http_method` ([UInt8](/ja/reference/data-types)) — クエリを開始した HTTP メソッド。設定可能な値: 0 — クエリは TCP インターフェイス経由で実行された。1 — GET メソッドが使用された。2 — POST メソッドが使用された。
* `http_user_agent` ([String](/ja/reference/data-types)) — HTTPクエリで渡されるHTTPヘッダーのUserAgent。
* `http_referer` ([String](/ja/reference/data-types)) — HTTPクエリで渡される HTTP ヘッダー Referer (クエリを実行したページの絶対アドレスまたは一部のアドレスを含みます) 。
* `forwarded_for` ([String](/ja/reference/data-types)) — HTTPクエリで渡される HTTP ヘッダー X-Forwarded-For。
* `quota_key` ([String](/ja/reference/data-types)) — `quotas` 設定で指定するクォータキー (keyed を参照) 。
* `distributed_depth` ([UInt64](/ja/reference/data-types)) — クエリが内部的にサーバーノード間で再送信された回数。
* `elapsed` ([Float64](/ja/reference/data-types)) — リクエストの実行開始からの経過時間 (秒) 。
* `is_cancelled` ([UInt8](/ja/reference/data-types)) — クエリがキャンセルされたかどうか。
* `is_all_data_sent` ([UInt8](/ja/reference/data-types)) — すべてのデータがクライアントに送信されたかどうか (つまり、サーバー上でクエリの実行が完了していたかどうか) 。
* `read_rows` ([UInt64](/ja/reference/data-types)) — テーブルから読み取られた行数。分散処理では、リクエスト元のサーバーでは、これはすべてのリモートサーバーの合計値です。
* `read_bytes` ([UInt64](/ja/reference/data-types)) — テーブルから読み取られた非圧縮バイト数。分散処理では、リクエスト元サーバーでは、これはすべてのリモートサーバーの合計値です。
* `total_rows_approx` ([UInt64](/ja/reference/data-types)) — 読み込まれるべき行の総数の概算値。分散処理では、リクエスト元のサーバー上では、これはすべてのリモートサーバー分を合計した値です。処理対象の新しいソースが判明した際に、リクエストの処理中に更新されることがあります。
* `written_rows` ([UInt64](/ja/reference/data-types)) — ストレージに書き込まれた行数。
* `written_bytes` ([UInt64](/ja/reference/data-types)) — ストレージに書き込まれたバイト数。
* `memory_usage` ([Int64](/ja/reference/data-types)) — クエリが使用するRAM量。専用メモリの一部の種類は含まれない場合があります
* `peak_memory_usage` ([Int64](/ja/reference/data-types)) — 現在のメモリ使用量の最大値。
* `query` ([String](/ja/reference/data-types)) — クエリテキスト。INSERT の場合、挿入するデータは含まれません。
* `normalized_query_hash` ([UInt64](/ja/reference/data-types)) — リテラルの値のみが異なるクエリでは同一になる数値のハッシュ値。
* `query_kind` ([String](/ja/reference/data-types)) — クエリの種別 - SELECT、INSERT など。
* `thread_ids` ([Array(UInt64)](/ja/reference/data-types)) — このクエリの実行に関与したすべてのスレッドの識別子の一覧。
* `peak_threads_usage` ([UInt64](/ja/reference/data-types)) — クエリの実行中に同時に使用されたスレッド数の最大値。
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/ja/reference/data-types)) — このクエリで計算されたProfileEvents。
* `Settings` ([Map(LowCardinality(String), LowCardinality(String))](/ja/reference/data-types)) — 変更されたユーザーレベルの設定一覧。
* `current_database` ([String](/ja/reference/data-types)) — 現在のデータベース名。
* `is_internal` ([UInt8](/ja/reference/data-types)) — 内部的に実行される補助クエリかどうかを示します。

{/*AUTOGENERATED_END*/}
