<div id="description">
  ## 説明
</div>

サーバーでサポートされているデータベースエンジンの一覧です。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ja/reference/data-types)) — データベースエンジンの名前。

{/*AUTOGENERATED_END*/}

<div id="example">
  ## 例
</div>

```sql title="Query"
SELECT *
FROM system.database_engines
WHERE name IN ('Atomic', 'Lazy', 'Ordinary')
```

```text title="Response"
┌─name─────┐
│ Ordinary │
│ Atomic   │
│ Lazy     │
└──────────┘
```
