<div id="description">
  ## 説明
</div>

利用可能なすべての集約関数コンビネータの一覧です。これらは集約関数に適用でき、その動作を変更します。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ja/reference/data-types)) — コンビネータの名前。
* `is_internal` ([UInt8](/ja/reference/data-types)) — このコンビネータが内部利用専用かどうか。

{/*AUTOGENERATED_END*/}
