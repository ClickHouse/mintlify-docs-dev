<div id="description">
  ## 説明
</div>

リモートオブジェクトに対するファイルシステムキャッシュ内のすべてのエントリに関する情報が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `cache_name` ([String](/ja/reference/data-types)) — cache オブジェクトの名前。`SYSTEM DESCRIBE FILESYSTEM CACHE <name>`、`SYSTEM DROP FILESYSTEM CACHE <name>` コマンドで使用できます
* `cache_base_path` ([String](/ja/reference/data-types)) — すべての cache ファイル (`cache_name` で識別される cache) が保存されるベースディレクトリのパス。
* `cache_path` ([String](/ja/reference/data-types)) — 特定の cache ファイルのパス。ソースファイル内のファイルセグメントに対応します
* `key` ([String](/ja/reference/data-types)) — ファイルセグメントの cache キー
* `file_segment_range_begin` ([UInt64](/ja/reference/data-types)) — ファイルセグメント範囲の先頭に対応するオフセット
* `file_segment_range_end` ([UInt64](/ja/reference/data-types)) — ファイルセグメント範囲の末尾 (含む) に対応するオフセット
* `size` ([UInt64](/ja/reference/data-types)) — ファイルセグメントのサイズ
* `state` ([String](/ja/reference/data-types)) — ファイルセグメントの状態 (DOWNLOADED、DOWNLOADING、PARTIALLY&#95;DOWNLOADED、...)
* `finished_download_time` ([DateTime](/ja/reference/data-types)) — ファイルセグメントのダウンロード完了時刻。
* `cache_hits` ([UInt64](/ja/reference/data-types)) — 対応するファイルセグメントでの cache ヒット数
* `references` ([UInt64](/ja/reference/data-types)) — 対応するファイルセグメントへの参照数。値が 1 の場合、その時点では誰も使用していないことを意味します (存在する参照は cache ストレージ自体のものだけです)
* `downloaded_size` ([UInt64](/ja/reference/data-types)) — ファイルセグメントのダウンロード済みサイズ
* `kind` ([String](/ja/reference/data-types)) — ファイルセグメントの種類 (&#39;Temporary data in cache&#39; の一部として追加されたファイルセグメントを区別するために使用されます)
* `unbound` ([UInt8](/ja/reference/data-types)) — 内部実装フラグ
* `user_id` ([String](/ja/reference/data-types)) — ファイルセグメントを作成したユーザーのユーザー ID
* `segment_type` ([String](/ja/reference/data-types)) — セグメントのタイプ。データファイル (`.json`、`.txt` など) とデータファイル (`.bin`、mark files) を区別するために使用されます。
* `file_size` ([Nullable(UInt64)](/ja/reference/data-types)) — 現在のファイルセグメントが属するファイルのサイズ

{/*AUTOGENERATED_END*/}
