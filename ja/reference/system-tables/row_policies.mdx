<div id="description">
  ## 説明
</div>

特定のテーブルに対するフィルターと、この行ポリシーを適用すべきロールおよび/またはユーザーの一覧が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ja/reference/data-types)) — 行ポリシーの名前。
* `short_name` ([String](/ja/reference/data-types)) — 行ポリシーの短縮名。行ポリシー名は複合名です。たとえば `myfilter ON mydb.mytable` の場合、&#39;myfilter ON mydb.mytable&#39; が行ポリシー名、&#39;myfilter&#39; が短縮名です。
* `database` ([String](/ja/reference/data-types)) — データベース名。
* `table` ([String](/ja/reference/data-types)) — テーブル名。データベースに対するポリシーの場合は空です。
* `id` ([UUID](/ja/reference/data-types)) — 行ポリシー ID。
* `storage` ([String](/ja/reference/data-types)) — 行ポリシーが保存されているディレクトリ名。
* `select_filter` ([Nullable(String)](/ja/reference/data-types)) — SELECT クエリでのフィルタリングに使用される式。
* `is_restrictive` ([UInt8](/ja/reference/data-types)) — 行ポリシーが行へのアクセスを制限するかどうかを示します。値: • 0 — 行ポリシーは `AS PERMISSIVE` 句で定義されています。• 1 — 行ポリシーは `AS RESTRICTIVE` 句で定義されています。
* `apply_to_all` ([UInt8](/ja/reference/data-types)) — すべてのロールおよび/またはユーザーに対して行ポリシーが設定されていることを示します。
* `apply_to_list` ([Array(String)](/ja/reference/data-types)) — 行ポリシーが適用されるロールおよび/またはユーザーの一覧。
* `apply_to_except` ([Array(String)](/ja/reference/data-types)) — 一覧に含まれるものを除く、すべてのロールおよび/またはユーザーに行ポリシーが適用されます。

{/*AUTOGENERATED_END*/}
