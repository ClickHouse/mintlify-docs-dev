<div id="description">
  ## 説明
</div>

[リフレッシュ可能なマテリアライズドビュー](/ja/reference/statements/create/view#refreshable-materialized-view)に関する情報です。リフレッシュが進行中かどうかにかかわらず、すべてのリフレッシュ可能なマテリアライズドビューが含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ja/reference/data-types)) — テーブルが存在するデータベースの名前。
* `view` ([String](/ja/reference/data-types)) — テーブル名。
* `uuid` ([UUID](/ja/reference/data-types)) — テーブルの UUID (Atomic データベース) 。
* `status` ([String](/ja/reference/data-types)) — リフレッシュの現在の状態。
* `last_success_time` ([Nullable(DateTime)](/ja/reference/data-types)) — 直近で成功したリフレッシュが開始された時刻。サーバーの起動以降、またはテーブル作成以降に成功したリフレッシュがない場合は NULL。
* `last_success_duration_ms` ([Nullable(UInt64)](/ja/reference/data-types)) — 直近のリフレッシュにかかった時間。
* `last_refresh_time` ([Nullable(DateTime)](/ja/reference/data-types)) — 直近のリフレッシュ試行が終了した時刻 (判明している場合) 、または開始した時刻 (不明な場合、またはまだ実行中の場合) 。サーバーの起動以降、またはテーブル作成以降にリフレッシュの試行がない場合は NULL。
* `last_refresh_replica` ([String](/ja/reference/data-types)) — 協調が有効な場合、現在のリフレッシュ試行 (実行中の場合) または前回のリフレッシュ試行 (実行中でない場合) を行ったレプリカの名前。
* `next_refresh_time` ([Nullable(DateTime)](/ja/reference/data-types)) — status = Scheduled の場合に、次回のリフレッシュが開始予定の時刻。
* `exception` ([String](/ja/reference/data-types)) — 前回の試行が失敗した場合のエラーメッセージ。
* `retry` ([UInt64](/ja/reference/data-types)) — 現在のリフレッシュについて、これまでに失敗した試行回数。status が `RunningOnAnotherReplica` の場合は利用できません。
* `progress` ([Nullable(Float64)](/ja/reference/data-types)) — 指定したレプリカにおける、現在実行中または直近で完了したリフレッシュの進捗。値は 0 から 1 の間です。status が `RunningOnAnotherReplica` の場合、またはリフレッシュが実行中でない場合は NULL。
* `read_rows` ([Nullable(UInt64)](/ja/reference/data-types)) — 指定したレプリカにおける、現在実行中または直近で完了したリフレッシュで読み取られた行数。status が `RunningOnAnotherReplica` の場合は NULL。
* `read_bytes` ([Nullable(UInt64)](/ja/reference/data-types)) — 指定したレプリカにおける、現在実行中または直近で完了したリフレッシュで読み取られたバイト数。status が `RunningOnAnotherReplica` の場合は NULL
* `total_rows` ([Nullable(UInt64)](/ja/reference/data-types)) — 指定したレプリカにおいて、現在実行中または直近で完了したリフレッシュで読み取る必要があると見積もられる総行数。status が `RunningOnAnotherReplica` の場合は NULL
* `written_rows` ([Nullable(UInt64)](/ja/reference/data-types)) — 指定したレプリカにおける、現在実行中または直近で完了したリフレッシュで書き込まれた行数。status が `RunningOnAnotherReplica` の場合は NULL
* `written_bytes` ([Nullable(UInt64)](/ja/reference/data-types)) — 指定したレプリカにおける、現在実行中または直近で完了したリフレッシュで書き込まれたバイト数。status が `RunningOnAnotherReplica` の場合は NULL

{/*AUTOGENERATED_END*/}

<div id="example">
  ## 例
</div>

```sql
SELECT
    database,
    view,
    status,
    last_refresh_result,
    last_refresh_time,
    next_refresh_time
FROM system.view_refreshes

┌─database─┬─view───────────────────────┬─status────┬─last_refresh_result─┬───last_refresh_time─┬───next_refresh_time─┐
│ default  │ hello_documentation_reader │ Scheduled │ Finished            │ 2023-12-01 01:24:00 │ 2023-12-01 01:25:00 │
└──────────┴────────────────────────────┴───────────┴─────────────────────┴─────────────────────┴─────────────────────┘
```
