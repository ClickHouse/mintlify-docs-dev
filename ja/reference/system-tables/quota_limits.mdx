<div id="description">
  ## 説明
</div>

すべてのQUOTAのすべてのインターバルに対する上限情報が含まれます。1 つのQUOTAに対応する行数は、0 行を含め任意です。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `quota_name` ([String](/ja/reference/data-types)) — QUOTA 名。
* `duration` ([UInt32](/ja/reference/data-types)) — リソース消費量の計算に使用する時間インターバルの長さ (秒単位) 。
* `is_randomized_interval` ([UInt8](/ja/reference/data-types)) — 真偽値。インターバルがランダム化されているかどうかを示します。ランダム化されていない場合、インターバルは常に同じ時刻に開始されます。たとえば、1 分のインターバルは常に分単位のちょうどの時刻に開始されます (つまり、11:20:00 に開始することはありますが、11:20:01 に開始することはありません) 。また、1 日のインターバルは常に UTC の午前 0 時に開始されます。インターバルがランダム化されている場合、最初のインターバルはランダムな時刻に開始され、その後のインターバルは順に開始されます。値: 0 — インターバルはランダム化されていません、1 — インターバルはランダム化されています。
* `max_queries` ([Nullable(UInt64)](/ja/reference/data-types)) — 実行が許可される、あらゆる種類のクエリの最大数。
* `max_query_selects` ([Nullable(UInt64)](/ja/reference/data-types)) — 実行が許可される SELECT クエリの最大数。
* `max_query_inserts` ([Nullable(UInt64)](/ja/reference/data-types)) — 実行が許可される INSERT クエリの最大数。
* `max_errors` ([Nullable(UInt64)](/ja/reference/data-types)) — 指定した期間内に許可される、エラーになったクエリの最大数。
* `max_result_rows` ([Nullable(UInt64)](/ja/reference/data-types)) — 指定した期間内に許可される、すべてのクエリの結果セットに含まれる行の総数の最大値。
* `max_result_bytes` ([Nullable(UInt64)](/ja/reference/data-types)) — 指定した期間内に許可される、すべてのクエリの結果セットに含まれるバイト総数の最大値。
* `max_read_rows` ([Nullable(UInt64)](/ja/reference/data-types)) — 指定した期間内に許可される、すべてのクエリの実行中に読み取る行数の最大値。
* `max_read_bytes` ([Nullable(UInt64)](/ja/reference/data-types)) — 指定した期間内に許可される、すべてのクエリの実行中に読み取るバイト数の最大値。
* `max_execution_time` ([Nullable(Float64)](/ja/reference/data-types)) — 指定した期間内において、すべてのクエリの実行に許可される時間の最大値 (ナノ秒単位) 。
* `max_written_bytes` ([Nullable(UInt64)](/ja/reference/data-types)) — 指定した期間内に許可される、すべてのクエリの実行中に書き込まれるバイト数の最大値。
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/ja/reference/data-types)) — 指定した期間内に許可される、連続する認証失敗の最大数。
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/ja/reference/data-types)) — 指定した期間内に許可される、単一の正規化されたクエリごとの最大実行回数。
