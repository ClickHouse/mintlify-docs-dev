<div id="description">
  ## 説明
</div>

すべてのフォーマットの一覧に加え、各フォーマットが入力／出力に適しているかどうか、および並列化をサポートしているかどうかを示すフラグが含まれています。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ja/reference/data-types)) — フォーマット名。
* `is_input` ([UInt8](/ja/reference/data-types)) — そのフォーマットがデータ入力に適しているかを示すフラグ。
* `is_output` ([UInt8](/ja/reference/data-types)) — そのフォーマットがデータ出力に適しているかを示すフラグ。
* `supports_parallel_parsing` ([UInt8](/ja/reference/data-types)) — そのフォーマットが並列パースに対応しているかを示すフラグ。
* `supports_parallel_formatting` ([UInt8](/ja/reference/data-types)) — そのフォーマットが並列フォーマットに対応しているかを示すフラグ。
* `is_tty_friendly` ([UInt8](/ja/reference/data-types)) — そのフォーマットが通常ターミナル上で問題なく表示されるかを示すフラグ。その他のフォーマットでは、CLI は出力前に確認を求めます。
* `content_type` ([String](/ja/reference/data-types)) — 出力フォーマットに対応する HTTP Content-Type。現在のフォーマット設定に依存する場合があります。
* `supports_random_access` ([UInt8](/ja/reference/data-types)) — そのフォーマットが入力時のランダムアクセスに対応しているかを示すフラグ。
* `has_schema_inference` ([UInt8](/ja/reference/data-types)) — そのフォーマットがデータから動的にスキーマを推定できることを示します (埋め込まれたヘッダー/メタデータ、またはデータ自体から) 。
* `has_external_schema` ([UInt8](/ja/reference/data-types)) — そのフォーマットが固定スキーマを持つか、またはそのフォーマット独自の形式で事前定義されたスキーマを受け入れられることを示します。
* `prefers_large_blocks` ([UInt8](/ja/reference/data-types)) — そのフォーマットが出力時により大きなブロックを書き込み、入力時により大きなブロックを生成することを示します。
* `supports_append` ([UInt8](/ja/reference/data-types)) — このフォーマットでは、単一のファイルに追記できます。
* `supports_subsets_of_columns` ([UInt8](/ja/reference/data-types)) — 入力フォーマットが特定のカラムの省略を認識できることを示します。
