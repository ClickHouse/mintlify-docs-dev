<div id="migration">
  # 移行
</div>

Docusaurus から Mintlify へ ClickHouse ドキュメントを移行するための、一時的なツールとデータです。**移行が
完了したら、このフォルダ全体は削除できます** — 本番サイトで実行時にこれへ依存するものはありません。

<div id="contents">
  ## Contents
</div>

* `slug-map.csv` — pairing of every Docusaurus slug → Mintlify file/URL, with
  source/migrated hashes for staleness tracking.
* `slug-aliases.csv` — manually-reviewed aliases for slugs that couldn&#39;t be
  resolved automatically.
* `migrate.py` — main migration script. Reads `slug-map.csv`, applies
  Mintlify-necessary transforms, writes the result.
* `generate-slug-map.py` — regenerates `slug-map.csv` from upstream Docusaurus
  * this repo&#39;s current layout.
* `apply-slug-aliases.py` — rewrites `<!-- MIGRATE: unknown slug -->` markers
  using `slug-aliases.csv`.
* `suggest-slug-aliases.py` — proposes alias candidates for unresolved slugs.
* `match_slugless.py` — finds Mintlify pages with no upstream slug match.
* `verify_mapping.py` — sanity-checks the slug map for duplicates/drift.
* `find_dup_imports.py` — detects MDX import conflicts caused by Mintlify
  hoisting snippet imports into the parent bundle.

## コンテンツ

* `slug-map.csv` — すべてのDocusaurusスラッグ → Mintlifyのファイル/URLのペアリング。
  鮮度追跡用のソース/移行済みハッシュが含まれます。
* `slug-aliases.csv` — 自動的に解決できなかったスラッグに対する、
  手動で確認済みの別名。
* `migrate.py` — メインの移行スクリプト。`slug-map.csv`を読み込み、
  Mintlifyに必要な変換を適用し、結果を書き込みます。
* `generate-slug-map.py` — アップストリームのDocusaurusと
  このリポジトリの現在のレイアウトから`slug-map.csv`を再生成します。
* `apply-slug-aliases.py` — `slug-aliases.csv`を使用して
  `<!-- MIGRATE: unknown slug -->`マーカーを書き換えます。
* `suggest-slug-aliases.py` — 未解決のスラッグに対する別名の候補を提案します。
* `match_slugless.py` — 一致するアップストリームのスラッグがないMintlifyページを検索します。
* `verify_mapping.py` — スラッグマップに重複やズレがないかサニティチェックします。
* `find_dup_imports.py` — Mintlifyがスニペットのインポートを親バンドルに
  巻き上げることで発生するMDXインポートの競合を検出します。

移行ワークフローについては、
`.claude/skills/migrate-docusaurus-to-mintlify/SKILL.md`を参照してください。
