<div id="helmonprem-clickhouse-cluster-version-11210">
  ### `helm/onprem-clickhouse-cluster` versão `1.1.210`
</div>

A partir da versão `1.1.210` do chart, novas restrições de configuração passam a ser incluídas por padrão. Se você estiver usando uma versão do ClickHouse server **inferior a 25.10**, deverá excluir essas restrições adicionando o seguinte à configuração do servidor:

```yaml
server:
  excludeConfigConstraints:
    - allow_experimental_qbit_type
    - rewrite_in_to_join
    - allow_experimental_alias_table_engine
```

Sem essa configuração, o ClickHouse não conseguirá iniciar, pois essas definições não são reconhecidas em versões anteriores à 25.10.
