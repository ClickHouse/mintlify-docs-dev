Você pode modificar parâmetros de configuração e gerenciar as configurações da sua instância do Managed Postgres na guia **Configurações** da barra lateral.

<div id="changing-configuration">
  ## Alterando parâmetros de configuração
</div>

<Image img="/images/managed-postgres/postgres-parameters.png" alt="Configuração dos parâmetros do Postgres" size="md" border />

Para modificar um parâmetro, selecione o botão **Editar parâmetros**. Selecione os parâmetros que deseja modificar e altere os respectivos valores conforme necessário. Quando estiver satisfeito com as alterações, clique em **Salvar alterações**.

Todas as alterações feitas nos parâmetros de configuração normalmente são persistidas na instância em até um minuto. Alguns parâmetros exigem a reinicialização do banco de dados para entrarem em vigor. Essas alterações serão aplicadas após a próxima reinicialização, que você pode acionar manualmente na barra de ferramentas **Ações do serviço**.

<div id="service-actions">
  ## ações do serviço e escalonamento
</div>

<Image img="/images/managed-postgres/service-actions.png" alt="ações do serviço e escalonamento" size="md" border />

A barra de ferramentas **ações do serviço** fornece controles para gerenciar sua instância do Managed Postgres:

* **Reset password**: Atualiza a senha do superusuário (somente quando a instância está `Running`)
* **Restart**: Reinicia a instância do banco de dados (somente quando a instância está `Running`)
* **Delete**: Exclui a instância

A seção **Scaling** permite alterar os tipos de instância da sua primária e das suas standbys para aumentar ou reduzir os recursos computacionais e a capacidade de armazenamento. Nos bastidores, novas instâncias serão provisionadas e depois assumirão o serviço quando estiverem sincronizadas com a primária atual. O processo de failover interromperá todas as conexões atuais e causará uma breve indisponibilidade.

<Tip>
  Por motivos de segurança, talvez você não consiga mudar para tipos de instância cujo armazenamento esteja próximo da capacidade de armazenamento atualmente em uso. Sempre opte por tipos de instância com folga acima da capacidade atualmente utilizada para evitar problemas.
</Tip>

<div id="ip-filters">
  ## IP filters
</div>

Os IP filters controlam quais endereços IP de origem têm permissão para se conectar à sua instância do Managed Postgres.

<Image img="/images/managed-postgres/ip-filters.png" alt="Configuração da IP Access List" size="md" border />

Para configurar os IP filters:

1. Vá para a aba **Settings**
2. Em **IP Filters**, clique em **Edit**
3. Adicione os endereços IP ou intervalos CIDR que devem ter permissão para se conectar
4. Clique em **Save** para aplicar as alterações

Você pode especificar endereços IP individuais ou usar a notação CIDR para intervalos de IP (por exemplo, `192.168.1.0/24`). Também é possível selecionar **Anywhere** ou **Nowhere** como atalho para abrir ou bloquear completamente o acesso à instância a partir de qualquer lugar.

<Note>
  Se nenhum IP filter estiver configurado, conexões de todos os endereços IP serão permitidas. Para workloads de produção, recomendamos restringir o acesso a endereços IP conhecidos.
</Note>
