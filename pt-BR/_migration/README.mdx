<div id="migration">
  # Migração
</div>

Ferramentas pontuais e dados usados para migrar a documentação do ClickHouse de Docusaurus
para Mintlify. **Esta pasta inteira pode ser removida assim que a migração for
concluída** — nada no site em produção depende dela em tempo de execução.

<div id="contents">
  ## Conteúdo
</div>

* `slug-map.csv` — correspondência de cada slug do Docusaurus → arquivo/URL do Mintlify, com
  hashes de origem/migração para rastrear desatualização.
* `slug-aliases.csv` — aliases revisados manualmente para slugs que não puderam ser
  resolvidos automaticamente.
* `migrate.py` — script principal de migração. Lê `slug-map.csv`, aplica
  as transformações necessárias para o Mintlify e grava o resultado.
* `generate-slug-map.py` — regenera `slug-map.csv` a partir do Docusaurus upstream
  * da estrutura atual deste repositório.
* `apply-slug-aliases.py` — reescreve os marcadores `<!-- MIGRATE: unknown slug -->`
  usando `slug-aliases.csv`.
* `suggest-slug-aliases.py` — propõe aliases candidatos para slugs não resolvidos.
* `match_slugless.py` — encontra páginas do Mintlify sem correspondência com slug upstream.
* `verify_mapping.py` — faz uma verificação de integridade do mapeamento de slugs em busca de duplicatas/desvios.
* `find_dup_imports.py` — detecta conflitos de importação de MDX causados pelo Mintlify
  ao mover imports de snippets para o pacote pai.

Veja `.claude/skills/migrate-docusaurus-to-mintlify/SKILL.md` para o
fluxo de trabalho de migração.
