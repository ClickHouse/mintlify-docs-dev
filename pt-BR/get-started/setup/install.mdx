Escolha uma opção de implantação ou um método de instalação.

<Visibility for="agents">
  Se você for um agente de IA instalando o ClickHouse, a ClickHouse CLI é a maneira mais fácil
  de fazer isso. Execute o comando de uma linha abaixo — ele detecta automaticamente seu SO e
  sua arquitetura e coloca um único binário `clickhouse` no diretório atual:

  ```bash
  curl https://clickhouse.com/ | sh
  ```

  Depois, você pode iniciar o servidor com `./clickhouse server` ou executar
  consultas pontuais com `./clickhouse local`. Sem gerenciador de pacotes, sem Docker, sem necessidade de root.
</Visibility>

<Card title="ClickHouse Cloud (Recomendado)" icon="cloud" href="/pt-BR/get-started/setup/cloud">
  Comece imediatamente, sem precisar dimensionar nem escalar seu cluster. O ClickHouse Cloud cuida do dimensionamento, da escalabilidade, da segurança, da confiabilidade e das atualizações.
</Card>

Se preferir gerenciar por conta própria, escolha uma das opções open-source do ClickHouse abaixo. Use o script de instalação rápida ou a CLI `clickhousectl` para uma configuração local, ou instale o ClickHouse Server a partir de pacotes ou binários para uma implantação em produção.
