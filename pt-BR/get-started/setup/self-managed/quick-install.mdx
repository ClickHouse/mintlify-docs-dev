Se você não precisa instalar o ClickHouse para produção, pode executar um script de instalação com curl. O script identificará um binário adequado para o seu sistema operacional.

<Steps>
  <Step>
    ## Instale o ClickHouse usando curl

    Execute o comando a seguir para baixar um único binário para o seu sistema operacional.

    ```bash
    curl https://clickhouse.com/ | sh
    ```

    <Note>
      Para usuários de Mac: se você estiver recebendo erros informando que não foi possível verificar o desenvolvedor do binário, consulte [aqui](/pt-BR/resources/support-center/knowledge-base/troubleshooting/fix-developer-verification-error-in-macos).
    </Note>
  </Step>

  <Step>
    ## Inicie o clickhouse-local

    O `clickhouse-local` permite processar arquivos locais e remotos usando a poderosa sintaxe SQL do ClickHouse, sem necessidade de configuração. Os dados da tabela são armazenados em um local temporário, o que significa que, após reiniciar o `clickhouse-local`, as tabelas criadas anteriormente não estarão mais disponíveis.

    Execute o comando a seguir para iniciar o [clickhouse-local](/pt-BR/concepts/features/tools-and-utilities/clickhouse-local):

    ```bash
    ./clickhouse
    ```
  </Step>

  <Step>
    ## Inicie o clickhouse-server

    Se quiser persistir os dados, execute o `clickhouse-server`. Você pode iniciar o servidor ClickHouse com o seguinte comando:

    ```bash
    ./clickhouse server
    ```
  </Step>

  <Step>
    ## Inicie o clickhouse-client

    Com o servidor em execução, abra uma nova janela do terminal e execute o comando a seguir para iniciar o `clickhouse-client`:

    ```bash
    ./clickhouse client
    ```

    Você verá algo assim:

    ```response
    ./clickhouse client
    ClickHouse client version 24.5.1.117 (official build).
    Connecting to localhost:9000 as user default.
    Connected to ClickHouse server version 24.5.1.

    local-host :)
    ```

    Os dados da tabela são armazenados no diretório atual e continuarão disponíveis após a reinicialização do servidor ClickHouse. Se necessário, você pode passar `-C config.xml` como argumento adicional de linha de comando para `./clickhouse server` e fornecer configurações adicionais em um arquivo de configuração. Todas as opções de configuração disponíveis estão documentadas [aqui](/pt-BR/reference/settings/server-settings/settings) e no [modelo do arquivo de configuração de exemplo](https://github.com/ClickHouse/ClickHouse/blob/master/programs/server/config.xml).

    Agora você já pode começar a enviar comandos SQL para o ClickHouse!

    <Tip>
      O [Quick Start](/pt-BR/get-started/setup/install) orienta você nas etapas de criação de tabelas e inserção de dados.
    </Tip>
  </Step>
</Steps>
