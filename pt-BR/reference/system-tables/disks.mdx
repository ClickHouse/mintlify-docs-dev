<div id="description">
  ## Descrição
</div>

Contém informações sobre os disks definidos na [configuração do servidor](/pt-BR/reference/engines/table-engines/mergetree-family/mergetree#table_engine-mergetree-multiple-volumes_configure).

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/pt-BR/reference/data-types)) — Nome de um disco na configuração do servidor.
* `path` ([String](/pt-BR/reference/data-types)) — Caminho para o ponto de montagem no sistema de arquivos.
* `free_space` ([UInt64](/pt-BR/reference/data-types)) — Espaço livre no disco em bytes.
* `total_space` ([UInt64](/pt-BR/reference/data-types)) — Volume do disco em bytes.
* `unreserved_space` ([UInt64](/pt-BR/reference/data-types)) — Espaço livre que não está comprometido por reservas (`free&#95;space` menos o tamanho das reservas usadas por merges, inserts e outras operações de gravação em disco atualmente em execução).
* `keep_free_space` ([UInt64](/pt-BR/reference/data-types)) — Quantidade de espaço em disco que deve permanecer livre, em bytes. Definida no parâmetro keep&#95;free&#95;space&#95;bytes da configuração do disco.
* `type` ([String](/pt-BR/reference/data-types)) — O tipo de disco, que informa onde este disco armazena os dados: RAM, unidade local ou armazenamento remoto.
* `object_storage_type` ([String](/pt-BR/reference/data-types)) — Tipo de armazenamento de objetos se o tipo de disco for object&#95;storage
* `metadata_type` ([String](/pt-BR/reference/data-types)) — Tipo de armazenamento de metadados se o tipo de disco for object&#95;storage
* `is_encrypted` ([UInt8](/pt-BR/reference/data-types)) — Sinalizador que mostra se este disco criptografa os dados subjacentes.
* `is_read_only` ([UInt8](/pt-BR/reference/data-types)) — Sinalizador que indica que você só pode realizar operações de leitura com este disco.
* `is_write_once` ([UInt8](/pt-BR/reference/data-types)) — Sinalizador que indica se o disco é de gravação única. Isso significa que ele oferece suporte a BACKUP nesse disco, mas não oferece suporte a INSERT em uma tabela MergeTree nesse disco.
* `is_remote` ([UInt8](/pt-BR/reference/data-types)) — Sinalizador que indica quais operações com este disco envolvem interação de rede.
* `is_broken` ([UInt8](/pt-BR/reference/data-types)) — Sinalizador que indica se o disco está com defeito. disks com defeito terão 0 de espaço e não poderão ser usados.
* `cache_path` ([String](/pt-BR/reference/data-types)) — Caminho para o diretório de cache na unidade local, caso o disco ofereça suporte a cache.

{/*AUTOGENERATED_END*/}
