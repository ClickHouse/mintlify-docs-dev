<div id="description">
  ## Descrição
</div>

Contém informações sobre os certificados disponíveis e suas origens.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `version` ([Int32](/pt-BR/reference/data-types)) — Versão do certificado. Os valores possíveis são 0 para v1, 1 para v2 e 2 para v3.
* `serial_number` ([Nullable(String)](/pt-BR/reference/data-types)) — Número de série do certificado atribuído pelo emissor.
* `signature_algo` ([Nullable(String)](/pt-BR/reference/data-types)) — Algoritmo de assinatura — algoritmo usado pelo emissor para assinar este certificado.
* `issuer` ([Nullable(String)](/pt-BR/reference/data-types)) — Emissor — identificador exclusivo da autoridade certificadora que emite este certificado.
* `not_before` ([Nullable(String)](/pt-BR/reference/data-types)) — Início da janela de tempo em que este certificado é válido.
* `not_after` ([Nullable(String)](/pt-BR/reference/data-types)) — Fim da janela de tempo em que este certificado é válido.
* `subject` ([Nullable(String)](/pt-BR/reference/data-types)) — Assunto — identifica o proprietário da chave pública.
* `pkey_algo` ([Nullable(String)](/pt-BR/reference/data-types)) — O algoritmo de chave pública define com qual algoritmo a chave pública pode ser usada.
* `path` ([String](/pt-BR/reference/data-types)) — Caminho para o arquivo ou diretório que contém este certificado.
* `default` ([UInt8](/pt-BR/reference/data-types)) — O certificado está no local padrão de certificados.
* `protocol` ([String](/pt-BR/reference/data-types)) — Nome do protocolo se o certificado vier de uma configuração TLS por protocolo; caso contrário, ficará vazio.

{/*AUTOGENERATED_END*/}
