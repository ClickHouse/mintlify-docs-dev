<div id="description">
  ## Descrição
</div>

Contém uma lista de todos os formatos, com indicadores de se um formato é adequado para entrada/saída e se oferece suporte à paralelização.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/pt-BR/reference/data-types)) — Nome do formato.
* `is_input` ([UInt8](/pt-BR/reference/data-types)) — Flag que indica se o formato é adequado para entrada de dados.
* `is_output` ([UInt8](/pt-BR/reference/data-types)) — Flag que indica se o formato é adequado para saída de dados.
* `supports_parallel_parsing` ([UInt8](/pt-BR/reference/data-types)) — Flag que indica se o formato oferece suporte a análise paralela.
* `supports_parallel_formatting` ([UInt8](/pt-BR/reference/data-types)) — Flag que indica se o formato oferece suporte à formatação paralela.
* `is_tty_friendly` ([UInt8](/pt-BR/reference/data-types)) — Flag que indica se o formato geralmente é exibido corretamente no terminal. Para outros formatos, a CLI pedirá confirmação antes de gerar a saída.
* `content_type` ([String](/pt-BR/reference/data-types)) — Content-Type HTTP correspondente ao formato de saída. Pode depender das configurações atuais do formato.
* `supports_random_access` ([UInt8](/pt-BR/reference/data-types)) — Flag que indica se o formato oferece suporte a acesso aleatório na entrada.
* `has_schema_inference` ([UInt8](/pt-BR/reference/data-types)) — O formato pode determinar dinamicamente o esquema a partir dos dados (seja de cabeçalhos/metadados incorporados ou do próprio trecho de dados).
* `has_external_schema` ([UInt8](/pt-BR/reference/data-types)) — O formato tem um esquema fixo ou aceita um esquema predefinido no próprio formato.
* `prefers_large_blocks` ([UInt8](/pt-BR/reference/data-types)) — O formato gravará blocos maiores na saída e gerará blocos maiores na entrada.
* `supports_append` ([UInt8](/pt-BR/reference/data-types)) — É possível acrescentar dados a um único arquivo com este formato.
* `supports_subsets_of_columns` ([UInt8](/pt-BR/reference/data-types)) — O formato de entrada pode reconhecer quando determinadas colunas são omitidas.

{/*AUTOGENERATED_END*/}
