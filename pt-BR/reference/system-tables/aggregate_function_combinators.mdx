<div id="description">
  ## Descrição
</div>

Contém uma lista de todos os combinadores de funções de agregação disponíveis, que podem ser aplicados às funções de agregação e alterar seu funcionamento.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/pt-BR/reference/data-types)) — O nome do combinador.
* `is_internal` ([UInt8](/pt-BR/reference/data-types)) — Indica se este combinador é apenas para uso interno.
