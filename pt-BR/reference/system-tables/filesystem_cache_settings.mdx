<div id="description">
  ## Descrição
</div>

Contém informações sobre todas as configurações do cache do sistema de arquivos

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `cache_name` ([String](/pt-BR/reference/data-types)) — Nome do cache
* `path` ([String](/pt-BR/reference/data-types)) — Caminho do diretório do cache
* `max_size` ([UInt64](/pt-BR/reference/data-types)) — Tamanho máximo do cache
* `max_elements` ([UInt64](/pt-BR/reference/data-types)) — Número máximo de elementos do cache, por exemplo, segmentos de arquivo (limita o número de arquivos no sistema de arquivos)
* `max_file_segment_size` ([UInt64](/pt-BR/reference/data-types)) — Tamanho máximo de um único segmento de arquivo
* `boundary_alignment` ([UInt64](/pt-BR/reference/data-types)) — Alinhamento de segmento de arquivo
* `cache_on_write_operations` ([UInt8](/pt-BR/reference/data-types)) — Habilita cache write-through (cache em INSERT e MERGE)
* `cache_policy` ([String](/pt-BR/reference/data-types)) — Política de eviction do cache
* `slru_size_ratio` ([Float64](/pt-BR/reference/data-types)) — Proporção de tamanho da política de cache SLRU entre elementos protegidos e em observação
* `background_download_threads` ([UInt64](/pt-BR/reference/data-types)) — Número de threads de download em segundo plano. O valor 0 desabilita o download em segundo plano
* `background_download_queue_size_limit` ([UInt64](/pt-BR/reference/data-types)) — Tamanho da fila de download em segundo plano. O valor 0 desabilita o download em segundo plano
* `background_download_max_file_segment_size` ([UInt64](/pt-BR/reference/data-types)) — Tamanho máximo que pode ser baixado em segundo plano
* `load_metadata_threads` ([UInt64](/pt-BR/reference/data-types)) — Número máximo de threads usadas para carregar os metadados do cache na inicialização do servidor
* `load_metadata_asynchronously` ([UInt8](/pt-BR/reference/data-types)) — Habilita o carregamento assíncrono de metadados na inicialização do servidor
* `keep_free_space_size_ratio` ([Float64](/pt-BR/reference/data-types)) — Proporção de espaço livre que o cache tentará manter em segundo plano
* `keep_free_space_elements_ratio` ([Float64](/pt-BR/reference/data-types)) — Proporção de elementos livres que o cache tentará manter em segundo plano
* `keep_free_space_remove_batch` ([UInt64](/pt-BR/reference/data-types)) — Tamanho do lote de remoção de elementos do cache feito pela thread em segundo plano que mantém a proporção de espaço livre/elementos
* `enable_filesystem_query_cache_limit` ([UInt8](/pt-BR/reference/data-types)) — Habilita a limitação do tamanho máximo do cache que pode ser gravado dentro de uma consulta
* `cache_hits_threshold` ([UInt64](/pt-BR/reference/data-types)) — Configuração obsoleta
* `enable_bypass_cache_with_threshold` ([UInt8](/pt-BR/reference/data-types)) — Não documentado. Uso não recomendado
* `bypass_cache_threshold` ([UInt64](/pt-BR/reference/data-types)) — Não documentado. Uso não recomendado
* `write_cache_per_user_id_directory` ([UInt8](/pt-BR/reference/data-types)) — Configuração interna do ClickHouse Cloud
* `allow_dynamic_cache_resize` ([UInt8](/pt-BR/reference/data-types)) — Permite o redimensionamento dinâmico do cache do sistema de arquivos
* `dynamic_resize_lock_wait_ms` ([UInt64](/pt-BR/reference/data-types)) — Timeout em milissegundos para adquirir o bloqueio exclusivo de redimensionamento dinâmico antes de ignorar a tentativa de redimensionamento
* `max_size_ratio_to_total_space` ([Float64](/pt-BR/reference/data-types)) — Proporção de `max_size` em relação ao espaço total em disco
* `skip_cache_on_disk_failure` ([UInt8](/pt-BR/reference/data-types)) — Se verdadeiro, ignora silenciosamente as operações do cache do sistema de arquivos em caso de erros de E/S de disco. Se falso (padrão), os erros de E/S de disco são propagados como falhas de inicialização.
* `use_split_cache` ([UInt8](/pt-BR/reference/data-types)) — Usa a separação de arquivos entre sistema e dados.
* `split_cache_ratio` ([Float64](/pt-BR/reference/data-types)) — Proporção do segmento do sistema em relação ao tamanho total do cache para split&#95;cache.
* `overcommit_eviction_evict_step` ([UInt64](/pt-BR/reference/data-types)) — Passo de eviction em bytes para a política de eviction por overcommit. Usado para as configurações keep&#95;free&#95;space&#95;*&#95;ratio
* `check_cache_probability` ([Float64](/pt-BR/reference/data-types)) — Funciona apenas em compilação de depuração ou com sanitizer. Verifica a correção do cache percorrendo todo o cache e verificando o estado de cada elemento do cache
* `is_initialized` ([UInt8](/pt-BR/reference/data-types)) — Indica se o cache foi inicializado com sucesso
* `current_size` ([UInt64](/pt-BR/reference/data-types)) — Tamanho atual do cache
* `current_elements_num` ([UInt64](/pt-BR/reference/data-types)) — Número atual de elementos do cache (segmentos de arquivo)
