<div id="description">
  ## Descrição
</div>

Esta tabela de sistema é usada para implementar a consulta `SHOW PROCESSLIST`.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `is_initial_query` ([UInt8](/pt-BR/reference/data-types)) — Indica se esta consulta vem diretamente do usuário ou foi emitida pelo servidor ClickHouse no contexto da execução distribuída de consultas.
* `user` ([String](/pt-BR/reference/data-types)) — O usuário que fez a consulta. Tenha em mente que, no processamento distribuído, as consultas são enviadas aos servidores remotos com o usuário padrão. O campo contém o nome de usuário de uma consulta específica, não de uma consulta iniciada por esta consulta.
* `query_id` ([String](/pt-BR/reference/data-types)) — ID da consulta, se estiver definido.
* `address` ([IPv6](/pt-BR/reference/data-types)) — O endereço IP de onde a consulta foi feita. O mesmo vale para processamento distribuído. Para rastrear de onde uma consulta distribuída foi originalmente feita, consulte system.processes no servidor que solicitou a consulta.
* `port` ([UInt16](/pt-BR/reference/data-types)) — A porta do cliente da qual a consulta foi feita.
* `initial_user` ([String](/pt-BR/reference/data-types)) — Nome do usuário que executou a consulta inicial (na execução distribuída de consultas).
* `initial_query_id` ([String](/pt-BR/reference/data-types)) — ID da consulta inicial (para execução distribuída de consultas).
* `initial_address` ([IPv6](/pt-BR/reference/data-types)) — Endereço IP de onde a consulta principal foi iniciada.
* `initial_port` ([UInt16](/pt-BR/reference/data-types)) — A porta do cliente usada para executar a consulta pai.
* `interface` ([UInt8](/pt-BR/reference/data-types)) — A interface usada para enviar a consulta. TCP = 1, HTTP = 2, GRPC = 3, MYSQL = 4, POSTGRESQL = 5, LOCAL = 6, TCP&#95;INTERSERVER = 7.
* `os_user` ([String](/pt-BR/reference/data-types)) — Nome de usuário do sistema operacional que executa o clickhouse-client.
* `client_hostname` ([String](/pt-BR/reference/data-types)) — Hostname da máquina cliente onde o clickhouse-client ou outro cliente TCP está em execução.
* `client_name` ([String](/pt-BR/reference/data-types)) — Nome do clickhouse-client ou de outro cliente TCP.
* `client_revision` ([UInt64](/pt-BR/reference/data-types)) — Revisão do clickhouse-client ou de outro cliente TCP.
* `client_version_major` ([UInt64](/pt-BR/reference/data-types)) — Versão principal do clickhouse-client ou de outro cliente TCP.
* `client_version_minor` ([UInt64](/pt-BR/reference/data-types)) — Versão secundária do clickhouse-client ou de outro cliente TCP.
* `client_version_patch` ([UInt64](/pt-BR/reference/data-types)) — Componente patch da versão do clickhouse-client ou de outro cliente TCP.
* `http_method` ([UInt8](/pt-BR/reference/data-types)) — Método HTTP que iniciou a consulta. Possíveis valores: 0 — A consulta foi iniciada pela interface TCP. 1 — O método GET foi usado. 2 — O método POST foi usado.
* `http_user_agent` ([String](/pt-BR/reference/data-types)) — cabeçalho HTTP UserAgent enviado na consulta HTTP.
* `http_referer` ([String](/pt-BR/reference/data-types)) — cabeçalho HTTP Referer enviado na requisição HTTP (contém um endereço absoluto ou parcial da página que faz a requisição).
* `forwarded_for` ([String](/pt-BR/reference/data-types)) — cabeçalho HTTP X-Forwarded-For enviado na consulta HTTP.
* `quota_key` ([String](/pt-BR/reference/data-types)) — A chave da quota especificada na configuração de quotas (consulte keyed).
* `distributed_depth` ([UInt64](/pt-BR/reference/data-types)) — O número de vezes que a consulta foi retransmitida internamente entre os nós do servidor.
* `elapsed` ([Float64](/pt-BR/reference/data-types)) — O tempo, em segundos, desde o início da execução da requisição.
* `is_cancelled` ([UInt8](/pt-BR/reference/data-types)) — Indica se a consulta foi cancelada.
* `is_all_data_sent` ([UInt8](/pt-BR/reference/data-types)) — Todos os dados foram enviados ao cliente (ou seja, a consulta havia sido concluída no servidor).
* `read_rows` ([UInt64](/pt-BR/reference/data-types)) — O número de linhas lidas da tabela. Para processamento distribuído, no servidor solicitante, esse é o total de todos os servidores remotos.
* `read_bytes` ([UInt64](/pt-BR/reference/data-types)) — O número de bytes não compactados lidos da tabela. Em processamento distribuído, no servidor solicitante, esse é o total de todos os servidores remotos.
* `total_rows_approx` ([UInt64](/pt-BR/reference/data-types)) — A estimativa do número total de linhas que devem ser lidas. Em processamento distribuído, no servidor solicitante, esse é o total de todos os servidores remotos. Ele pode ser atualizado durante o processamento da solicitação, quando novas fontes a processar se tornam conhecidas.
* `written_rows` ([UInt64](/pt-BR/reference/data-types)) — Quantidade de linhas gravadas no armazenamento.
* `written_bytes` ([UInt64](/pt-BR/reference/data-types)) — A quantidade de bytes gravados no armazenamento.
* `memory_usage` ([Int64](/pt-BR/reference/data-types)) — Quantidade de RAM usada pela consulta. Talvez não inclua alguns tipos de memória dedicada
* `peak_memory_usage` ([Int64](/pt-BR/reference/data-types)) — O pico atual do uso de memória.
* `query` ([String](/pt-BR/reference/data-types)) — O texto da consulta. Para INSERT, não inclui os dados a serem inseridos.
* `normalized_query_hash` ([UInt64](/pt-BR/reference/data-types)) — Um valor de hash numérico que é idêntico para consultas que diferem apenas nos valores dos literais.
* `query_kind` ([String](/pt-BR/reference/data-types)) — O tipo da consulta — SELECT, INSERT, etc.
* `thread_ids` ([Array(UInt64)](/pt-BR/reference/data-types)) — A lista dos identificadores de todas as threads que participaram desta consulta.
* `peak_threads_usage` ([UInt64](/pt-BR/reference/data-types)) — Número máximo de threads executando a consulta simultaneamente.
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/pt-BR/reference/data-types)) — ProfileEvents calculados nesta consulta.
* `Settings` ([Map(LowCardinality(String), LowCardinality(String))](/pt-BR/reference/data-types)) — A lista de configurações de usuário modificadas.
* `current_database` ([String](/pt-BR/reference/data-types)) — O nome do banco de dados atual.
* `is_internal` ([UInt8](/pt-BR/reference/data-types)) — Indica se se trata de uma consulta auxiliar executada internamente.

{/*AUTOGENERATED_END*/}
