<div id="description">
  ## Descrição
</div>

Esta tabela contém informações sobre as partes de projeção de tabelas da família MergeTree.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `partition` ([String](/pt-BR/reference/data-types)) — O nome da partição.
* `name` ([String](/pt-BR/reference/data-types)) — Nome da data part.
* `part_type` ([String](/pt-BR/reference/data-types)) — O formato de armazenamento da data part. Valores possíveis: Wide (um arquivo por coluna) e Compact (um único arquivo para todas as colunas).
* `parent_name` ([String](/pt-BR/reference/data-types)) — O nome da parte de dados de origem (pai).
* `parent_uuid` ([UUID](/pt-BR/reference/data-types)) — O UUID da parte de dados de origem (parte pai).
* `parent_part_type` ([String](/pt-BR/reference/data-types)) — O formato de armazenamento da parte de dados de origem (pai).
* `active` ([UInt8](/pt-BR/reference/data-types)) — Indicador que informa se a parte de dados está ativa. Se uma parte de dados estiver ativa, ela é usada em uma tabela. Caso contrário, está prestes a ser excluída. Partes de dados inativas aparecem após operações de mesclagem e mutação.
* `marks` ([UInt64](/pt-BR/reference/data-types)) — O número de marcas. Para obter o número aproximado de linhas em uma parte de dados, multiplique as marcas pela granularidade do índice (geralmente 8192) (esta observação não funciona para granularidade adaptativa).
* `rows` ([UInt64](/pt-BR/reference/data-types)) — O número de linhas.
* `bytes_on_disk` ([UInt64](/pt-BR/reference/data-types)) — Tamanho total, em bytes, de todos os arquivos das partes de dados.
* `data_compressed_bytes` ([UInt64](/pt-BR/reference/data-types)) — Tamanho total dos dados compactados na parte de dados. Arquivos auxiliares (por exemplo, arquivos com marcas) não estão incluídos.
* `data_uncompressed_bytes` ([UInt64](/pt-BR/reference/data-types)) — Tamanho total dos dados não compactados na parte de dados. Os arquivos auxiliares (por exemplo, arquivos com marcas) não estão incluídos.
* `marks_bytes` ([UInt64](/pt-BR/reference/data-types)) — O tamanho do arquivo de marcas.
* `parent_marks` ([UInt64](/pt-BR/reference/data-types)) — O número de marcas na parte de origem (parte pai).
* `parent_rows` ([UInt64](/pt-BR/reference/data-types)) — O número de linhas na parte de origem (parte pai).
* `parent_bytes_on_disk` ([UInt64](/pt-BR/reference/data-types)) — Tamanho total em bytes de todos os arquivos das partes de dados de origem (pai).
* `parent_data_compressed_bytes` ([UInt64](/pt-BR/reference/data-types)) — Tamanho total dos dados compactados na parte de dados de origem (parte pai).
* `parent_data_uncompressed_bytes` ([UInt64](/pt-BR/reference/data-types)) — Tamanho total dos dados não compactados na parte de dados de origem (parte pai).
* `parent_marks_bytes` ([UInt64](/pt-BR/reference/data-types)) — O tamanho do arquivo de marcas na parte de dados de origem (pai).
* `modification_time` ([DateTime](/pt-BR/reference/data-types)) — O momento em que o diretório com a parte de dados foi modificado. Isso geralmente corresponde ao momento de criação da parte de dados.
* `remove_time` ([DateTime](/pt-BR/reference/data-types)) — O momento em que a data part se tornou inativa.
* `refcount` ([UInt32](/pt-BR/reference/data-types)) — O número de contextos em que a parte de dados é usada. Um valor maior que 2 indica que a parte de dados está sendo usada em consultas ou operações de mesclagem.
* `min_date` ([Date](/pt-BR/reference/data-types)) — O menor valor da chave de data na parte de dados.
* `max_date` ([Date](/pt-BR/reference/data-types)) — O valor máximo da chave de data na parte de dados.
* `min_time` ([DateTime](/pt-BR/reference/data-types)) — O menor valor da chave de data e hora na parte de dados.
* `max_time` ([DateTime](/pt-BR/reference/data-types)) — O valor máximo da chave de data e hora na parte de dados.
* `partition_id` ([String](/pt-BR/reference/data-types)) — ID da partição.
* `min_block_number` ([Int64](/pt-BR/reference/data-types)) — O menor número de partes de dados que compõem a parte atual após a mesclagem.
* `max_block_number` ([Int64](/pt-BR/reference/data-types)) — O número máximo de partes de dados que formam a parte atual após a mesclagem.
* `level` ([UInt32](/pt-BR/reference/data-types)) — Profundidade da árvore de merge. Zero significa que a parte atual foi criada por `insert`, e não pela mesclagem de outras partes.
* `data_version` ([UInt64](/pt-BR/reference/data-types)) — Número usado para determinar quais mutações devem ser aplicadas à parte de dados (mutações com versão maior que data&#95;version).
* `primary_key_bytes_in_memory` ([UInt64](/pt-BR/reference/data-types)) — A quantidade de memória (em bytes) usada pelos valores da chave primária.
* `primary_key_bytes_in_memory_allocated` ([UInt64](/pt-BR/reference/data-types)) — A quantidade de memória (em bytes) reservada para os valores da chave primária.
* `is_frozen` ([UInt8](/pt-BR/reference/data-types)) — Indicador de que existe um backup dos dados de uma partição. 1, o backup existe. 0, o backup não existe.
* `database` ([String](/pt-BR/reference/data-types)) — Nome do banco de dados.
* `table` ([String](/pt-BR/reference/data-types)) — Nome da tabela.
* `engine` ([String](/pt-BR/reference/data-types)) — Nome do mecanismo da tabela sem parâmetros.
* `disk_name` ([String](/pt-BR/reference/data-types)) — Nome do disco que armazena a parte de dados.
* `path` ([String](/pt-BR/reference/data-types)) — Caminho absoluto para a pasta com os arquivos da parte de dados.
* `hash_of_all_files` ([String](/pt-BR/reference/data-types)) — sipHash128 dos arquivos compactados.
* `hash_of_uncompressed_files` ([String](/pt-BR/reference/data-types)) — sipHash128 de arquivos não compactados (arquivos com marcas, arquivo de índice etc.).
* `uncompressed_hash_of_compressed_files` ([String](/pt-BR/reference/data-types)) — sipHash128 dos dados contidos nos arquivos compactados, como se estivessem descompactados.
* `delete_ttl_info_min` ([DateTime](/pt-BR/reference/data-types)) — O valor mínimo da chave de data e hora da regra TTL DELETE.
* `delete_ttl_info_max` ([DateTime](/pt-BR/reference/data-types)) — O valor máximo da chave de data e hora da regra TTL DELETE.
* `move_ttl_info.expression` ([Array(String)](/pt-BR/reference/data-types)) — Array de expressões. Cada expressão define uma regra de TTL MOVE.
* `move_ttl_info.min` ([Array(DateTime)](/pt-BR/reference/data-types)) — Array com valores de data e hora. Cada elemento descreve o menor valor da chave para uma regra TTL MOVE.
* `move_ttl_info.max` ([Array(DateTime)](/pt-BR/reference/data-types)) — Array de valores de data e hora. Cada elemento descreve o maior valor de chave para uma regra TTL MOVE.
* `default_compression_codec` ([String](/pt-BR/reference/data-types)) — O nome do codec usado para compactar esta parte de dados (caso não haja um codec explícito para as colunas).
* `recompression_ttl_info.expression` ([Array(String)](/pt-BR/reference/data-types)) — A expressão de TTL.
* `recompression_ttl_info.min` ([Array(DateTime)](/pt-BR/reference/data-types)) — O valor mínimo da expressão TTL calculada nesta parte. Usado para entender se há pelo menos uma linha com TTL expirado.
* `recompression_ttl_info.max` ([Array(DateTime)](/pt-BR/reference/data-types)) — O valor máximo da expressão TTL calculada nesta parte. É usado para verificar se todas as linhas têm o TTL expirado.
* `group_by_ttl_info.expression` ([Array(String)](/pt-BR/reference/data-types)) — A expressão de TTL.
* `group_by_ttl_info.min` ([Array(DateTime)](/pt-BR/reference/data-types)) — O valor mínimo da expressão TTL calculada nesta parte. Usado para indicar se há pelo menos uma linha com TTL expirado.
* `group_by_ttl_info.max` ([Array(DateTime)](/pt-BR/reference/data-types)) — O valor máximo da expressão TTL calculada nesta parte. Usado para verificar se temos todas as linhas com TTL expirado.
* `rows_where_ttl_info.expression` ([Array(String)](/pt-BR/reference/data-types)) — A expressão de TTL.
* `rows_where_ttl_info.min` ([Array(DateTime)](/pt-BR/reference/data-types)) — O valor mínimo da expressão TTL calculada nesta parte. Usado para determinar se há pelo menos uma linha com TTL expirado.
* `rows_where_ttl_info.max` ([Array(DateTime)](/pt-BR/reference/data-types)) — O valor máximo da expressão TTL calculada nesta parte. Usado para determinar se todas as linhas com TTL expirado estão presentes.
* `is_broken` ([UInt8](/pt-BR/reference/data-types)) — Indica se a parte da projeção está corrompida
* `exception_code` ([Int32](/pt-BR/reference/data-types)) — Mensagem de exceção que descreve o estado corrompido da parte da projeção
* `exception` ([String](/pt-BR/reference/data-types)) — Código de exceção que indica o estado corrompido da parte da projeção
