<div id="description">
  ## Descrição
</div>

[Apache Arrow](https://arrow.apache.org/) conta com dois formatos nativos de armazenamento colunar. O ClickHouse oferece suporte a operações de leitura e gravação nesses formatos.
`Arrow` é o formato de &quot;modo de arquivo&quot; do Apache Arrow. Ele foi projetado para acesso aleatório na memória.

<div id="data-types-matching">
  ## Correspondência entre tipos de dados
</div>

A tabela abaixo mostra os tipos de dados compatíveis e como eles correspondem aos [tipos de dados](/pt-BR/reference/data-types) do ClickHouse em consultas `INSERT` e `SELECT`.

| Tipo de dado Arrow (`INSERT`)           | Tipo de dado ClickHouse                                                                                        | Tipo de dado Arrow (`SELECT`) |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------- | ----------------------------- |
| `BOOL`                                  | [Bool](/pt-BR/reference/data-types/boolean)                                                                          | `BOOL`                        |
| `UINT8`, `BOOL`                         | [UInt8](/pt-BR/reference/data-types/int-uint)                                                                        | `UINT8`                       |
| `INT8`                                  | [Int8](/pt-BR/reference/data-types/int-uint)/[Enum8](/pt-BR/reference/data-types/enum)                                     | `INT8`                        |
| `UINT16`                                | [UInt16](/pt-BR/reference/data-types/int-uint)                                                                       | `UINT16`                      |
| `INT16`                                 | [Int16](/pt-BR/reference/data-types/int-uint)/[Enum16](/pt-BR/reference/data-types/enum)                                   | `INT16`                       |
| `UINT32`                                | [UInt32](/pt-BR/reference/data-types/int-uint)                                                                       | `UINT32`                      |
| `INT32`                                 | [Int32](/pt-BR/reference/data-types/int-uint)                                                                        | `INT32`                       |
| `UINT64`                                | [UInt64](/pt-BR/reference/data-types/int-uint)                                                                       | `UINT64`                      |
| `INT64`                                 | [Int64](/pt-BR/reference/data-types/int-uint)                                                                        | `INT64`                       |
| `FLOAT`, `HALF_FLOAT`                   | [Float32](/pt-BR/reference/data-types/float)                                                                         | `FLOAT32`                     |
| `DOUBLE`                                | [Float64](/pt-BR/reference/data-types/float)                                                                         | `FLOAT64`                     |
| `DATE32`                                | [Date32](/pt-BR/reference/data-types/date32)                                                                         | `UINT16`                      |
| `DATE64`                                | [DateTime](/pt-BR/reference/data-types/datetime)                                                                     | `UINT32`                      |
| `TIMESTAMP`, `TIME32`, `TIME64`         | [DateTime64](/pt-BR/reference/data-types/datetime64)                                                                 | `TIMESTAMP`                   |
| `STRING`, `BINARY`                      | [String](/pt-BR/reference/data-types/string)                                                                         | `BINARY`                      |
| `STRING`, `BINARY`, `FIXED_SIZE_BINARY` | [FixedString](/pt-BR/reference/data-types/fixedstring)                                                               | `FIXED_SIZE_BINARY`           |
| `DECIMAL`                               | [Decimal](/pt-BR/reference/data-types/decimal)                                                                       | `DECIMAL`                     |
| `DECIMAL256`                            | [Decimal256](/pt-BR/reference/data-types/decimal)                                                                    | `DECIMAL256`                  |
| `LIST`                                  | [Array](/pt-BR/reference/data-types/array)                                                                           | `LIST`                        |
| `STRUCT`                                | [Tuple](/pt-BR/reference/data-types/tuple)                                                                           | `STRUCT`                      |
| `MAP`                                   | [Map](/pt-BR/reference/data-types/map)                                                                               | `MAP`                         |
| `UINT32`                                | [IPv4](/pt-BR/reference/data-types/ipv4)                                                                             | `UINT32`                      |
| `FIXED_SIZE_BINARY`, `BINARY`           | [IPv6](/pt-BR/reference/data-types/ipv6)                                                                             | `FIXED_SIZE_BINARY`           |
| `FIXED_SIZE_BINARY`, `BINARY`           | [Int128/UInt128/Int256/UInt256](/pt-BR/reference/data-types/int-uint)                                                | `FIXED_SIZE_BINARY`           |
| `DURATION`                              | [Interval](/pt-BR/reference/data-types/special-data-types/interval) (Nanosegundo/Microssegundo/Milissegundo/Segundo) | `DURATION`                    |
| `INT64`                                 | [Interval](/pt-BR/reference/data-types/special-data-types/interval) (Minuto/Hora/Dia/Semana/Mês/Trimestre/Ano)       | `INT64`                       |

Arrays podem ser aninhados e podem ter um valor do tipo `Nullable` como argumento. Os tipos `Tuple` e `Map` também podem ser aninhados.

O tipo `DICTIONARY` é compatível com consultas `INSERT`, e, para consultas `SELECT`, há uma configuração [`output_format_arrow_low_cardinality_as_dictionary`](/pt-BR/reference/settings/formats#output_format_arrow_low_cardinality_as_dictionary) que permite retornar o tipo [LowCardinality](/pt-BR/reference/data-types/lowcardinality) como um tipo `DICTIONARY`. Observe que pode haver valores não utilizados no dicionário `LowCardinality`, o que pode resultar em valores não utilizados no `DICTIONARY` do Arrow na saída.

Tipos de dados Arrow sem suporte:

* `FIXED_SIZE_BINARY`
* `JSON`
* `UUID`
* `ENUM`.

Os tipos de dados das colunas da tabela do ClickHouse não precisam corresponder aos campos de dados correspondentes do Arrow. Ao inserir dados, o ClickHouse interpreta os tipos de dados de acordo com a tabela acima e depois [aplica CAST](/pt-BR/reference/functions/regular-functions/type-conversion-functions#CAST) aos dados para convertê-los para o tipo de dado definido para a coluna da tabela do ClickHouse.

<div id="example-usage">
  ## Exemplo de uso
</div>

<div id="inserting-data">
  ### Inserção de dados
</div>

Você pode inserir dados Arrow de um arquivo em uma tabela do ClickHouse usando o seguinte comando:

```bash
$ cat filename.arrow | clickhouse-client --query="INSERT INTO some_table FORMAT Arrow"
```

<div id="selecting-data">
  ### Selecionando dados
</div>

Você pode selecionar dados de uma tabela do ClickHouse e salvá-los em um arquivo no formato Arrow usando o seguinte comando:

```bash
$ clickhouse-client --query="SELECT * FROM {some_table} FORMAT Arrow" > {filename.arrow}
```

<div id="format-settings">
  ## Configurações de formato
</div>

| Configuração                                                                 | Descrição                                                                                                      | Padrão      |
| ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- | ----------- |
| `input_format_arrow_allow_missing_columns`                                   | Permite colunas ausentes ao ler formatos de entrada Arrow                                                      | `1`         |
| `input_format_arrow_case_insensitive_column_matching`                        | Ignora a diferenciação entre maiúsculas e minúsculas ao corresponder colunas Arrow às colunas CH.              | `0`         |
| `input_format_arrow_import_nested`                                           | Configuração obsoleta; não faz nada.                                                                           | `0`         |
| `input_format_arrow_skip_columns_with_unsupported_types_in_schema_inference` | Ignora colunas com tipos não compatíveis durante a inferência de esquema para o formato Arrow                  | `0`         |
| `output_format_arrow_compression_method`                                     | Método de compressão do formato de saída Arrow. Codecs compatíveis: lz4&#95;frame, zstd, none (sem compressão) | `lz4_frame` |
| `output_format_arrow_fixed_string_as_fixed_byte_array`                       | Usa o tipo Arrow FIXED&#95;SIZE&#95;BINARY em vez de Binary para colunas FixedString.                          | `1`         |
| `output_format_arrow_low_cardinality_as_dictionary`                          | Habilita a saída do tipo LowCardinality como o tipo Arrow Dictionary                                           | `0`         |
| `output_format_arrow_string_as_string`                                       | Usa o tipo Arrow String em vez de Binary para colunas String                                                   | `1`         |
| `output_format_arrow_use_64_bit_indexes_for_dictionary`                      | Sempre usa inteiros de 64 bits para índices de dicionário no formato Arrow                                     | `0`         |
| `output_format_arrow_use_signed_indexes_for_dictionary`                      | Usa inteiros com sinal para índices de dicionário no formato Arrow                                             | `1`         |
