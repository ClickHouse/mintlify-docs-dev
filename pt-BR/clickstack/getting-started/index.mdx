<Tip>
  Estes tutoriais funcionam com qualquer implantação do ClickHouse, incluindo o [ClickHouse Cloud](/pt-BR/get-started/setup/cloud).
</Tip>

Temos muitos recursos para ajudar você a começar e a entender como o ClickHouse funciona:

* Se você precisa colocar o ClickHouse em funcionamento, confira nosso [Início rápido](/pt-BR/get-started/setup/install)
* O [Tutorial do ClickHouse](/pt-BR/get-started/quickstarts/tutorial) analisa um conjunto de dados de corridas de táxi da cidade de Nova York

Além disso, os conjuntos de dados de exemplo são uma ótima forma de trabalhar com o ClickHouse,
aprender técnicas e truques importantes e ver como aproveitar as muitas funções poderosas
do ClickHouse. Os conjuntos de dados de exemplo incluem:
