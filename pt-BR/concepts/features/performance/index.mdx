Esta seção aborda recursos e técnicas para melhorar o desempenho de consultas e da ingestão
no ClickHouse. Recomendamos ler
[Conceitos centrais](/pt-BR/concepts/core-concepts/parts) primeiro, para entender os fundamentos
nos quais estes guias se baseiam.

<CardGroup cols={2}>
  <Card title="Otimização de PREWHERE" icon="filter" href="/pt-BR/concepts/features/performance/prewhere">
    Como `PREWHERE` reduz E/S ao filtrar dados antes de ler colunas não usadas no filtro e como monitorar sua eficácia.
  </Card>

  <Card title="Profiling de alocação" icon="chart-line" href="/pt-BR/concepts/features/performance/allocation-profiling">
    Analise alocações de memória para diagnosticar pressão de memória e ajustar o uso de recursos no ClickHouse.
  </Card>

  <Card title="Caches" icon="bolt" href="/pt-BR/concepts/features/performance/caches/caches">
    Cache de consultas, cache de condição de consulta e cache de páginas em espaço de usuário para acelerar cargas de trabalho repetidas.
  </Card>

  <Card title="Skip indexes" icon="forward" href="/pt-BR/concepts/features/performance/skip-indexes/skipping-indexes">
    Use skip indexes secundários para eliminar blocos de dados irrelevantes e acelerar consultas com filtro.
  </Card>

  <Card title="Materialização tardia" icon="clock" href="/pt-BR/concepts/features/performance/lazy-materialization">
    Adie leituras de colunas até que sejam necessárias para reduzir E/S em consultas seletivas.
  </Card>

  <Card title="Solução de problemas" icon="bug" href="/pt-BR/concepts/features/performance/troubleshoot/sampling-query-profiler">
    Sampling query profiler, benchmarking de hardware e depuração de problemas de memória.
  </Card>
</CardGroup>
