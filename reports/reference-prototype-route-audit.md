## Migration rule

Do not let the renderer choose a slug solely from the system-table name. Give every generated record a route decision in the snapshot artifact:

1. `canonicalRoute` — retain an existing public URL when one exists.
2. `redirectFrom` — include previous URLs only when the canonical route must change.
3. `source` — identify the system-table catalog or mark the page as site-owned.

This turns the JSON audit into a CI gate: a new generated route or a missing current autogenerated route must be classified before a release snapshot is published.
