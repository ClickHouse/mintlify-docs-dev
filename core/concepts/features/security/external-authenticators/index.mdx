ClickHouse supports authenticating and managing users using external services.

The following external authenticators and directories are supported:

- [LDAP](/core/concepts/features/security/external-authenticators/ldap#ldap-external-authenticator) [Authenticator](/core/concepts/features/security/external-authenticators/ldap#ldap-external-authenticator) and [Directory](/core/concepts/features/security/external-authenticators/ldap#ldap-external-user-directory)
- Kerberos [Authenticator](/core/concepts/features/security/external-authenticators/kerberos#kerberos-as-an-external-authenticator-for-existing-users)
- [SSL X.509 authentication](/core/concepts/features/security/external-authenticators/ssl-x509)
- HTTP [Authenticator](/core/concepts/features/security/external-authenticators/http)
