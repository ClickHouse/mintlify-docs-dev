El protocolo nativo se utiliza en el [cliente de línea de comandos](/es/concepts/features/interfaces/cli), para la comunicación entre servidores durante el procesamiento de consultas distribuidas, y también en otros programas de C++. Lamentablemente, el protocolo nativo de ClickHouse aún no tiene una especificación formal, pero puede deducirse mediante ingeniería inversa a partir del código fuente de ClickHouse (empezando [aproximadamente aquí](https://github.com/ClickHouse/ClickHouse/tree/master/src/Client)) y/o interceptando y analizando el tráfico TCP.
