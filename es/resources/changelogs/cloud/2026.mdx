<div id="clickstack-cloud">
  ### Vista previa privada de ClickStack Cloud
</div>

ClickStack Cloud es una plataforma de observabilidad totalmente gestionada y sin servidor, basada en ClickHouse Cloud. Los equipos pueden enviar datos de OpenTelemetry a un endpoint gestionado y explorar de inmediato logs, métricas y trazas sin tener que operar infraestructura de observabilidad. Disponible en vista previa privada en AWS us-east-1. Consulta la [entrada del blog](https://clickhouse.com/blog/clickstack-cloud-private-preview) para más detalles y apúntate a la [lista de espera](https://clickhouse.com/cloud/clickstack-cloud-waitlist) para obtener acceso.

<div id="ai-notebooks-clickstack">
  ### AI Notebooks para Managed ClickStack (beta)
</div>

AI Notebooks ya está disponible en beta para Managed ClickStack y ofrece a los SRE y a los equipos de ingeniería espacios de trabajo persistentes y transparentes para la investigación de incidentes asistida por IA. Notebooks permite secuencias estructuradas de prompts, consultas, gráficos, pasos de razonamiento y hallazgos, con flujos de trabajo con ramificaciones para explorar múltiples hipótesis. Consulta la [documentación](/es/clickstack/notebooks) para obtener más información.

<div id="clickstack-mcp-server">
  ### ClickStack MCP Server
</div>

El nuevo ClickStack MCP Server de código abierto ofrece a agentes de IA externos herramientas estructuradas para la investigación de observabilidad, basadas en ClickStack y ClickHouse. Expone primitivas semánticas de investigación para logs, métricas y trazas, así como primitivas de orquestación bidireccional para crear dashboards, guardar búsquedas y alertas. Consulta la [documentación](/es/clickstack/mcp) y la [entrada del blog](https://clickhouse.com/blog/observability-mcp-server-ai-notebooks#clickstack-mcp-server) para obtener más información.

<div id="executable-udfs">
  ### UDF ejecutables (beta pública)
</div>

Las UDF ejecutables ya están en beta pública en ClickHouse Cloud. Puedes escribir una función en Python, subirla a tu clúster y llamarla desde SQL como cualquier función integrada. ClickHouse ejecuta un conjunto de procesos aislados y de larga duración, y hace pasar las filas por ellos a velocidad de consulta, por lo que puedes usar tu función en cualquier lugar donde funcione SQL: consultas ad hoc, joins e incluso vistas materializadas que se activan con cada insert. Lee el [anuncio en el blog](https://clickhouse.com/blog/executable-udfs-clickhouse-cloud-beta) para obtener más información.

<div id="clickpipes-gcp-native">
  ### ClickPipes funciona de forma nativa en GCP
</div>

La infraestructura de ClickPipes ahora funciona de forma nativa en GCP para todos los nuevos servicios de ClickHouse Cloud alojados en GCP (creados después del 26 de mayo), incluida la compatibilidad con Private Service Connect (PSC). Esto elimina los costos de salida entre nubes, permite redes privadas nativas de GCP, reduce la latencia y ofrece garantías de residencia de los datos. Consulta la [lista de regiones de GCP compatibles](/es/integrations/clickpipes#list-of-static-ips).

<div id="clickpipes-pubsub">
  ### ClickPipes para GCP Pub/Sub (vista previa privada)
</div>

ClickPipes ahora permite transmitir datos desde temas de GCP Pub/Sub directamente a ClickHouse Cloud. Disponible en vista previa privada — [regístrese](https://clickhouse.com/cloud/clickpipes#pubsub-private-preview) para obtener acceso. Consulte la [documentación](/es/integrations/clickpipes/pubsub) para obtener más detalles.

<div id="clickhouse-agents">
  ### ClickHouse Agents — analítica con agentes (beta pública)
</div>

ClickHouse Agents ya está en beta pública: una solución nativa de analítica con agentes impulsada por Claude que permite a los usuarios crear, ejecutar y orquestar agentes sobre sus datos de ClickHouse. Entre sus capacidades se incluyen análisis conversacional con reconocimiento de schema, AgentBuilder con compatibilidad con MCP, topologías de subagentes y generación de código. Disponible en [ai.clickhouse.cloud](https://ai.clickhouse.cloud).

<div id="clickhouse-postgres">
  ### ClickHouse Postgres (beta pública)
</div>

Postgres totalmente gestionado con almacenamiento NVMe local ya está disponible en beta pública y ofrece más de 5 veces el TPS de AWS RDS. Un pipeline nativo de CDC transmite datos directamente a ClickHouse sin infraestructura intermedia. La extensión de código abierto pg&#95;clickhouse permite a los desarrolladores consultar tablas de ClickHouse desde sesiones estándar de Postgres. Consulta la [entrada del blog](https://clickhouse.com/blog/postgres-managed-by-clickhouse-beta) para obtener más información.

<div id="horizontal-autoscaling">
  ### Autoscaling horizontal (vista previa privada)
</div>

El autoscaling horizontal ajusta automáticamente el número de réplicas en un clúster de ClickHouse Cloud en función del número de consultas concurrentes, aumentando el número de réplicas cuando se dispara la demanda y reduciéndolo cuando baja la carga. Disponible en vista previa privada para clientes de Enterprise y Scale tier en ClickHouse 26.2+. Póngase en contacto con soporte e indique su Organization ID para habilitarlo.

<div id="spend-alerts-ga">
  ### Lanzamiento GA de las alertas de gasto de la organización
</div>

Las alertas de gasto de la organización ya están disponibles de forma general. Reciba notificaciones cuando el gasto configurado de su organización por período de facturación alcance el 50 %, 75 % y 100 %. Elija correo electrónico, Cloud console (UI) y/o Slack como canales de notificación. Las alertas se basan en el uso bruto de la organización, se envían cada hora y se restablecen automáticamente en cada período de facturación. Requiere el rol Org Admin o Billing Admin.

<div id="clickpipes-aws-mx-central-1">
  ### Nuevas regiones de AWS para ClickPipes
</div>

La región de AWS `mx-central-1` (México Central) ya está disponible para [ClickPipes](/es/integrations/clickpipes), tras el lanzamiento de la región de Cloud. En el caso de los servicios de ClickHouse Cloud creados en esta región a partir del 19 de mayo de 2026, ClickPipes estará en la misma región. Para los servicios creados antes de esa fecha, ClickPipes usará de forma predeterminada la región `us-east-2`; si ese es el caso, [póngase en contacto con nuestro equipo](https://clickhouse.com/company/contact?loc=clickpipes) para que actualice su servicio y use la nueva región.

<div id="postgres-query-insights">
  ### Query insights de Postgres (vista previa privada)
</div>

Una nueva pestaña de **Query insights** ya está disponible en [ClickHouse Cloud Managed Postgres](/es/products/managed-postgres/overview) (vista previa privada). Clasifica cada patrón de consulta según su impacto y muestra por qué cada uno es lento en tres vistas:

* **Overview** — estado general de la base de datos en una sola pantalla
* **Patterns** — tabla ordenable por tiempo de ejecución, CPU, errores y P95
* **Flyout por patrón** — percentiles de latencia, CPU frente a I/O, caché frente a disco, spills temporales a disco, falta de workers paralelos y volumen de WAL

Basado en [pg&#95;stat&#95;ch](https://github.com/ClickHouse/pg_stat_ch), una extensión de Postgres de código abierto.

<div id="index-sharding">
  ### Segmentación de índices (vista previa privada)
</div>

La segmentación de índices ya está disponible en vista previa privada. Esta funcionalidad distribuye la fase de análisis de índices entre varias réplicas, lo que reduce el uso de memoria por réplica y mejora el rendimiento de las consultas mediante paralelización distribuida. Esto resulta especialmente beneficioso para tablas con índices secundarios de gran tamaño, como los de búsqueda vectorial y búsqueda de texto completo. Consulta la [entrada del blog](https://clickhouse.com/blog/index-sharding-clickhouse-cloud-petabyte-scale-indexing) para obtener más información.

Esto incluye cobertura completa para conectores CDC (Postgres, MySQL, MongoDB). Consulta la [documentación de Terraform](/es/integrations/clickpipes/programmatic-access/terraform), la [documentación de OpenAPI](/es/integrations/clickpipes/programmatic-access/openapi) y la [entrada del blog](https://clickhouse.com/blog/terraform-ga) para obtener más información.

<div id="centralized-marketplace-billing">
  ### Facturación centralizada del marketplace
</div>

Ahora los clientes pueden consolidar la facturación entre organizaciones mediante una única suscripción del marketplace en la nube (AWS, Azure y GCP). Las principales novedades incluyen:

* **Compartir suscripciones de marketplace:** Cambie una organización de la facturación con tarjeta de crédito a una suscripción de marketplace existente de otra organización, lo que elimina la necesidad de configurar una suscripción de marketplace adicional. Solo se consolida el uso de PAYG (no los créditos prepagados).
* **Actualizar suscripciones de marketplace:** Cambie la suscripción de marketplace de una organización por la que utiliza otra organización.
* **Método de pago de respaldo:** Las organizaciones con facturación de marketplace ahora pueden añadir una tarjeta de crédito como alternativa si la suscripción de marketplace principal se cancela o vence.

Consulte la [documentación de facturación](/es/products/cloud/reference/billing/managing-payment-methods) para obtener más información.

<div id="april-3-2026">
  ## 3 de abril de 2026
</div>

* **Escalado automático más inteligente con recomendador de dos ventanas:** ClickHouse Cloud ahora utiliza un enfoque de doble ventana retrospectiva para el escalado automático vertical, sustituyendo la anterior ventana única de 30 horas por una combinación de una &quot;ventana pequeña&quot; de 3 horas y una &quot;ventana grande&quot; de 30 horas. Esto reduce la latencia de scale-down de hasta 30 horas a tan solo 3 horas, lo que disminuye los costos de infraestructura para cargas de trabajo variables sin sacrificar la capacidad de respuesta del scale-up. Lee la [entrada del blog](https://clickhouse.com/blog/smarter-auto-scaling) para obtener más detalles.
* **Monitoring en Cloud Console:** Los nuevos paneles de Overview e infraestructura ofrecen una mejor visibilidad del comportamiento de los servidores de ClickHouse. Los usuarios Admin ahora reciben notificaciones por correo electrónico sobre problemas comunes al usar ClickHouse Cloud. Lee la [entrada del blog](https://clickhouse.com/blog/clickhouse-cloud-new-monitoring-capabilities) para obtener más detalles.
* **Compute-compute separation (warehouses):** La compatibilidad con auto-idling en los primary services (también denominados parent services) ya se está implementando como vista previa pública. Si la función no está habilitada para tu organización, [contacta con soporte](https://clickhouse.com/support/program) para obtener acceso. Una vez que la función pase a disponibilidad general, el comportamiento predeterminado será que los primary services existentes tendrán la opción de activar el auto-idling y los nuevos primary services lo tendrán habilitado de forma predeterminada.
* **Integración de catálogo de datos:** ClickHouse Cloud ahora admite Iceberg REST Catalog y Microsoft OneLake como integraciones de catálogo de lago de datos en la UI de fuentes de datos. Una vez conectado, el catálogo aparece como una base de datos, lo que te permite leer tablas Iceberg directamente, sin duplicar datos.
* **Bring Your Own Cloud (BYOC) en GCP ya está generalmente disponible:** ClickHouse BYOC ahora es GA en Google Cloud, lo que te permite implementar servicios de ClickHouse en tu propio proyecto de GCP y cumplir requisitos estrictos de residencia de datos. Lee la [documentación](/es/products/cloud/guides/infrastructure/deployment-options/byoc/overview) y la [entrada del blog](https://clickhouse.com/blog/byoc-gcp-ga) para obtener más detalles. Puedes [contactarnos](https://clickhouse.com/cloud/bring-your-own-cloud) para solicitar acceso.
* **Notificaciones de facturación para créditos prepagados y cambios en el método de pago:** ClickHouse Cloud ahora envía notificaciones cuando se añaden créditos prepagados a tu organización tras la formalización de un contrato, o cuando se actualiza un método de pago (tarjeta de crédito o suscripción del marketplace). Las notificaciones están habilitadas de forma predeterminada para la UI y el correo electrónico, y también se pueden configurar para enviarse a Slack.
