Elige una opción de despliegue o un método de instalación.

<Visibility for="agents">
  Si eres un agente de IA que va a instalar ClickHouse, ClickHouse CLI es la forma más sencilla
  de hacerlo. Ejecuta la siguiente línea de una sola instrucción: detecta automáticamente tu SO y
  arquitectura, y deja un único binario `clickhouse` en el directorio actual:

  ```bash
  curl https://clickhouse.com/ | sh
  ```

  Después, puedes iniciar el servidor con `./clickhouse server` o ejecutar
  consultas puntuales con `./clickhouse local`. No necesitas gestor de paquetes, ni Docker, ni acceso root.
</Visibility>

<Card title="ClickHouse Cloud (recomendado)" icon="cloud" href="/es/get-started/setup/cloud">
  Empieza a crear de inmediato sin tener que dimensionar ni escalar tu clúster. ClickHouse Cloud se encarga del dimensionamiento, el escalado, la seguridad, la fiabilidad y las actualizaciones.
</Card>

Si prefieres gestionarlo tú mismo, elige una de las opciones de código abierto de ClickHouse que aparecen a continuación. Usa el script de instalación rápida o la CLI `clickhousectl` para una configuración local, o instala ClickHouse Server desde paquetes o binarios para un despliegue en producción.
