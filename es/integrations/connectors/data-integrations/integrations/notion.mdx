[Notion](https://www.notion.com/) es un espacio de trabajo conectado para notas, documentos, proyectos y Custom Agents impulsados por IA.

Puedes conectar ClickHouse Cloud a un [Custom Agent](https://www.notion.com/help/mcp-connections-for-custom-agents) de Notion como un MCP Server personalizado. Una vez conectado, el agente puede explorar tus datos, ejecutar consultas analíticas en modo de solo lectura y mostrar información sobre el servicio y los costos de ClickHouse Cloud sin salir de Notion.

<div id="prerequisites">
  ## Requisitos previos
</div>

* Un [servicio de ClickHouse Cloud](/es/get-started/setup/cloud) en funcionamiento con el [servidor MCP remoto activado](/es/products/cloud/features/ai-ml/mcp/remote-mcp#enable-remote-mcp-server)
* Un espacio de trabajo de Notion con el plan **Business** o **Enterprise**
* Un administrador del espacio de trabajo ha habilitado **Custom MCP servers** en **Settings** &gt; **Notion AI** &gt; **AI connectors**

<div id="connect-clickhouse-to-notion">
  ## Conecta ClickHouse con un Custom Agent de Notion
</div>

1. En Notion, abre el Custom Agent que quieres extender y haz clic en **Settings**.
2. En **Tools &amp; Access**, haz clic en **Add connection** y elige **Custom MCP server**.

{/* TODO(screenshot): el menú "Agregar conexión" dentro de "Herramientas y acceso" del agente, que muestra la opción "Custom MCP server" */}

3. Introduce la URL del servidor MCP remoto de ClickHouse Cloud y asigna a la conexión un nombre visible, como `ClickHouse`:

   ```text
   https://mcp.clickhouse.cloud/mcp
   ```

{/* TODO(captura de pantalla): la ventana modal del Custom MCP server con la URL del servidor y el nombre para mostrar ya completados */}

4. Haz clic en **Guardar** y, a continuación, completa el flujo de OAuth para autenticarte con tus credenciales de ClickHouse Cloud. El acceso se limita a las organizaciones y los servicios a los que tu cuenta ya tiene acceso.

{/* TODO(captura de pantalla): la pantalla de consentimiento de OAuth / estado de confirmación de "Conectado" */}

5. Despliega la nueva conexión para revisar las [herramientas disponibles de ClickHouse](/es/products/cloud/features/ai-ml/remote-mcp#available-tools) y activa las que quieras que use este agente. Todas las herramientas de ClickHouse Remote MCP son de solo lectura.

{/* TODO(captura de pantalla): la conexión de ClickHouse expandida, mostrando la lista de controles para activar o desactivar herramientas */}

<Note>
  Cada Custom Agent requiere su propia conexión a ClickHouse, y solo la persona que autenticó una conexión puede cambiar la configuración de sus herramientas. Consulta las [prácticas recomendadas de seguridad de Notion para las conexiones de agentes](https://www.notion.com/help/security-best-practices-for-agent-connections) para obtener más información.
</Note>

<div id="example-prompts">
  ## Prompts de ejemplo
</div>

Una vez conectado, puedes hacerle preguntas al Custom Agent en lenguaje natural. Algunos ejemplos:

| Prompt                                                                            | Herramienta invocada    |
| --------------------------------------------------------------------------------- | ----------------------- |
| &quot;¿Qué bases de datos hay disponibles en mi servicio de ClickHouse?&quot;     | `list_databases`        |
| &quot;Muéstrame las 10 primeras filas de la tabla `hits`&quot;                    | `run_select_query`      |
| &quot;¿Cuál fue el costo de ClickHouse de mi organización la semana pasada?&quot; | `get_organization_cost` |
| &quot;Muestra las copias de seguridad recientes de este servicio&quot;            | `list_service_backups`  |

Para consultar el conjunto completo de patrones en lenguaje natural y herramientas, consulta la sección [uso de ejemplo de Remote MCP](/es/products/cloud/features/ai-ml/mcp/remote-mcp#example-usage).
