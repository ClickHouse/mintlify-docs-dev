<div id="migration">
  # Migración
</div>

Herramientas de un solo uso y datos utilizados para migrar la documentación de ClickHouse de Docusaurus
a Mintlify. **Toda esta carpeta puede eliminarse una vez completada la migración** — nada del sitio en producción depende de ella durante la ejecución.

<div id="contents">
  ## Contenido
</div>

* `slug-map.csv` — correspondencia de cada slug de Docusaurus → archivo/URL de Mintlify, con
  hash de origen y migrado para detectar desactualizaciones.
* `slug-aliases.csv` — alias revisados manualmente para slugs que no pudieron
  resolverse automáticamente.
* `migrate.py` — script principal de migración. Lee `slug-map.csv`, aplica
  las transformaciones necesarias para Mintlify y escribe el resultado.
* `generate-slug-map.py` — regenera `slug-map.csv` a partir de Docusaurus upstream
  * la estructura actual de este repositorio.
* `apply-slug-aliases.py` — reescribe los marcadores `<!-- MIGRATE: unknown slug -->`
  usando `slug-aliases.csv`.
* `suggest-slug-aliases.py` — propone posibles alias para slugs no resueltos.
* `match_slugless.py` — encuentra páginas de Mintlify sin un slug upstream coincidente.
* `verify_mapping.py` — verifica el mapa de slugs para detectar duplicados o desajustes.
* `find_dup_imports.py` — detecta conflictos de importación de MDX causados por Mintlify
  al mover las importaciones de fragmentos al paquete padre.

Consulta `.claude/skills/migrate-docusaurus-to-mintlify/SKILL.md` para ver el
flujo de trabajo de migración.
