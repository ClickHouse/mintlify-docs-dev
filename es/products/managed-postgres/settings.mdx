Puedes modificar los parámetros de configuración y gestionar la configuración de tu instancia de Managed Postgres desde la pestaña **Configuración** de la barra lateral.

<div id="changing-configuration">
  ## Cambiar parámetros de configuración
</div>

<Image img="/images/managed-postgres/postgres-parameters.png" alt="Configuración de parámetros de Postgres" size="md" border />

Para modificar un parámetro, selecciona el botón **Edit parameters**. Selecciona los parámetros que quieras modificar y cambia sus valores según corresponda. Cuando hayas terminado, pulsa el botón **Save Changes**.

Todos los cambios realizados en los parámetros de configuración suelen persistirse en la instancia en un plazo de un minuto. Algunos parámetros requieren reiniciar la base de datos para que surtan efecto. Estos cambios se aplicarán después del siguiente reinicio, que puedes activar manualmente desde la barra de herramientas **Service actions**.

<div id="service-actions">
  ## Service actions y escalado
</div>

<Image img="/images/managed-postgres/service-actions.png" alt="Service actions y escalado" size="md" border />

La barra de herramientas **Service actions** proporciona controles para administrar tu instancia de Managed Postgres:

* **Reset password**: Actualiza la contraseña del superusuario (solo cuando la instancia está en estado `Running`)
* **Restart**: Reinicia la instancia de base de datos (solo cuando la instancia está en estado `Running`)
* **Delete**: Elimina la instancia

La sección **Scaling** te permite cambiar los tipos de instancia de tu instancia primaria y tus instancias en espera para aumentar o reducir los recursos de cómputo y la capacidad de almacenamiento. En segundo plano, se aprovisionarán nuevas instancias y pasarán a estar activas una vez que se hayan puesto al día con la primaria actual. El proceso de failover interrumpirá todas las conexiones actuales y provocará una breve interrupción del servicio.

<Tip>
  Por motivos de seguridad, es posible que no puedas cambiar a tipos de instancia cuya capacidad de almacenamiento se acerque a la que tienes actualmente en uso. Elige siempre tipos de instancia con holgura por encima de tu capacidad actual en uso para evitar problemas.
</Tip>

<div id="ip-filters">
  ## Filtros IP
</div>

Los filtros IP controlan qué direcciones IP de origen pueden conectarse a su instancia de Managed Postgres.

<Image img="/images/managed-postgres/ip-filters.png" alt="Configuración de la lista de acceso IP" size="md" border />

Para configurar los filtros IP:

1. Vaya a la pestaña **Configuración**
2. En **Filtros IP**, haga clic en **Edit**
3. Agregue las direcciones IP o los rangos CIDR a los que se debe permitir la conexión
4. Haga clic en **Guardar** para aplicar los cambios

Puede especificar direcciones IP individuales o usar la notación CIDR para rangos de IP (p. ej., `192.168.1.0/24`). También puede seleccionar **Anywhere** o **Nowhere** como atajo para abrir o cerrar completamente la instancia al acceso desde cualquier lugar.

<Note>
  Si no se configura ningún filtro IP, se permiten conexiones desde todas las direcciones IP. Para cargas de trabajo de producción, recomendamos restringir el acceso a direcciones IP conocidas.
</Note>
