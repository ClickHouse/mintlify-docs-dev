<div id="description">
  ## Descripción
</div>

Contiene información sobre el estado de los [nodos de planificación](/es/concepts/features/configuration/server-config/workload-scheduling#hierarchy) que residen en el servidor local.
Esta tabla puede usarse para la monitorización. La tabla contiene una fila por cada nodo de planificación.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `resource` ([String](/es/reference/data-types)) — Nombre del recurso
* `path` ([String](/es/reference/data-types)) — Ruta a un nodo de planificación dentro de esta jerarquía de planificación de recursos
* `type` ([String](/es/reference/data-types)) — Tipo de nodo de planificación.
* `weight` ([Float64](/es/reference/data-types)) — Peso de un nodo, que usa un nodo padre de tipo `fair`.
* `priority` ([Int64](/es/reference/data-types)) — Prioridad de un nodo, utilizada por un nodo padre de tipo &#39;priority&#39; (un valor más bajo significa una prioridad más alta).
* `is_active` ([UInt8](/es/reference/data-types)) — Indica si este nodo está activo actualmente; es decir, si tiene solicitudes de recursos para desencolar y se cumplen las restricciones.
* `active_children` ([UInt64](/es/reference/data-types)) — Número de hijos en estado activo.
* `dequeued_requests` ([UInt64](/es/reference/data-types)) — Número total de solicitudes de recursos desencoladas de este nodo.
* `canceled_requests` ([UInt64](/es/reference/data-types)) — Número total de solicitudes de recursos canceladas de este nodo.
* `dequeued_cost` ([Int64](/es/reference/data-types)) — Suma de los costes (p. ej., tamaño en bytes) de todas las solicitudes desencoladas de este nodo.
* `throughput` ([Float64](/es/reference/data-types)) — Rendimiento medio actual (coste desencolado por segundo).
* `canceled_cost` ([Int64](/es/reference/data-types)) — Suma de los costes (p. ej., tamaño en bytes) de todas las solicitudes canceladas de este nodo.
* `busy_periods` ([UInt64](/es/reference/data-types)) — Número total de desactivaciones de este nodo.
* `vruntime` ([Nullable(Float64)](/es/reference/data-types)) — Solo para hijos de nodos `fair`. Tiempo de ejecución virtual de un nodo, utilizado por el algoritmo SFQ para seleccionar el siguiente hijo que se procesará de forma max-min justa.
* `system_vruntime` ([Nullable(Float64)](/es/reference/data-types)) — Solo para nodos `fair`. Tiempo de ejecución virtual que muestra el `vruntime` de la última solicitud de recurso procesada. Se utiliza durante la activación del hijo como nuevo valor de `vruntime`.
* `queue_length` ([Nullable(UInt64)](/es/reference/data-types)) — Solo para nodos `fifo`. Número actual de solicitudes de recursos presentes en la cola.
* `queue_cost` ([Nullable(Int64)](/es/reference/data-types)) — Solo para nodos fifo. Suma de los costes (p. ej., tamaño en bytes) de todas las solicitudes presentes en la cola.
* `budget` ([Nullable(Int64)](/es/reference/data-types)) — Solo para nodos fifo. Número de &#39;unidades de coste&#39; disponibles para nuevas solicitudes de recursos. Puede aparecer en caso de discrepancia entre los costes estimados y reales de las solicitudes de recursos (p. ej., después de un fallo de lectura/escritura)
* `is_satisfied` ([Nullable(UInt8)](/es/reference/data-types)) — Solo para nodos de restricción (p. ej., `inflight_limit`). Es `1` si se cumplen todas las restricciones de este nodo.
* `inflight_requests` ([Nullable(Int64)](/es/reference/data-types)) — Solo para nodos `inflight_limit`. Número de solicitudes de recursos desencoladas de este nodo que se encuentran actualmente en estado de consumo.
* `inflight_cost` ([Nullable(Int64)](/es/reference/data-types)) — Solo para nodos `inflight_limit`. Suma de los costes (p. ej., bytes) de todas las solicitudes de recursos desencoladas de este nodo que se encuentran actualmente en estado de consumo.
* `max_requests` ([Nullable(Int64)](/es/reference/data-types)) — Solo para nodos `inflight_limit`. Límite superior de inflight&#95;requests que da lugar a una violación de las restricciones.
* `max_cost` ([Nullable(Int64)](/es/reference/data-types)) — Solo para nodos `inflight_limit`. Límite superior de inflight&#95;cost que da lugar a una violación de las restricciones.
* `max_speed` ([Nullable(Float64)](/es/reference/data-types)) — Solo para nodos `bandwidth_limit`. Límite superior del ancho de banda en tokens por segundo.
* `max_burst` ([Nullable(Float64)](/es/reference/data-types)) — Solo para nodos `bandwidth_limit`. Límite superior de tokens disponibles en el throttler token-bucket.
* `throttling_us` ([Nullable(Int64)](/es/reference/data-types)) — Solo para nodos `bandwidth_limit`. Número total de microsegundos durante los que este nodo estuvo en estado de throttling.
* `tokens` ([Nullable(Float64)](/es/reference/data-types)) — Solo para nodos `bandwidth_limit`. Número de tokens disponibles actualmente en el throttler token-bucket.

{/*AUTOGENERATED_END*/}
