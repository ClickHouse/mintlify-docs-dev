<div id="description">
  ## Descripción
</div>

Contiene una lista de todos los formatos, junto con indicadores de si un formato es adecuado para la entrada/salida o si admite paralelización.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/es/reference/data-types)) — Nombre del formato.
* `is_input` ([UInt8](/es/reference/data-types)) — Indicador de si el formato es adecuado para la entrada de datos.
* `is_output` ([UInt8](/es/reference/data-types)) — Indicador de si el formato es adecuado para la salida de datos.
* `supports_parallel_parsing` ([UInt8](/es/reference/data-types)) — Indicador de si el formato admite el análisis en paralelo.
* `supports_parallel_formatting` ([UInt8](/es/reference/data-types)) — Indicador de si el formato admite el formateo en paralelo.
* `is_tty_friendly` ([UInt8](/es/reference/data-types)) — Indicador de si el formato suele mostrarse correctamente en la terminal. Para otros formatos, la CLI pedirá confirmación antes de generar la salida.
* `content_type` ([String](/es/reference/data-types)) — HTTP Content-Type correspondiente al formato de salida. Puede depender de la configuración actual del formato.
* `supports_random_access` ([UInt8](/es/reference/data-types)) — Indicador de si el formato admite acceso aleatorio en la entrada.
* `has_schema_inference` ([UInt8](/es/reference/data-types)) — El formato puede determinar dinámicamente el esquema a partir de los datos (ya sea desde un encabezado o metadatos integrados, o desde el propio fragmento de datos).
* `has_external_schema` ([UInt8](/es/reference/data-types)) — El formato tiene un esquema fijo o acepta un esquema predefinido en su propio formato.
* `prefers_large_blocks` ([UInt8](/es/reference/data-types)) — El formato escribirá blocks más grandes en la salida y generará blocks más grandes en la entrada.
* `supports_append` ([UInt8](/es/reference/data-types)) — Es posible añadir datos a un único archivo con este formato.
* `supports_subsets_of_columns` ([UInt8](/es/reference/data-types)) — El formato de entrada puede reconocer cuándo se omiten determinadas columnas.

{/*AUTOGENERATED_END*/}
