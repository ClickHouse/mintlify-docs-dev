<div id="description">
  ## Descripción
</div>

Contiene la descripción de los motores de tabla compatibles con el servidor y la información sobre la compatibilidad de sus funciones.

Esta tabla contiene las siguientes columnas (el tipo de columna se muestra entre paréntesis):

{/*AUTOGENERATED_START*/}

* `name` ([String](/es/reference/data-types)) — El nombre del motor de tabla.
* `supports_settings` ([UInt8](/es/reference/data-types)) — Indicador que indica si el motor de tabla admite la cláusula SETTINGS.
* `supports_skipping_indices` ([UInt8](/es/reference/data-types)) — Indicador que indica si el motor de tabla admite índices de omisión.
* `supports_projections` ([UInt8](/es/reference/data-types)) — Indicador que indica si el motor de tabla admite proyecciones.
* `supports_sort_order` ([UInt8](/es/reference/data-types)) — Indicador que indica si el motor de tabla admite las cláusulas PARTITION&#95;BY, PRIMARY&#95;KEY, ORDER&#95;BY y SAMPLE&#95;BY.
* `supports_ttl` ([UInt8](/es/reference/data-types)) — Indicador que indica si el motor de tabla admite TTL.
* `supports_replication` ([UInt8](/es/reference/data-types)) — Indicador que indica si el motor de tabla admite la replicación de datos.
* `supports_deduplication` ([UInt8](/es/reference/data-types)) — Indicador que indica si el motor de tabla admite la deduplicación de datos.
* `supports_parallel_insert` ([UInt8](/es/reference/data-types)) — Indicador que indica si el motor de tabla admite insert en paralelo (consulte el ajuste max&#95;insert&#95;threads).

{/*AUTOGENERATED_END*/}
