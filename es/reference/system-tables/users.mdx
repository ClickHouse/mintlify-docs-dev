<div id="description">
  ## Descripción
</div>

Contiene una lista de [cuentas de usuario](/es/concepts/features/security/access-rights#user-account-management) configuradas en el servidor.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/es/reference/data-types)) — Nombre de usuario.
* `id` ([UUID](/es/reference/data-types)) — ID del usuario.
* `storage` ([String](/es/reference/data-types)) — Ruta al almacenamiento de usuarios. Se configura en el parámetro access&#95;control&#95;path.
* `auth_type` ([Array(Enum8(&#39;no&#95;password&#39; = 0, &#39;plaintext&#95;password&#39; = 1, &#39;sha256&#95;password&#39; = 2, &#39;double&#95;sha1&#95;password&#39; = 3, &#39;ldap&#39; = 4, &#39;kerberos&#39; = 5, &#39;ssl&#95;certificate&#39; = 6, &#39;bcrypt&#95;password&#39; = 7, &#39;ssh&#95;key&#39; = 8, &#39;http&#39; = 9, &#39;jwt&#39; = 10, &#39;scram&#95;sha256&#95;password&#39; = 11, &#39;no&#95;authentication&#39; = 12))](/es/reference/data-types)) — Muestra los tipos de autenticación. Existen varias formas de identificar usuarios: sin contraseña, con contraseña en texto plano, con contraseña codificada con SHA256, con contraseña codificada con doble SHA-1 o con contraseña codificada con bcrypt.
* `auth_params` ([Array(String)](/es/reference/data-types)) — Parámetros de autenticación en formato JSON según el auth&#95;type.
* `valid_until` ([Array(DateTime)](/es/reference/data-types)) — Fecha y hora de vencimiento de las credenciales del usuario.
* `host_ip` ([Array(String)](/es/reference/data-types)) — Direcciones IP de los hosts desde los que se permite la conexión al servidor de ClickHouse.
* `host_names` ([Array(String)](/es/reference/data-types)) — Nombres de los hosts desde los que se permite la conexión al servidor de ClickHouse.
* `host_names_regexp` ([Array(String)](/es/reference/data-types)) — Expresión regular para los nombres de host desde los que se permite la conexión al servidor de ClickHouse.
* `host_names_like` ([Array(String)](/es/reference/data-types)) — Nombres de los hosts desde los que se permite la conexión al servidor de ClickHouse, definidos mediante el predicado LIKE.
* `default_roles_all` ([UInt8](/es/reference/data-types)) — Indica que todos los roles otorgados se establecen como predeterminados para el usuario.
* `default_roles_list` ([Array(String)](/es/reference/data-types)) — Lista de roles otorgados de forma predeterminada.
* `default_roles_except` ([Array(String)](/es/reference/data-types)) — Todos los roles otorgados se establecen como predeterminados, excepto los de la lista.
* `grantees_any` ([UInt8](/es/reference/data-types)) — Indicador de si un usuario con cualquier opción de grant puede otorgarla a cualquiera.
* `grantees_list` ([Array(String)](/es/reference/data-types)) — Lista de usuarios o roles a los que este usuario puede otorgar opciones.
* `grantees_except` ([Array(String)](/es/reference/data-types)) — Lista de usuarios o roles a los que este usuario no puede otorgar opciones.
* `default_database` ([String](/es/reference/data-types)) — Nombre de la base de datos predeterminada de este usuario.
