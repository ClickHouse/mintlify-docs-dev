<div id="description">
  ## Descripción
</div>

Contiene una lista de todos los combinadores de funciones de agregación disponibles, que se pueden aplicar a las funciones de agregación para cambiar su funcionamiento.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/es/reference/data-types)) — El nombre del combinador.
* `is_internal` ([UInt8](/es/reference/data-types)) — Indica si este combinador es solo para uso interno.

{/*AUTOGENERATED_END*/}
