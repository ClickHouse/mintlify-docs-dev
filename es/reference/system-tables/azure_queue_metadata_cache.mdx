<div id="description">
  ## Descripción
</div>

Contiene el estado en memoria de los metadatos de AzureQueue y las filas que se están procesando actualmente por archivo.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `zookeeper_path` ([String](/es/reference/data-types)) — Ruta en ZooKeeper a los metadatos
* `file_path` ([String](/es/reference/data-types)) — Ruta del archivo que se está procesando
* `file_name` ([String](/es/reference/data-types)) — Nombre del archivo que se está procesando
* `rows_processed` ([UInt64](/es/reference/data-types)) — Número de filas procesadas actualmente
* `status` ([String](/es/reference/data-types)) — Estado del procesamiento: Processed, Processing, Failed
* `processing_start_time` ([Nullable(DateTime)](/es/reference/data-types)) — Hora a la que comenzó el procesamiento del archivo
* `processing_end_time` ([Nullable(DateTime)](/es/reference/data-types)) — Hora a la que terminó el procesamiento del archivo
* `exception` ([String](/es/reference/data-types)) — Excepción producida durante el procesamiento

{/*AUTOGENERATED_END*/}
