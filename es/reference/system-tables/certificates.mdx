<div id="description">
  ## Descripción
</div>

Contiene información sobre los certificados disponibles y sus fuentes.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `version` ([Int32](/es/reference/data-types)) — Versión del certificado. Los valores son 0 para v1, 1 para v2 y 2 para v3.
* `serial_number` ([Nullable(String)](/es/reference/data-types)) — Número de serie del certificado asignado por el emisor.
* `signature_algo` ([Nullable(String)](/es/reference/data-types)) — Algoritmo de firma: algoritmo utilizado por el emisor para firmar este certificado.
* `issuer` ([Nullable(String)](/es/reference/data-types)) — Emisor: identificador único de la autoridad de certificación que emite este certificado.
* `not_before` ([Nullable(String)](/es/reference/data-types)) — Inicio del periodo durante el que este certificado es válido.
* `not_after` ([Nullable(String)](/es/reference/data-types)) — Fin del periodo durante el que este certificado es válido.
* `subject` ([Nullable(String)](/es/reference/data-types)) — Titular: identifica al propietario de la clave pública.
* `pkey_algo` ([Nullable(String)](/es/reference/data-types)) — El algoritmo de clave pública define con qué algoritmo se puede usar la clave pública.
* `path` ([String](/es/reference/data-types)) — Ruta al archivo o directorio que contiene este certificado.
* `default` ([UInt8](/es/reference/data-types)) — El certificado está en la ubicación predeterminada para certificados.
* `protocol` ([String](/es/reference/data-types)) — Nombre del protocolo si el certificado proviene de una configuración de TLS por protocolo; en caso contrario, está vacío.

{/*AUTOGENERATED_END*/}
