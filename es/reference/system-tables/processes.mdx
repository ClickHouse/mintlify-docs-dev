<div id="description">
  ## Descripción
</div>

Esta tabla del sistema se utiliza para implementar la consulta `SHOW PROCESSLIST`.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `is_initial_query` ([UInt8](/es/reference/data-types)) — Indica si esta consulta proviene directamente del usuario o si fue emitida por el servidor ClickHouse en el contexto de la ejecución distribuida de consultas.
* `user` ([String](/es/reference/data-types)) — El usuario que realizó la consulta. Tenga en cuenta que, en el procesamiento distribuido, las consultas se envían a servidores remotos con el usuario `default`. El campo contiene el nombre de usuario de una consulta específica, no de una consulta iniciada por esta.
* `query_id` ([String](/es/reference/data-types)) — ID de la consulta, si está definido.
* `address` ([IPv6](/es/reference/data-types)) — La dirección IP desde la que se realizó la consulta. Lo mismo aplica al procesamiento distribuido. Para rastrear desde dónde se realizó originalmente una consulta distribuida, consulte system.processes en el servidor solicitante.
* `port` ([UInt16](/es/reference/data-types)) — El puerto del cliente desde el que se hizo la consulta.
* `initial_user` ([String](/es/reference/data-types)) — Nombre del usuario que ejecutó la consulta inicial (en la ejecución distribuida de consultas).
* `initial_query_id` ([String](/es/reference/data-types)) — ID de la consulta inicial (para la ejecución distribuida de consultas).
* `initial_address` ([IPv6](/es/reference/data-types)) — Dirección IP desde la que se inició la consulta principal.
* `initial_port` ([UInt16](/es/reference/data-types)) — El puerto del cliente utilizado para realizar la consulta principal.
* `interface` ([UInt8](/es/reference/data-types)) — La interfaz utilizada para enviar la consulta. TCP = 1, HTTP = 2, GRPC = 3, MYSQL = 4, POSTGRESQL = 5, LOCAL = 6, TCP&#95;INTERSERVER = 7.
* `os_user` ([String](/es/reference/data-types)) — Nombre de usuario del sistema operativo con el que se ejecuta clickhouse-client.
* `client_hostname` ([String](/es/reference/data-types)) — nombre de host de la máquina cliente donde se ejecuta `clickhouse-client` u otro cliente TCP.
* `client_name` ([String](/es/reference/data-types)) — El nombre de clickhouse-client o de otro cliente TCP.
* `client_revision` ([UInt64](/es/reference/data-types)) — Revisión de clickhouse-client o de cualquier otro cliente TCP.
* `client_version_major` ([UInt64](/es/reference/data-types)) — Versión principal de `clickhouse-client` o de cualquier otro cliente TCP.
* `client_version_minor` ([UInt64](/es/reference/data-types)) — Versión menor del clickhouse-client o de otro cliente TCP.
* `client_version_patch` ([UInt64](/es/reference/data-types)) — Componente de la versión correspondiente al parche de clickhouse-client o de otro cliente TCP.
* `http_method` ([UInt8](/es/reference/data-types)) — Método HTTP que inició la consulta. Posibles valores: 0 — La consulta se ejecutó desde la interfaz TCP. 1 — Se utilizó el método GET. 2 — Se utilizó el método POST.
* `http_user_agent` ([String](/es/reference/data-types)) — cabecera HTTP UserAgent enviada en la consulta HTTP.
* `http_referer` ([String](/es/reference/data-types)) — encabezado HTTP Referer enviado en la consulta HTTP (contiene una dirección absoluta o parcial de la página que realiza la consulta).
* `forwarded_for` ([String](/es/reference/data-types)) — encabezado HTTP X-Forwarded-For incluido en la consulta HTTP.
* `quota_key` ([String](/es/reference/data-types)) — La clave de cuota especificada en la configuración de cuotas (véase keyed).
* `distributed_depth` ([UInt64](/es/reference/data-types)) — El número de veces que la consulta se retransmitió internamente entre los nodos del servidor.
* `elapsed` ([Float64](/es/reference/data-types)) — El tiempo en segundos desde que se inició la ejecución de la solicitud.
* `is_cancelled` ([UInt8](/es/reference/data-types)) — Indica si la consulta fue cancelada.
* `is_all_data_sent` ([UInt8](/es/reference/data-types)) — Si se enviaron todos los datos al cliente (es decir, la consulta había finalizado en el servidor).
* `read_rows` ([UInt64](/es/reference/data-types)) — El número de filas leídas de la tabla. En el procesamiento distribuido, en el servidor solicitante, este es el total de todos los servidores remotos.
* `read_bytes` ([UInt64](/es/reference/data-types)) — El número de bytes sin comprimir leídos de la tabla. En el procesamiento distribuido, en el servidor solicitante, este valor es el total de todos los servidores remotos.
* `total_rows_approx` ([UInt64](/es/reference/data-types)) — Estimación del número total de filas que deberían leerse. En el procesamiento distribuido, en el servidor solicitante, este es el total de todos los servidores remotos. Puede actualizarse durante el procesamiento de la solicitud, a medida que se conocen nuevas fuentes que procesar.
* `written_rows` ([UInt64](/es/reference/data-types)) — El número de filas escritas en el almacenamiento.
* `written_bytes` ([UInt64](/es/reference/data-types)) — La cantidad de bytes escritos en el almacenamiento.
* `memory_usage` ([Int64](/es/reference/data-types)) — Cantidad de RAM que utiliza la consulta. Puede que no incluya algunos tipos de memoria dedicada
* `peak_memory_usage` ([Int64](/es/reference/data-types)) — El pico actual de uso de memoria.
* `query` ([String](/es/reference/data-types)) — El texto de la consulta. Para INSERT, no incluye los datos que se insertan.
* `normalized_query_hash` ([UInt64](/es/reference/data-types)) — Un valor hash numérico, idéntico para consultas que difieren solo en los valores de los literales.
* `query_kind` ([String](/es/reference/data-types)) — El tipo de consulta: SELECT, INSERT, etc.
* `thread_ids` ([Array(UInt64)](/es/reference/data-types)) — La lista de identificadores de todos los hilos que han participado en esta consulta.
* `peak_threads_usage` ([UInt64](/es/reference/data-types)) — Número máximo de hilos simultáneos que ejecutan la consulta.
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/es/reference/data-types)) — los ProfileEvents calculados para esta consulta.
* `Settings` ([Map(LowCardinality(String), LowCardinality(String))](/es/reference/data-types)) — La lista de los ajustes de usuario modificados.
* `current_database` ([String](/es/reference/data-types)) — El nombre de la base de datos actual.
* `is_internal` ([UInt8](/es/reference/data-types)) — Indica si se trata de una consulta auxiliar ejecutada internamente.

{/*AUTOGENERATED_END*/}
