  # Instale o ClickHouse usando o ClickHouse CLI
</div>

O ClickHouse CLI (`clickhousectl`) ajuda você a instalar e gerenciar versões locais do ClickHouse, iniciar servidores e executar consultas.

<Steps>
  <Step>
    ## Instale o ClickHouse CLI

    ```bash
    curl https://clickhouse.com/cli | sh
    ```

    Um alias `chctl` também é criado automaticamente para facilitar.
  </Step>

  <Step>
    ## Instale o ClickHouse

    Instale a versão mais recente do ClickHouse e defina-a como padrão:

    ```bash
    clickhousectl local use latest
    ```

    `local use` instala a versão se ela ainda não estiver presente, define-a como padrão e cria um symlink `clickhouse` em `~/.local/bin` (no seu `PATH`) para que você possa invocar o binário `clickhouse` diretamente. Assim, qualquer etapa posterior desta documentação que execute um comando `clickhouse` funcionará como está.

    Você também pode selecionar uma versão específica:

    ```bash
    clickhousectl local use 26.5            # Versão 26.5.x.x mais recente
    clickhousectl local use 26.5.2.39       # Versão exata
    ```

    <Info>
      **Use vs install**

      `clickhousectl local use <version>` instala uma versão *e* a define como padrão, atualizando o symlink `clickhouse` no seu `PATH`. Para baixar uma versão sem alterar o padrão nem atualizar o symlink, use `clickhousectl local install <version>`.
    </Info>
  </Step>

  <Step>
    ## Inicie o clickhouse-server

    ```bash
    clickhousectl local server start
    ```

    O servidor é executado em segundo plano. Para verificar se ele está em execução:

    ```bash
    clickhousectl local server list
    ```
  </Step>

  <Step>
    ## Inicie o clickhouse-client

    ```bash
    clickhousectl local client
    ```

    Você verá algo parecido com isto:

    ```response
    ClickHouse client version 24.5.1.117 (official build).
    Connecting to localhost:9000 as user default.
    Connected to ClickHouse server version 24.5.1.

    local-host :)
    ```

    Agora você já pode começar a enviar comandos SQL para o ClickHouse!

    <Tip>
      O [Quick Start](/pt-BR/get-started/setup/install) orienta você nas etapas para criar tabelas e inserir dados.
    </Tip>
  </Step>
</Steps>
