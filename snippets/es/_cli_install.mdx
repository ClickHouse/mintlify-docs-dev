<div id="install-clickhouse-using-the-clickhouse-cli">
  # Instalar ClickHouse con ClickHouse CLI
</div>

ClickHouse CLI (`clickhousectl`) le ayuda a instalar y gestionar versiones locales de ClickHouse,
iniciar servidores y ejecutar consultas.

<Steps>
  <Step>
    ## Instalar ClickHouse CLI

    ```bash
    curl https://clickhouse.com/cli | sh
    ```

    También se crea automáticamente el alias `chctl` para mayor comodidad.
  </Step>

  <Step>
    ## Instalar ClickHouse

    Instale la versión más reciente de ClickHouse y establézcala como predeterminada:

    ```bash
    clickhousectl local use latest
    ```

    `local use` instala la versión si aún no está presente, la establece como su
    predeterminada y crea un enlace simbólico `clickhouse` en `~/.local/bin` (en su `PATH`)
    para que pueda invocar directamente el binario `clickhouse`. Cualquier paso posterior en esta documentación
    que ejecute un comando `clickhouse` funcionará tal cual.

    También puede seleccionar una versión específica:

    ```bash
    clickhousectl local use 26.5            # Última versión 26.5.x.x
    clickhousectl local use 26.5.2.39       # Versión exacta
    ```

    <Info>
      **Use frente a install**

      `clickhousectl local use <version>` instala una versión *y* la establece como su
      predeterminada, actualizando el enlace simbólico `clickhouse` en su `PATH`. Para descargar una versión
      sin cambiar su predeterminada ni actualizar el enlace simbólico, use
      `clickhousectl local install <version>` en su lugar.
    </Info>
  </Step>

  <Step>
    ## Iniciar clickhouse-server

    ```bash
    clickhousectl local server start
    ```

    El servidor se ejecuta en segundo plano. Para comprobar que está en ejecución:

    ```bash
    clickhousectl local server list
    ```
  </Step>

  <Step>
    ## Iniciar clickhouse-client

    ```bash
    clickhousectl local client
    ```

    Verá algo como esto:

    ```response
    ClickHouse client version 24.5.1.117 (official build).
    Connecting to localhost:9000 as user default.
    Connected to ClickHouse server version 24.5.1.

    local-host :)
    ```

    Ya está listo para empezar a enviar comandos SQL a ClickHouse.

    <Tip>
      La [Quick Start](/es/get-started/setup/install) le guía por los pasos para crear tablas e insertar datos.
    </Tip>
  </Step>
</Steps>
