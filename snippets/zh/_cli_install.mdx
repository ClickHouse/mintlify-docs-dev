  # 使用 ClickHouse 命令行客户端安装 ClickHouse
</div>

ClickHouse 命令行客户端 (`clickhousectl`) 可帮助你安装和管理本地 ClickHouse
版本、启动服务器并执行查询。

<Steps>
  <Step>
    ## 安装 ClickHouse 命令行客户端

    ```bash
    curl https://clickhouse.com/cli | sh
    ```

    为方便使用，还会自动创建一个 `chctl` 别名。
  </Step>

  <Step>
    ## 安装 ClickHouse

    安装最新版本的 ClickHouse 并将其设为默认版本：

    ```bash
    clickhousectl local use latest
    ```

    如果该版本尚未安装，`local use` 会自动安装它，并将其设为你的默认版本，同时在 `~/.local/bin` (位于你的 `PATH` 中) 中创建一个 `clickhouse` 符号链接，
    这样你就可以直接调用 `clickhouse` 可执行文件。此文档中后续任何运行 `clickhouse` 命令
    的步骤都可以直接照常使用。

    你也可以选择指定版本：

    ```bash
    clickhousectl local use 26.5            # 最新 26.5.x.x 版本
    clickhousectl local use 26.5.2.39       # 精确版本
    ```

    <Info>
      **use 与 install 的区别**

      `clickhousectl local use <version>` 会安装一个版本*并且*将其设为你的
      默认版本，同时更新你 `PATH` 中的 `clickhouse` 符号链接。若只想下载某个版本
      而不更改默认版本或更新符号链接，请改用
      `clickhousectl local install <version>`。
    </Info>
  </Step>

  <Step>
    ## 启动 clickhouse-server

    ```bash
    clickhousectl local server start
    ```

    服务器将在后台运行。要验证其是否已启动，请运行：

    ```bash
    clickhousectl local server list
    ```
  </Step>

  <Step>
    ## 启动 clickhouse-client

    ```bash
    clickhousectl local client
    ```

    你会看到类似以下内容：

    ```response
    ClickHouse client version 24.5.1.117 (official build).
    Connecting to localhost:9000 as user default.
    Connected to ClickHouse server version 24.5.1.

    local-host :)
    ```

    现在，你已经可以开始向 ClickHouse 发送 SQL 命令了！

    <Tip>
      [快速入门](/zh/get-started/setup/install) 将引导你完成创建表和插入数据的步骤。
    </Tip>
  </Step>
</Steps>
