<Tabs>
  <Tab title="Claude Code">
    Run in your terminal:
    ```
    claude mcp add clickhouse-docs -- npx -y mintlify-mcp --doc-url https://clickhouse.com/docs
    ```
  </Tab>
  <Tab title="Claude Desktop">
    Add to `claude_desktop_config.json`:

    ```
      "mcpServers": {
        "clickhouse-docs": {
          "command": "npx",

        }
      }
    }
    ```
