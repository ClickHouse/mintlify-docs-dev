  # Установка ClickHouse с помощью ClickHouse CLI
</div>

ClickHouse CLI (`clickhousectl`) помогает устанавливать локальные версии ClickHouse и управлять ими, запускать сервер и выполнять запросы.

<Steps>
  <Step>
    ## Установите ClickHouse CLI

    ```bash
    curl https://clickhouse.com/cli | sh
    ```

    Для удобства также автоматически создаётся алиас `chctl`.
  </Step>

  <Step>
    ## Установите ClickHouse

    Установите последнюю стабильную версию ClickHouse:

    ```bash
    clickhousectl local install stable
    ```

    Также можно установить конкретную версию:

    ```bash
    clickhousectl local install lts             # Последний LTS-релиз
    clickhousectl local install 25.6            # Последняя версия 25.6.x.x
    clickhousectl local install 25.6.1.1        # Точная версия
    ```
  </Step>

  <Step>
    ## Запустите clickhouse-server

    ```bash
    clickhousectl local server start
    ```

    Сервер работает в фоновом режиме. Чтобы проверить, что он запущен, выполните:

    ```bash
    clickhousectl local server list
    ```
  </Step>

  <Step>
    ## Запустите clickhouse-client

    ```bash
    clickhousectl local client
    ```

    Вы увидите примерно следующее:

    ```response
    ClickHouse client version 24.5.1.117 (official build).
    Connecting to localhost:9000 as user default.
    Connected to ClickHouse server version 24.5.1.

    local-host :)
    ```

    Теперь можно начинать отправлять SQL-команды в ClickHouse!

    <Tip>
      Руководство [Быстрый старт](/ru/get-started/setup/install) показывает, как создавать таблицы и выполнять вставку данных.
    </Tip>
  </Step>
</Steps>
