<div id="install-clickhouse-via-script-using-curl">
  # Installer ClickHouse à l’aide d’un script avec curl
</div>

Si vous n’avez pas besoin d’installer ClickHouse en production, vous pouvez exécuter un script d’installation avec curl. Le script déterminera le binaire adapté à votre système d’exploitation.

<Steps>
  <Step>
    ## Installer ClickHouse avec curl

    Exécutez la commande suivante pour télécharger un seul binaire pour votre système d’exploitation.

    ```bash
    curl https://clickhouse.com/ | sh
    ```

    Sous Linux et macOS, cela installe également [`clickhousectl`](https://github.com/ClickHouse/clickhousectl)
    dans `~/.local/bin` (avec un lien symbolique `chctl`) afin que vous puissiez gérer les
    versions et les serveurs ClickHouse locaux.

    Pour installer uniquement le binaire `clickhouse` sans `clickhousectl`, définissez
    `CLICKHOUSE_ONLY=1` :

    ```bash
    curl https://clickhouse.com/ | CLICKHOUSE_ONLY=1 sh
    ```

    <Note>
      Pour les utilisateurs de Mac : si vous obtenez des erreurs indiquant que le développeur du binaire ne peut pas être vérifié, veuillez consulter [cette page](/fr/resources/support-center/knowledge-base/troubleshooting/fix-developer-verification-error-in-macos).
    </Note>
  </Step>

  <Step>
    ## Démarrer clickhouse-local

    `clickhouse-local` vous permet de traiter des fichiers locaux et distants à l’aide de la
    puissante syntaxe SQL de ClickHouse, sans nécessiter de configuration. Les données des tables sont stockées
    dans un emplacement temporaire, ce qui signifie qu’après un redémarrage de `clickhouse-local`,
    les tables créées précédemment ne sont plus disponibles.

    Exécutez la commande suivante pour démarrer [clickhouse-local](/fr/concepts/features/tools-and-utilities/clickhouse-local) :

    ```bash
    ./clickhouse
    ```
  </Step>

  <Step>
    ## Démarrer clickhouse-server

    Si vous souhaitez conserver les données, vous devrez exécuter `clickhouse-server`. Vous pouvez
    démarrer le ClickHouse server à l’aide de la commande suivante :

    ```bash
    ./clickhouse server
    ```
  </Step>

  <Step>
    ## Démarrer clickhouse-client

    Une fois le server démarré, ouvrez une nouvelle fenêtre de terminal et exécutez la commande suivante
    pour lancer `clickhouse-client` :

    ```bash
    ./clickhouse client
    ```

    Vous verrez quelque chose comme ceci :

    ```response
    ./clickhouse client
    ClickHouse client version 24.5.1.117 (official build).
    Connecting to localhost:9000 as user default.
    Connected to ClickHouse server version 24.5.1.

    local-host :)
    ```

    Les données des tables sont stockées dans le répertoire actuel et restent disponibles après un redémarrage
    du ClickHouse server. Si nécessaire, vous pouvez passer
    `-C config.xml` comme argument de ligne de commande supplémentaire à `./clickhouse server`
    et fournir une configuration plus détaillée dans un fichier de configuration.
    Tous les paramètres de configuration disponibles sont documentés [ici](/fr/reference/settings/server-settings/settings), ainsi que dans le
    [fichier de configuration
    d’exemple](https://github.com/ClickHouse/ClickHouse/blob/master/programs/server/config.xml).

    Vous êtes maintenant prêt à envoyer des commandes SQL à ClickHouse !

    <Tip>
      Le [Quick Start](/fr/get-started/setup/install) vous guide à travers les étapes de création de tables et d’insertion de données.
    </Tip>
  </Step>
</Steps>
