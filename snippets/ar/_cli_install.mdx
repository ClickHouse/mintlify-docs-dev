  # تثبيت ClickHouse باستخدام ClickHouse CLI
</div>

يساعدك ClickHouse CLI (`clickhousectl`) على تثبيت إصدارات ClickHouse المحلية وإدارتها،
وتشغيل الخوادم، وتنفيذ الاستعلامات.

<Steps>
  <Step>
    ## تثبيت ClickHouse CLI

    ```bash
    curl https://clickhouse.com/cli | sh
    ```

    يُنشأ أيضًا الاسم المستعار `chctl` تلقائيًا لتسهيل الاستخدام.
  </Step>

  <Step>
    ## تثبيت ClickHouse

    ثبّت أحدث إصدار من ClickHouse واجعله الإصدار الافتراضي لديك:

    ```bash
    clickhousectl local use latest
    ```

    يعمل `local use` على تثبيت الإصدار إذا لم يكن موجودًا بالفعل، وتعيينه
    كإصدار افتراضي، وإنشاء رابط رمزي `clickhouse` في `~/.local/bin` (ضمن `PATH` لديك)
    حتى تتمكن من استدعاء الملف التنفيذي `clickhouse` مباشرةً. وبذلك، ستعمل أي خطوة لاحقة في هذه الوثائق
    تستخدم أمر `clickhouse` كما هي دون أي تعديل.

    يمكنك أيضًا تحديد إصدار معيّن:

    ```bash
    clickhousectl local use 26.5            # Latest 26.5.x.x
    clickhousectl local use 26.5.2.39       # Exact version
    ```

    <Info>
      **use مقابل install**

      يقوم `clickhousectl local use <version>` بتثبيت إصدار *وأيضًا* تعيينه
      كإصدار افتراضي لديك، مع تحديث الرابط الرمزي `clickhouse` في `PATH` لديك. ولتنزيل إصدار
      من دون تغيير الإصدار الافتراضي أو تحديث الرابط الرمزي، استخدم
      `clickhousectl local install <version>` بدلًا من ذلك.
    </Info>
  </Step>

  <Step>
    ## بدء clickhouse-server

    ```bash
    clickhousectl local server start
    ```

    يعمل الخادم في الخلفية. وللتحقق من أنه قيد التشغيل:

    ```bash
    clickhousectl local server list
    ```
  </Step>

  <Step>
    ## بدء clickhouse-client

    ```bash
    clickhousectl local client
    ```

    سترى شيئًا مثل هذا:

    ```response
    ClickHouse client version 24.5.1.117 (official build).
    Connecting to localhost:9000 as user default.
    Connected to ClickHouse server version 24.5.1.

    local-host :)
    ```

    أنت الآن جاهز لبدء إرسال أوامر SQL إلى ClickHouse!

    <Tip>
      يرشدك [Quick Start](/ar/get-started/setup/install) خلال خطوات إنشاء الجداول وإدراج البيانات.
    </Tip>
  </Step>
</Steps>
