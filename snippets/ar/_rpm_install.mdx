<div id="from-rpm-packages">
  # تثبيت ClickHouse على التوزيعات المستندة إلى rpm
</div>

> يُوصى باستخدام حزم `rpm` الرسمية المجمّعة مسبقًا لأنظمة **CentOS** و**RedHat** وجميع توزيعات
> Linux الأخرى المستندة إلى rpm.

<Steps>
  <Step>
    ## مراجعة التوصيات

    <Recommendations />
  </Step>

  <Step>
    ## إعداد مستودع RPM

    أضف المستودع الرسمي بتشغيل الأمر التالي:

    ```bash
    sudo yum install -y yum-utils
    sudo yum-config-manager --add-repo https://packages.clickhouse.com/rpm/clickhouse.repo
    ```

    بالنسبة إلى الأنظمة التي تستخدم مدير الحزم `zypper` ‏(openSUSE وSLES)، شغّل:

    ```bash
    sudo zypper addrepo -r https://packages.clickhouse.com/rpm/clickhouse.repo -g
    sudo zypper --gpg-auto-import-keys refresh clickhouse-stable
    ```

    في الخطوات التالية، يمكن استبدال `yum install` بـ `zypper install`، وذلك بحسب
    مدير الحزم الذي تستخدمه.
  </Step>

  <Step>
    ## تثبيت ClickHouse server وClickHouse client

    لتثبيت ClickHouse، شغّل الأوامر التالية:

    ```bash
    sudo yum install -y clickhouse-server clickhouse-client
    ```

    * يمكنك استبدال `stable` بـ `lts` لاستخدام أنواع [الإصدارات](/ar/resources/support-center/knowledge-base/setup-installation/production) المختلفة وفقًا لاحتياجاتك.
    * يمكنك تنزيل الحزم وتثبيتها يدويًا من [packages.clickhouse.com/rpm](https://packages.clickhouse.com/rpm/stable).
    * لتحديد إصدار معيّن، أضف `-$version` إلى نهاية اسم الحزمة،
      على سبيل المثال:

    ```bash
    sudo yum install clickhouse-server-22.8.7.34
    ```
  </Step>

  <Step>
    ## بدء تشغيل ClickHouse server

    لبدء تشغيل ClickHouse server، شغّل:

    ```bash
    sudo systemctl enable clickhouse-server
    sudo systemctl start clickhouse-server
    sudo systemctl status clickhouse-server
    ```

    لبدء تشغيل ClickHouse client، شغّل:

    ```bash
    clickhouse-client
    ```

    إذا قمت بإعداد كلمة مرور لخادمك، فستحتاج عندئذٍ إلى تشغيل:

    ```bash
    clickhouse-client --password
    ```
  </Step>

  <Step>
    ## تثبيت standalone ClickHouse Keeper

    <Tip>
      في بيئات الإنتاج، نوصي بشدة بتشغيل ClickHouse Keeper على عقد مخصّصة.
      في بيئات الاختبار، إذا قررت تشغيل ClickHouse Server وClickHouse Keeper على الخادم نفسه،
      فلن تحتاج إلى تثبيت ClickHouse Keeper لأنه مضمّن مع ClickHouse server.
    </Tip>

    لتثبيت `clickhouse-keeper` على خوادم standalone ClickHouse Keeper، شغّل:

    ```bash
    sudo yum install -y clickhouse-keeper
    ```
  </Step>

  <Step>
    ## تمكين ClickHouse Keeper وبدء تشغيله

    ```bash
    sudo systemctl enable clickhouse-keeper
    sudo systemctl start clickhouse-keeper
    sudo systemctl status clickhouse-keeper
    ```
  </Step>
</Steps>
