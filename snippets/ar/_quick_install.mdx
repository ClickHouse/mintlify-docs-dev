<div id="install-clickhouse-via-script-using-curl">
  # تثبيت ClickHouse عبر سكربت باستخدام curl
</div>

إذا لم تكن بحاجة إلى تثبيت ClickHouse لبيئة الإنتاج، فيمكنك تشغيل سكربت التثبيت باستخدام curl. سيحدّد السكربت ملفًا تنفيذيًا مناسبًا لنظام التشغيل لديك.

<Steps>
  <Step>
    ## تثبيت ClickHouse باستخدام curl

    شغّل الأمر التالي لتنزيل ملف تنفيذي واحد لنظام التشغيل لديك.

    ```bash
    curl https://clickhouse.com/ | sh
    ```

    على Linux وmacOS، يثبّت هذا أيضًا [`clickhousectl`](https://github.com/ClickHouse/clickhousectl)
    في `~/.local/bin` (مع رابط رمزي `chctl`) بحيث يمكنك إدارة
    إصدارات ClickHouse المحلية وخوادمه.

    لتثبيت الملف التنفيذي `clickhouse` فقط من دون `clickhousectl`، اضبط
    `CLICKHOUSE_ONLY=1`:

    ```bash
    curl https://clickhouse.com/ | CLICKHOUSE_ONLY=1 sh
    ```

    <Note>
      لمستخدمي macOS: إذا ظهرت لك أخطاء تفيد بأنه لا يمكن التحقق من مطوّر الملف التنفيذي، فيُرجى الاطلاع [هنا](/ar/resources/support-center/knowledge-base/troubleshooting/fix-developer-verification-error-in-macos).
    </Note>
  </Step>

  <Step>
    ## بدء clickhouse-local

    يتيح لك `clickhouse-local` معالجة الملفات المحلية والبعيدة باستخدام
    صياغة SQL القوية في ClickHouse ومن دون الحاجة إلى أي إعداد. تُخزَّن بيانات الجداول
    في موقع مؤقت، ما يعني أنه بعد إعادة تشغيل `clickhouse-local`
    لن تعود الجداول التي أُنشئت سابقًا متاحة.

    شغّل الأمر التالي لبدء [clickhouse-local](/ar/concepts/features/tools-and-utilities/clickhouse-local):

    ```bash
    ./clickhouse
    ```
  </Step>

  <Step>
    ## بدء clickhouse-server

    إذا كنت ترغب في الاحتفاظ بالبيانات، فستحتاج إلى تشغيل `clickhouse-server`. يمكنك
    بدء خادم ClickHouse باستخدام الأمر التالي:

    ```bash
    ./clickhouse server
    ```
  </Step>

  <Step>
    ## بدء clickhouse-client

    بعد تشغيل الخادم، افتح نافذة طرفية جديدة وشغّل الأمر التالي
    لبدء `clickhouse-client`:

    ```bash
    ./clickhouse client
    ```

    سترى شيئًا مشابهًا لما يلي:

    ```response
    ./clickhouse client
    ClickHouse client version 24.5.1.117 (official build).
    Connecting to localhost:9000 as user default.
    Connected to ClickHouse server version 24.5.1.

    local-host :)
    ```

    تُخزَّن بيانات الجداول في الدليل الحالي، وستظل متاحة بعد إعادة تشغيل
    خادم ClickHouse. وإذا لزم الأمر، يمكنك تمرير
    `-C config.xml` كوسيط إضافي في سطر الأوامر إلى `./clickhouse server`
    وتوفير مزيد من الإعدادات في ملف إعدادات.
    جميع إعدادات الضبط المتاحة موثقة [هنا](/ar/reference/settings/server-settings/settings) وفي
    [قالب ملف الإعدادات
    المثال](https://github.com/ClickHouse/ClickHouse/blob/master/programs/server/config.xml).

    أصبحت الآن جاهزًا لبدء إرسال أوامر SQL إلى ClickHouse!

    <Tip>
      يرشدك [Quick Start](/ar/get-started/setup/install) خلال خطوات إنشاء الجداول وإدراج البيانات.
    </Tip>
  </Step>
</Steps>
