<div id="description">
  ## 描述
</div>

包含 AzureQueue 元数据的内存状态，以及每个文件当前正在处理的行。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/}

* `zookeeper_path` ([String](/zh/reference/data-types)) — zookeeper 中元数据的 路径
* `file_path` ([String](/zh/reference/data-types)) — 正在处理的文件的路径
* `file_name` ([String](/zh/reference/data-types)) — 正在处理的文件名
* `rows_processed` ([UInt64](/zh/reference/data-types)) — 当前已处理的行数
* `status` ([String](/zh/reference/data-types)) — 处理状态：已处理、处理中、失败
* `processing_start_time` ([Nullable(DateTime)](/zh/reference/data-types)) — 文件开始处理的时间
* `processing_end_time` ([Nullable(DateTime)](/zh/reference/data-types)) — 文件处理结束的时间
* `exception` ([String](/zh/reference/data-types)) — 处理过程中发生的异常

{/*AUTOGENERATED_END*/}
