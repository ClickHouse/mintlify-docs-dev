<div id="description">
  ## 描述
</div>

此表包含 MergeTree 家族表的投影 parts 中各列的信息。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/}

* `partition` ([String](/zh/reference/data-types)) — 分区名称。
* `name` ([String](/zh/reference/data-types)) — 数据分区片段名称。
* `part_type` ([String](/zh/reference/data-types)) — 数据分区片段的存储格式。
* `parent_name` ([String](/zh/reference/data-types)) — 源 (父级) 数据分区片段的名称。
* `parent_uuid` ([UUID](/zh/reference/data-types)) — 源数据分区片段 (父数据分区片段) 的 UUID。
* `parent_part_type` ([String](/zh/reference/data-types)) — 源 (父) 数据分区片段的存储格式。
* `active` ([UInt8](/zh/reference/data-types)) — 表示数据分区片段是否为活动状态的标志
* `marks` ([UInt64](/zh/reference/data-types)) — 标记数。
* `rows` ([UInt64](/zh/reference/data-types)) — 行数。
* `bytes_on_disk` ([UInt64](/zh/reference/data-types)) — 所有数据分区片段文件的总大小 (以字节为单位) 。
* `data_compressed_bytes` ([UInt64](/zh/reference/data-types)) — 数据分区片段中压缩数据的总大小。不包括所有辅助文件 (例如标记文件) 。
* `data_uncompressed_bytes` ([UInt64](/zh/reference/data-types)) — 数据分区片段中未压缩数据的总大小。不包括所有辅助文件 (例如，标记文件) 。
* `marks_bytes` ([UInt64](/zh/reference/data-types)) — 标记文件的大小。
* `parent_marks` ([UInt64](/zh/reference/data-types)) — 源 (父) 分片中的标记数。
* `parent_rows` ([UInt64](/zh/reference/data-types)) — 源 (父) 分片的行数。
* `parent_bytes_on_disk` ([UInt64](/zh/reference/data-types)) — 所有源 (父) 数据分区片段文件的总大小 (以字节计) 。
* `parent_data_compressed_bytes` ([UInt64](/zh/reference/data-types)) — 源 (父) 数据分区片段中的压缩数据总大小。
* `parent_data_uncompressed_bytes` ([UInt64](/zh/reference/data-types)) — 源 (父) 数据分区片段中未压缩数据的总大小。
* `parent_marks_bytes` ([UInt64](/zh/reference/data-types)) — 源 (父) 数据分区片段中的标记文件大小。
* `modification_time` ([DateTime](/zh/reference/data-types)) — 包含数据分区片段的目录的修改时间。通常对应数据分区片段的创建时间。
* `remove_time` ([DateTime](/zh/reference/data-types)) — 数据分区片段变为非活跃状态的时间。
* `refcount` ([UInt32](/zh/reference/data-types)) — 数据分区片段被使用的地方数量。值大于 2 表示该数据分区片段正用于查询或合并。
* `min_date` ([Date](/zh/reference/data-types)) — 如果分区键中包含 Date 列，则表示该列的最小值。
* `max_date` ([Date](/zh/reference/data-types)) — 如果分区键中包含 Date 列，则表示该列的最大值。
* `min_time` ([DateTime](/zh/reference/data-types)) — 如果分区键中包含 DateTime 列，则表示该列的最小值。
* `max_time` ([DateTime](/zh/reference/data-types)) — 如果分区键中包含 DateTime 列，则为该列的最大值。
* `partition_id` ([String](/zh/reference/data-types)) — 分区 ID。
* `min_block_number` ([Int64](/zh/reference/data-types)) — 合并后组成当前数据分区片段的各数据分区片段中的最小编号。
* `max_block_number` ([Int64](/zh/reference/data-types)) — 合并后构成当前 part 的数据分区片段中的最大编号。
* `level` ([UInt32](/zh/reference/data-types)) — MergeTree 的层级深度。零表示当前 part 是通过 `insert` 创建的，而不是由其他 parts 合并而成。
* `data_version` ([UInt64](/zh/reference/data-types)) — 用于确定哪些变更应应用于数据分区片段的数值 (版本高于 data&#95;version 的变更) 。
* `primary_key_bytes_in_memory` ([UInt64](/zh/reference/data-types)) — 主键值占用的内存量 (以字节为单位) 。
* `primary_key_bytes_in_memory_allocated` ([UInt64](/zh/reference/data-types)) — 为主键值预留的内存量 (以字节为单位) 。
* `database` ([String](/zh/reference/data-types)) — 数据库名称。
* `table` ([String](/zh/reference/data-types)) — 表名称。
* `engine` ([String](/zh/reference/data-types)) — 不含参数的表引擎名称。
* `disk_name` ([String](/zh/reference/data-types)) — 用于存储数据分区片段的磁盘名称。
* `path` ([String](/zh/reference/data-types)) — 数据分区片段文件所在文件夹的绝对路径。
* `column` ([String](/zh/reference/data-types)) — 列名。
* `type` ([String](/zh/reference/data-types)) — 列类型。
* `column_position` ([UInt64](/zh/reference/data-types)) — 表中列的顺序位置，从 1 开始计数。
* `default_kind` ([String](/zh/reference/data-types)) — 默认值的表达式类型 (DEFAULT、MATERIALIZED、ALIAS) ；如果未定义，则为空字符串。
* `default_expression` ([String](/zh/reference/data-types)) — 用于默认值的表达式；如果未定义，则为空字符串。
* `column_bytes_on_disk` ([UInt64](/zh/reference/data-types)) — 列的总大小 (以字节为单位) 。
* `column_data_compressed_bytes` ([UInt64](/zh/reference/data-types)) — 列中压缩数据的总大小 (以字节为单位) 。
* `column_data_uncompressed_bytes` ([UInt64](/zh/reference/data-types)) — 列中解压后数据的总大小，以字节为单位。
* `column_marks_bytes` ([UInt64](/zh/reference/data-types)) — 标记列的大小，单位为字节。
* `column_modification_time` ([Nullable(DateTime)](/zh/reference/data-types)) — 该列上次修改的时间。

{/*AUTOGENERATED_END*/}
