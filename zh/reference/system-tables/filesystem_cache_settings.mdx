  ## 描述
</div>

包含所有文件系统缓存设置的相关信息

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/}

* `cache_name` ([String](/zh/reference/data-types)) — 缓存名称
* `path` ([String](/zh/reference/data-types)) — 缓存目录路径
* `max_size` ([UInt64](/zh/reference/data-types)) — 缓存最大大小
* `max_elements` ([UInt64](/zh/reference/data-types)) — 缓存元素的最大数量，例如 File 段 (限制文件系统中的文件数量)
* `max_file_segment_size` ([UInt64](/zh/reference/data-types)) — 单个 File 段的最大大小
* `boundary_alignment` ([UInt64](/zh/reference/data-types)) — File 段边界对齐
* `cache_on_write_operations` ([UInt8](/zh/reference/data-types)) — 启用直写缓存 (在 INSERT 和 MERGE 时缓存)
* `cache_policy` ([String](/zh/reference/data-types)) — 缓存淘汰策略
* `slru_size_ratio` ([Float64](/zh/reference/data-types)) — SLRU 缓存策略中保护区元素与试用区元素的大小比例
* `background_download_threads` ([UInt64](/zh/reference/data-types)) — 后台下载线程数。值为 0 时禁用后台下载
* `background_download_queue_size_limit` ([UInt64](/zh/reference/data-types)) — 后台下载队列大小。值为 0 时禁用后台下载
* `background_download_max_file_segment_size` ([UInt64](/zh/reference/data-types)) — 后台下载允许的最大大小
* `load_metadata_threads` ([UInt64](/zh/reference/data-types)) — 服务器启动时用于加载缓存元数据的最大线程数
* `load_metadata_asynchronously` ([UInt8](/zh/reference/data-types)) — 启用在服务器启动时异步加载元数据
* `keep_free_space_size_ratio` ([Float64](/zh/reference/data-types)) — 缓存在后台尝试维持的空闲空间比例
* `keep_free_space_elements_ratio` ([Float64](/zh/reference/data-types)) — 缓存在后台尝试维持的空闲元素比例
* `keep_free_space_remove_batch` ([UInt64](/zh/reference/data-types)) — 由维持空闲空间/元素比例的后台线程执行的缓存元素单次移除批次大小
* `enable_filesystem_query_cache_limit` ([UInt8](/zh/reference/data-types)) — 启用对单个查询内可写入缓存的最大大小进行限制
* `cache_hits_threshold` ([UInt64](/zh/reference/data-types)) — 已弃用设置
* `enable_bypass_cache_with_threshold` ([UInt8](/zh/reference/data-types)) — 未文档化。不建议使用
* `bypass_cache_threshold` ([UInt64](/zh/reference/data-types)) — 未文档化。不建议使用
* `write_cache_per_user_id_directory` ([UInt8](/zh/reference/data-types)) — ClickHouse Cloud 内部设置
* `allow_dynamic_cache_resize` ([UInt8](/zh/reference/data-types)) — 允许动态调整文件系统缓存大小
* `dynamic_resize_lock_wait_ms` ([UInt64](/zh/reference/data-types)) — 在跳过本次调整大小尝试之前，获取动态调整大小独占锁的超时时间 (毫秒)
* `max_size_ratio_to_total_space` ([Float64](/zh/reference/data-types)) — `max_size` 占磁盘总空间的比例
* `skip_cache_on_disk_failure` ([UInt8](/zh/reference/data-types)) — 如果为 true，则在发生磁盘 IO 错误时静默跳过文件系统缓存操作。如果为 false (默认) ，则磁盘 IO 错误会向上传播为启动失败。
* `use_split_cache` ([UInt8](/zh/reference/data-types)) — 使用 system/data 文件分离。
* `split_cache_ratio` ([Float64](/zh/reference/data-types)) — 在 split&#95;cache 中，system 分段占缓存总大小的比例。
* `overcommit_eviction_evict_step` ([UInt64](/zh/reference/data-types)) — overcommit 淘汰策略的淘汰步长 (以字节为单位) 。用于 keep&#95;free&#95;space&#95;*&#95;ratio 设置
* `check_cache_probability` ([Float64](/zh/reference/data-types)) — 仅适用于 debug 或 sanitizer build。会遍历整个缓存并检查每个缓存元素的状态，以验证缓存正确性
* `is_initialized` ([UInt8](/zh/reference/data-types)) — 表示缓存是否已成功初始化
* `current_size` ([UInt64](/zh/reference/data-types)) — 当前缓存大小
* `current_elements_num` ([UInt64](/zh/reference/data-types)) — 当前缓存元素 (File 段) 数量

{/*AUTOGENERATED_END*/}
