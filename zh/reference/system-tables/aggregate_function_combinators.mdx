<div id="description">
  ## 描述
</div>

包含所有可用聚合函数组合器的列表；这些组合器可应用于聚合函数，以改变其工作方式。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/zh/reference/data-types)) — 组合器的名称。
* `is_internal` ([UInt8](/zh/reference/data-types)) — 该组合器是否仅用于内部。

{/*AUTOGENERATED_END*/}
