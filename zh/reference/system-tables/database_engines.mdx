<div id="description">
  ## 描述
</div>

列出服务器支持的数据库引擎。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/zh/reference/data-types)) — 数据库引擎的名称。

{/*AUTOGENERATED_END*/}

<div id="example">
  ## 示例
</div>

```sql title="Query"
SELECT *
FROM system.database_engines
WHERE name IN ('Atomic', 'Lazy', 'Ordinary')
```

```text title="Response"
┌─name─────┐
│ Ordinary │
│ Atomic   │
│ Lazy     │
└──────────┘
```
