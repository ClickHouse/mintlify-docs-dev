<div id="description">
  ## 描述
</div>

此表包含 MergeTree 家族中各表的 projection parts 信息。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/}

* `partition` ([String](/zh/reference/data-types)) — 分区名称。
* `name` ([String](/zh/reference/data-types)) — 数据分区片段名称。
* `part_type` ([String](/zh/reference/data-types)) — 数据分区片段的存储格式。可能的值：Wide (每列对应一个文件) 和 Compact (所有列共用一个文件) 。
* `parent_name` ([String](/zh/reference/data-types)) — 源数据分区片段 (父分区片段) 的名称。
* `parent_uuid` ([UUID](/zh/reference/data-types)) — 源 (父) 数据分区片段的 UUID。
* `parent_part_type` ([String](/zh/reference/data-types)) — 源数据分区片段 (父分区片段) 的存储格式。
* `active` ([UInt8](/zh/reference/data-types)) — 用于指示数据分区片段是否处于活动状态的标志。如果数据分区片段处于活动状态，则会在表中使用；否则，将被删除。非活动的数据分区片段会在合并和变异操作后出现。
* `marks` ([UInt64](/zh/reference/data-types)) — 标记的数量。要获取数据分区片段中大致的行数，可将标记数乘以索引粒度 (通常为 8192)  (此方法不适用于自适应粒度) 。
* `rows` ([UInt64](/zh/reference/data-types)) — 行数。
* `bytes_on_disk` ([UInt64](/zh/reference/data-types)) — 所有数据分区片段文件的总大小，单位为字节。
* `data_compressed_bytes` ([UInt64](/zh/reference/data-types)) — 数据分区片段中压缩数据的总大小。不包括任何辅助文件 (例如标记文件) 。
* `data_uncompressed_bytes` ([UInt64](/zh/reference/data-types)) — 数据分区片段中未压缩数据的总大小。不包括任何辅助文件 (例如标记文件) 。
* `marks_bytes` ([UInt64](/zh/reference/data-types)) — 标记文件的大小。
* `parent_marks` ([UInt64](/zh/reference/data-types)) — 源 (父) part 中的标记数。
* `parent_rows` ([UInt64](/zh/reference/data-types)) — 源 (父) 分片中的行数。
* `parent_bytes_on_disk` ([UInt64](/zh/reference/data-types)) — 所有源 (父) 数据分区片段文件的总大小 (以字节计) 。
* `parent_data_compressed_bytes` ([UInt64](/zh/reference/data-types)) — 源 (父) 数据分区片段中压缩后数据的总大小。
* `parent_data_uncompressed_bytes` ([UInt64](/zh/reference/data-types)) — 源 (父) 数据分区片段中的未压缩数据总大小。
* `parent_marks_bytes` ([UInt64](/zh/reference/data-types)) — 源 (父) 数据分区片段中的标记文件大小。
* `modification_time` ([DateTime](/zh/reference/data-types)) — 存放数据分区片段的目录的修改时间。通常对应于数据分区片段的创建时间。
* `remove_time` ([DateTime](/zh/reference/data-types)) — 数据分区片段变为非活跃状态的时间。
* `refcount` ([UInt32](/zh/reference/data-types)) — 引用该数据分区片段的地方数量。值大于 2 表示该数据分区片段用于查询或合并操作。
* `min_date` ([Date](/zh/reference/data-types)) — 数据分区片段中日期键的最小值。
* `max_date` ([Date](/zh/reference/data-types)) — 数据分区片段中日期键的最大值。
* `min_time` ([DateTime](/zh/reference/data-types)) — 数据分区片段中日期时间键的最小值。
* `max_time` ([DateTime](/zh/reference/data-types)) — 数据分区片段中日期时间键的最大值。
* `partition_id` ([String](/zh/reference/data-types)) — 分区 ID。
* `min_block_number` ([Int64](/zh/reference/data-types)) — 合并后构成当前 part 的各数据分区片段中的最小编号。
* `max_block_number` ([Int64](/zh/reference/data-types)) — 合并后构成当前数据分区片段的各数据分区片段中的最大编号。
* `level` ([UInt32](/zh/reference/data-types)) — MergeTree 的深度。零表示当前 part 是通过 insert 创建的，而不是由其他 parts 合并而成。
* `data_version` ([UInt64](/zh/reference/data-types)) — 用于确定哪些变更需要应用到数据分区片段上的数值 (即版本高于 data&#95;version 的变更) 。
* `primary_key_bytes_in_memory` ([UInt64](/zh/reference/data-types)) — 主键值占用的内存大小 (以字节为单位) 。
* `primary_key_bytes_in_memory_allocated` ([UInt64](/zh/reference/data-types)) — 为主键值预留的内存大小 (以字节为单位) 。
* `is_frozen` ([UInt8](/zh/reference/data-types)) — 表示是否存在分区数据备份的标志。1 表示备份存在。0 表示备份不存在。
* `database` ([String](/zh/reference/data-types)) — 数据库名称。
* `table` ([String](/zh/reference/data-types)) — 表名。
* `engine` ([String](/zh/reference/data-types)) — 不含参数的表引擎名称。
* `disk_name` ([String](/zh/reference/data-types)) — 用于存储数据分区片段的磁盘名称。
* `path` ([String](/zh/reference/data-types)) — 数据分区片段文件所在文件夹的绝对路径。
* `hash_of_all_files` ([String](/zh/reference/data-types)) — 压缩文件的 sipHash128 哈希值。
* `hash_of_uncompressed_files` ([String](/zh/reference/data-types)) — 未压缩文件 (包含标记、索引文件等的文件) 的 sipHash128 哈希值。
* `uncompressed_hash_of_compressed_files` ([String](/zh/reference/data-types)) — 将压缩文件中的数据视为未压缩时计算得到的 sipHash128。
* `delete_ttl_info_min` ([DateTime](/zh/reference/data-types)) — TTL DELETE 规则中日期时间键的最小值。
* `delete_ttl_info_max` ([DateTime](/zh/reference/data-types)) — TTL DELETE 规则中日期时间键的最大值。
* `move_ttl_info.expression` ([Array(String)](/zh/reference/data-types)) — 由表达式组成的数组。每个表达式定义一条 TTL MOVE 规则。
* `move_ttl_info.min` ([Array(DateTime)](/zh/reference/data-types)) — 日期时间值数组。每个元素表示某个 TTL MOVE 规则的最小键值。
* `move_ttl_info.max` ([Array(DateTime)](/zh/reference/data-types)) — 日期时间值数组。每个元素表示某条 TTL MOVE 规则的最大键值。
* `default_compression_codec` ([String](/zh/reference/data-types)) — 用于压缩此数据分区片段的编解码器名称 (当列未显式指定编解码器时) 。
* `recompression_ttl_info.expression` ([Array(String)](/zh/reference/data-types)) — TTL 表达式。
* `recompression_ttl_info.min` ([Array(DateTime)](/zh/reference/data-types)) — 此分片内计算出的 TTL 表达式的最小值。用于判断是否至少有一行的生存时间 (TTL) 已到期。
* `recompression_ttl_info.max` ([Array(DateTime)](/zh/reference/data-types)) — 该分片内计算得出的生存时间 (TTL) 表达式的最大值。用于判断是否已包含所有生存时间 (TTL) 已过期的行。
* `group_by_ttl_info.expression` ([Array(String)](/zh/reference/data-types)) — 生存时间 (TTL) 表达式。
* `group_by_ttl_info.min` ([Array(DateTime)](/zh/reference/data-types)) — 此分片内计算出的 TTL 表达式最小值。用于判断是否至少有一行数据的 TTL 已过期。
* `group_by_ttl_info.max` ([Array(DateTime)](/zh/reference/data-types)) — 此分片内计算得到的 TTL 表达式的最大值。用于判断是否已包含所有生存时间 (TTL) 已过期的行。
* `rows_where_ttl_info.expression` ([Array(String)](/zh/reference/data-types)) — TTL 表达式。
* `rows_where_ttl_info.min` ([Array(DateTime)](/zh/reference/data-types)) — 此 part 中计算出的 TTL 表达式的最小值。用于判断是否至少有一行的 TTL 已过期。
* `rows_where_ttl_info.max` ([Array(DateTime)](/zh/reference/data-types)) — 此分片内计算出的 TTL 表达式的最大值。用于判断是否已包含所有生存时间 (TTL) 已过期的行。
* `is_broken` ([UInt8](/zh/reference/data-types)) — 投影分片是否损坏
* `exception_code` ([Int32](/zh/reference/data-types)) — 说明投影分片损坏状态的异常消息
* `exception` ([String](/zh/reference/data-types)) — 说明投影分片损坏状态的异常代码
