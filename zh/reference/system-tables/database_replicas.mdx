<div id="description">
  ## 描述
</div>

包含各个 Replicated 数据库副本的信息。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/zh/reference/data-types)) — 所属 Replicated 数据库的名称。
* `is_readonly` ([UInt8](/zh/reference/data-types)) — 数据库副本是否处于只读模式。
* `max_log_ptr` ([Int32](/zh/reference/data-types)) — 常规活动日志中的最大条目编号。
* `replica_name` ([String](/zh/reference/data-types)) — ClickHouse Keeper 中的副本名称。
* `replica_path` ([String](/zh/reference/data-types)) — ClickHouse Keeper 中副本数据的路径。
* `zookeeper_path` ([String](/zh/reference/data-types)) — ClickHouse Keeper 中数据库数据的路径。
* `shard_name` ([String](/zh/reference/data-types)) — 集群中分片的名称。
* `log_ptr` ([Int32](/zh/reference/data-types)) — 副本已复制到其执行队列的常规活动日志中的最大条目编号，再加一。
* `total_replicas` ([UInt32](/zh/reference/data-types)) — 该数据库已知副本的总数。
* `zookeeper_exception` ([String](/zh/reference/data-types)) — 最近一次异常的消息；如果在从 ClickHouse Keeper 拉取信息时发生错误，则会返回该消息。
* `is_session_expired` ([UInt8](/zh/reference/data-types)) — 与 ClickHouse Keeper 的会话已过期。基本等同于 `is_readonly`。

{/*AUTOGENERATED_END*/}
