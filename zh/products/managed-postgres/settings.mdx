您可以在侧边栏的 **设置** 选项卡中，修改 Managed Postgres 实例的配置参数并管理实例设置。

<div id="changing-configuration">
  ## 更改配置参数
</div>

<Image img="/images/managed-postgres/postgres-parameters.png" alt="Postgres 参数配置" size="md" border />

要修改参数，请选择 **Edit parameters** 按钮。选择需要修改的参数，并相应调整其值。确认修改无误后，点击 **Save Changes** 按钮。

对配置参数所做的更改通常会在一分钟内保存到实例。某些参数需要重启数据库后才会生效。这些更改将在下次重启后应用，你可以从 **Service actions** 工具栏手动触发重启。

<div id="service-actions">
  ## Service actions 与扩缩容
</div>

<Image img="/images/managed-postgres/service-actions.png" alt="Service actions 与扩缩容" size="md" border />

**Service actions** 工具栏提供了用于管理您的 Managed Postgres 实例的操作：

* **重置密码**：更新 superuser 密码 (仅当实例处于 `Running` 状态时可用) 
* **重启**：重启数据库实例 (仅当实例处于 `Running` 状态时可用) 
* **删除**：删除实例

**扩缩容** 部分允许您更改主节点和备用节点的实例类型，以增加或减少计算资源和存储容量。系统会先预配新实例，并在其追上当前主节点后接管服务。故障转移过程会中断所有现有连接，并导致短暂中断。

<Tip>
  出于安全考虑，您可能无法切换到存储容量接近当前已用存储容量的实例类型。为避免出现问题，请始终选择存储容量高于当前已用容量、留有余量的实例类型。
</Tip>

<div id="ip-filters">
  ## IP 过滤器
</div>

IP 过滤器用于控制哪些源 IP 地址可以连接到你的 Managed Postgres 实例。

<Image img="/images/managed-postgres/ip-filters.png" alt="IP 访问列表配置" size="md" border />

要配置 IP 过滤器：

1. 前往 **设置** 选项卡
2. 在 **IP 过滤器** 下，点击 **编辑**
3. 添加允许连接的 IP 地址或 CIDR 范围
4. 点击 **保存** 以应用更改

你可以指定单个 IP 地址，也可以使用 CIDR 表示法来表示 IP 范围 (例如 `192.168.1.0/24`) 。你还可以选择 **Anywhere** 或 **Nowhere**，作为将实例完全向公网开放或完全关闭的快捷选项。

<Note>
  如果未配置任何 IP 过滤器，则允许来自所有 IP 地址的连接。对于生产工作负载，我们建议仅允许已知 IP 地址访问。
</Note>
