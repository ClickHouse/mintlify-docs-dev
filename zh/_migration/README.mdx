<div id="migration">
  # 迁移
</div>

用于将 ClickHouse 文档从 Docusaurus 迁移到 Mintlify 的一次性工具和数据。**整个文件夹在迁移
完成后都可以删除**——线上站点在运行时没有任何内容依赖它。

<div id="contents">
  ## 内容
</div>

* `slug-map.csv` — 每个 Docusaurus slug → Mintlify 文件/URL 的对应关系，并附带
  用于跟踪过期状态的 source/migrated 哈希值。
* `slug-aliases.csv` — 针对无法自动
  解析的 slug，经人工审核的别名。
* `migrate.py` — 主迁移脚本。读取 `slug-map.csv`，应用
  Mintlify 所需的转换，并写出结果。
* `generate-slug-map.py` — 根据上游 Docusaurus
  * 当前仓库的布局重新生成 `slug-map.csv`。
* `apply-slug-aliases.py` — 使用 `slug-aliases.csv` 重写 `<!-- MIGRATE: unknown slug -->` 标记。
* `suggest-slug-aliases.py` — 为未解析的 slug 提供别名候选项。
* `match_slugless.py` — 查找在上游中没有 slug 匹配的 Mintlify 页面。
* `verify_mapping.py` — 检查 slug 映射中是否存在重复项或漂移。
* `find_dup_imports.py` — 检测由于 Mintlify
  将 snippet 导入提升到父级 bundle 而导致的 MDX import 冲突。

迁移工作流请参见 `.claude/skills/migrate-docusaurus-to-mintlify/SKILL.md`。
