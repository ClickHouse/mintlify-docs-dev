原生协议用于[命令行客户端](/zh/concepts/features/interfaces/cli)、分布式查询处理期间的服务器间通信，也用于其他 C++ 程序。遗憾的是，ClickHouse 原生协议目前还没有正式规范，不过可以通过 ClickHouse 源代码 (大致从[这里](https://github.com/ClickHouse/ClickHouse/tree/master/src/Client)开始) 和/或拦截并分析 TCP 流量来进行逆向分析。
