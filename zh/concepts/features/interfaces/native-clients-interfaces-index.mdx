ClickHouse 提供多种原生客户端与接口，让您可以连接到 ClickHouse。

更多信息请参见以下页面：

| Section                                                            | Summary                        |
| ------------------------------------------------------------------ | ------------------------------ |
| [clickhousectl](/zh/concepts/features/interfaces/cli)                 | ClickHouse 的 CLI，支持本地和云端。      |
| [ClickHouse Client](/zh/concepts/features/interfaces/client)          | 原生命令行客户端，支持命令行选项和配置文件。         |
| [驱动和接口](/zh/concepts/features/interfaces/overview)                    | 提供多种网络接口、库和可视化界面。              |
| [C++ 客户端库](/zh/concepts/features/interfaces/cpp)                      | 用于连接 ClickHouse 的 C++ 客户端库。    |
| [从输入数据自动推断 schema](/zh/concepts/features/interfaces/schema-inference) | 从输入数据自动推断 schema。              |
| [Web 终端](/zh/concepts/features/interfaces/web-terminal)               | 适用于 ClickHouse 的基于浏览器的 Web 终端。 |
| [第三方客户端](/zh/concepts/features/interfaces/third-party/index)          | 来自第三方开发者的客户端库、GUI、代理及其他接口。     |
