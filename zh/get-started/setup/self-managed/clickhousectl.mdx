<div id="install-clickhouse-using-the-clickhouse-cli">
  # 使用 ClickHouse 命令行客户端安装 ClickHouse
</div>

ClickHouse 命令行客户端 (`clickhousectl`) 可帮助你安装和管理本地 ClickHouse
版本、启动服务器并执行查询。

<Steps>
  <Step>
    ## 安装 ClickHouse 命令行客户端

    ```bash
    curl https://clickhouse.com/cli | sh
    ```

    为方便使用，还会自动创建一个 `chctl` 别名。
  </Step>

  <Step>
    ## 安装 ClickHouse

    安装最新的稳定版本 ClickHouse：

    ```bash
    clickhousectl local install stable
    ```

    你也可以安装指定版本：

    ```bash
    clickhousectl local install lts             # 最新 LTS 版本
    clickhousectl local install 25.6            # 最新 25.6.x.x 版本
    clickhousectl local install 25.6.1.1        # 精确版本
    ```
  </Step>

  <Step>
    ## 启动 clickhouse-server

    ```bash
    clickhousectl local server start
    ```

    服务器将在后台运行。要验证其是否已启动，请运行：

    ```bash
    clickhousectl local server list
    ```
  </Step>

  <Step>
    ## 启动 clickhouse-client

    ```bash
    clickhousectl local client
    ```

    你会看到类似以下内容：

    ```response
    ClickHouse client version 24.5.1.117 (official build).
    Connecting to localhost:9000 as user default.
    Connected to ClickHouse server version 24.5.1.

    local-host :)
    ```

    现在，你已经可以开始向 ClickHouse 发送 SQL 命令了！

    <Tip>
      [快速入门](/zh/get-started/setup/install) 将引导你完成创建表和插入数据的步骤。
    </Tip>
  </Step>
</Steps>
